## 摘要
用于连续控制的世界模型通常针对固定物理系统进行训练，当连杆长度、质量、阻尼和驱动等已知形态参数发生变化时，其性能会下降。现有方法通常将这些参数作为条件信息提供，但未指明学习到的状态转移中哪些部分应保持可复用，哪些部分应随形态而变化。我们提出了图算子世界模型（GraphOp-WM），一种用于在相关关节式机器人族内泛化到未见形态参数的结构化世界模型。GraphOp-WM 将刚体及其运动学关系表示为属性图，并将每个转移分解为形态无关的局部动力学基和形态条件的结构化算子。该算子结合了节点局部调制、运动树耦合和低秩全局校正，同时通过架构信息分离、基归一化和成对形态监督，促使静态形态依赖性由算子路径承载。图级读出和逐边动作表示为奖励、价值和 TD-MPC 风格规划提供了兼容接口。我们进一步定义了受控的 MuJoCo 参数划分，涵盖 Hopper、Walker2d 和 HalfCheetah 中连杆几何、质量、阻尼和驱动参数的内插、外推及留出组合。

## Abstract
World models for continuous control are commonly trained for a fixed physical system and can degrade when known morphology parameters such as link lengths, masses, damping, and actuation change. Existing approaches often provide these parameters as conditioning information, but leave unspecified which part of the learned transition should remain reusable and which part should change with morphology. We propose Graph-Operator World Models (GraphOp-WM), a structured world model for generalization across unseen morphology parameters within related articulated robot families. GraphOp-WM represents bodies and their kinematic relations as an attributed graph and factorizes each transition into a morphology-independent local dynamics basis and a morphology-conditioned structured operator. The operator combines node-local modulation, kinematic-tree coupling, and a low-rank global correction, while architectural information separation, basis normalization, and paired-morphology supervision encourage static morphology dependence to be carried by the operator pathway. Graph-level readout and edge-wise action representations provide a compatible interface for reward, value, and TD-MPC-style planning. We further define controlled MuJoCo parameter splits covering interpolation, extrapolation, and held-out compositions of link geometry, mass, damping, and actuation parameters in Hopper, Walker2d, and HalfCheetah.

### 1. 核心问题与研究动机

- **背景**：世界模型（World Models）在连续控制中通过学习潜在状态转移、奖励预测和价值估计，支持规划或想象策略优化（如 DreamerV3、TD-MPC2、PWM 等）。但这些模型通常针对**固定物理系统**训练，一旦机器人的形态参数（如连杆长度、质量、阻尼、驱动齿轮比等）发生变化，模型性能会显著退化。
- **核心问题**：现有形态条件化方法（如将机器人规格编码为条件向量或结构嵌入）虽然能感知形态变化，但**没有明确区分**状态转移中哪些部分应当跨形态复用（可泛化的局部动力学），哪些部分应当随形态参数变化（形态引起的动力学耦合变化）。条件向量无法规定形态参数如何"变换"局部动力学响应之间的耦合关系。
- **核心研究问题**：能否构建一个紧凑的世界模型，通过显式分离"可复用的局部动力学"与"形态诱导的耦合"，实现对未见物理形态参数的泛化？

### 2. 方法论：GraphOp-WM

**（1）核心思想**

GraphOp-WM 将机器人表示为属性图，每个转移分解为两部分：
- **形态无关的局部动力学基（morphology-independent local dynamics basis）**：一个共享的局部核函数，基于局部状态、局部动作和离散刚体类型，预测每个刚体的规范增量，**刻意不观测**质量、长度、惯量、形态 ID 或池化形态嵌入。
- **形态条件化的结构化算子（morphology-conditioned structured operator）**：由形态编码器从静态形态图生成，作用于局部基上，负责将局部响应"传播"为整体状态转移。

**（2）关键公式与机制**

论文提出的转移公式（残差形式）为：

$\hat{Z}_{t+1} = Z_t + A_{m,t} \bar{B}_t$

其中 $Z_t$ 为刚体 token 矩阵，$\bar{B}_t$ 是归一化的共享局部动力学基，$A_{m,t}$ 为形态条件化的图算子。

算子结构为：

$A_{m,t} = I + \text{Diag}(d_{m,t}) + E_m \text{Diag}(w_{m,t}) E_m^\top + U_{m,t} \text{Diag}(s_{m,t}) U_{m,t}^\top$

其中：
- **对角项** $I + \text{Diag}(d_{m,t})$：捕捉刚体局部响应（body-local response）；
- **关联矩阵项** $E_m \text{Diag}(w_{m,t})E_m^\top$：沿运动学树传播耦合；
- **低秩全局校正项** $U_{m,t}\text{Diag}(s_{m,t})U_{m,t}^\top$：捕捉躯干-肢体耦合、接触导致的非局部模态。

**（3）信息分离与监督机制**

- **架构信息分离**：静态形态属性仅进入算子 $A_{m,t}$，局部基不观测任何静态形态信息，阻断了状态通路对形态的直接访问；
- **基归一化**：对每个图的基按 RMS 范数归一化，消除基与算子之间的尺度模糊；
- **成对形态监督（paired-morphology supervision）**：在同一标准化初始状态和动作序列下，用同一局部基与两个不同形态的算子分别预测转移，逼使形态差异全部通过算子表达；
- **算子-交换分析**：用受控形态的算子交换后对比模拟器输出来验证分配的合理性。

**（4）动作、奖励、价值与规划接口**

- 动作按**执行器边**嵌入，输出维度等于当前形态执行器数量，天然支持变维动作；
- 奖励分解为全局项 + 局部刚体项 + 执行器边项；价值头使用图级读出（全局 query 注意力 + 根节点 token 拼接），支持任意刚体数量下固定输入维度；
- 规划沿用 TD-MPC 风格的 MPPI/CEM 优化，候选轨迹维度随当前形态而定，无需固定的全局最大动作维度。

**（5）训练目标**

由动态损失（token 级对齐）、奖励损失、TD 价值损失、成对形态损失和算子正则化（促进算子接近单位阵）加权组成。
