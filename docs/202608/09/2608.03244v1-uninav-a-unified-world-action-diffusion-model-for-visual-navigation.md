## 摘要
图像目标视觉导航是具身智能体的基本能力。现有的导航策略能高效预测航点轨迹，但缺乏视觉前瞻性；而导航世界模型能够预测未来观测，但通常需要昂贵的规划展开。我们提出UniNav，一种统一的世界-动作模型，通过单一扩散过程生成未来视觉观测和连续航点轨迹。给定历史帧和目标图像，UniNav在单个Transformer中联合去噪视觉和航点token，在共享框架中统一未来预测和动作生成。为改善空间接地，我们引入几何感知的相机token。我们还在带有轨迹标注的导航数据和纯视频数据上训练，使模型能够从多样化的视频中获益而无需航点标注。基于该统一框架，我们提出两种变体：UniNav-Full联合预测可解释的未来观测及其对应轨迹，而UniNav-Fast在推理时移除未来图像token以实现高效轨迹预测。在导航基准上的实验表明，UniNav在所有数据集上的ATE均优于最强基线。通过一步推理，UniNav-Fast实现0.1秒延迟且无明显精度下降。代码将发布。

## Abstract
Image-goal visual navigation is a fundamental capability for embodied agents. Existing navigation policies efficiently predict waypoint trajectories but lack visual foresight, while navigation world models can anticipate future observations but often require costly planning rollouts. We present UniNav, a unified world-action model that generates future visual observations and continuous waypoint trajectories through a single diffusion process. Given history frames and a goal image, UniNav jointly denoises visual and waypoint tokens within a single transformer, unifying future prediction and action generation in a shared framework. To improve spatial grounding, we incorporate geometry-aware camera tokens. We also train on both trajectory-labeled navigation data and video-only data, enabling the model to benefit from diverse videos without waypoint annotations. Based on this unified framework, we introduce two variants: UniNav-Full jointly predicts interpretable future observations and their corresponding trajectories, while UniNav-Fast removes future-image tokens at inference for efficient trajectory prediction. Experiments on navigation benchmarks show that UniNav outperforms the strongest baseline in ATE across all datasets. With one-step inference, UniNav-Fast achieves a latency of 0.1s without a substantial accuracy drop. Code will be released.

- 整体意义：为视觉导航提供了一种“一边想象、一边行动”的统一范式，同时通过快速变体保证部署效率。

## 2. 论文提出的方法论：核心思想与关键技术

### 核心思想
- 在**单个扩散过程中**联合去噪未来视觉潜变量和航点轨迹 token，用共享 Transformer 统一建模世界动态与动作生成。
- 在训练时额外引入**几何感知相机 token**，通过冻结的几何基础模型（Depth Anything 3）提取 3D 结构信息，增强空间接地。
- 支持**轨迹标注导航数据与纯视频数据混合训练**，纯视频数据不提供航点标注，仅提供视觉和相机 token 监督，从而扩大训练数据规模。

### 技术细节
- 基于预训练视频扩散模型 **Wan2.1-1.3B** 初始化，视频 VAE 保持冻结，扩散 Transformer 与新模块进行微调。
- 输入序列由以下 token 组成：
  - 历史视觉 token、目标图像 token、未来视觉 token；
  - K 步航点 token；
  - 几何相机 token（对未来 K 帧的归一化几何描述）；
  - 可学习 register token，促进异质 token 间全局信息交换。
- 视觉 token 沿用预训练模型的旋转位置编码；航点、相机、register token 使用身份位置编码，避免强加不合理的空间坐标。
- 训练目标为**统一 flow-matching 目标**，同时优化三部分损失：
  - 视频损失：预测未来视频潜变量的速度场；
  - 轨迹损失：对航点轨迹速度场使用 SmoothL1 损失；
  - 相机损失：对相机 token 的速度场进行 L2 损失。
- 总损失为三种损失的加权和，权重为 \(\lambda_{vid}=1, \lambda_{traj}=5, \lambda_{cam}=0.01\)。

### 两种推理变体
- **UniNav-Full**：在推理时对噪声未来图像与航点轨迹进行迭代去噪，同时输出可解释的未来观测和航点轨迹。
- **UniNav-Fast**：训练时使用非对称注意力，使非未来 token 不关注噪声未来图像 token；推理时直接移除未来图像 token，仅采样航点轨迹，从而跳过视频解码，降低延迟。

## 6. 论文的主要结论与发现

- UniNav 在所有四个导航数据集上的 **ATE 均优于最强基线**：
  - RECON 降低 3.7%，SaCSoN 降低 24.7%，GO Stanford 降低 18.2%，SCAND 降低 6.8%。
- 联合建模未来视觉动态和航点动作能够提升航点预测精度，说明视觉前瞻对动作决策有正向促进作用。
- **相机 token 几何监督**能有效提升预测空间结构，且可作为可学习的去噪目标，避免依赖未来帧真值。
- **混合训练**仅在加入相机 token 几何监督时才能提升航点预测；若只有视觉预测损失，纯视频数据反而带来微小精度下降。
- **UniNav-Fast** 通过移除未来图像 token，在默认 2 步采样下延迟从 0.389s 降至 0.212s；一步采样时延迟仅 0.109s，精度几乎不降。
- 相比 NWM 约 900 秒的规划延迟，UniNav 在效率和精度上均更具实用性。

## 7. 优点

- **统一架构**：在单一 diffusion transformer 中联合建模视觉前瞻和动作生成，避免传统世界模型的多次 rollout。
- **可解释性**：能直接生成未来观测，提供 interpretable 的预测结果。
- **几何接地**：引入冻结几何基础模型的相机 token，为动作预测注入 3D 结构约束。
- **数据可扩展性**：支持无标注视频数据训练，通过几何 token 监督桥接视觉动态与动作预测，降低了对高成本航点标注的依赖。
- **推理灵活性**：提供 Full 和 Fast 两种变体，兼顾可解释性与实时性。
- **效果显著**：在所有 benchmark 上超越强基线，且具备很低延迟，工程实用性较强。

## 8. 不足与局限

- **短视距**：仅预测短时局部航点，未显式解决长时程规划。
- **离线评估为主**：实验主要在离线数据集上进行，缺少真实机器人闭环实验与开放世界部署验证。
- **消融范围有限**：核心消融仅在 RECON 上完成，跨数据集泛化下的设计选择未充分验证。
