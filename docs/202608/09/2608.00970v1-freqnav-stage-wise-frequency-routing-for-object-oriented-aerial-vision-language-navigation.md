## 摘要
面向目标的空中视觉语言导航（VLN）要求在长时程闭环控制下搜索指定目标并精确着陆。导航过程中由目标描述指令引导，感知优先级动态演变：早期探索优先关注低频空间布局，随后转向高频目标细节。现有VLN方法在整个导航阶段使用相同的视觉令牌来建模变化的感知需求，导致无关物体和背景杂波产生干扰。为此，我们将长时程空中导航形式化为从空间结构到局部细节的频率偏好转移，并提出FreqNav，一种轻量级频率路由自适应感知框架。在固定计算预算下，FreqNav根据当前导航阶段动态重新分配跨频率分量的视觉令牌。频率令牌路由器从双视角观测中选择与阶段相关的视觉表示，而相位相关接地模块通过显式监督锚定视觉证据。然后，扩散Transformer预测用于连续控制的平滑轨迹。实验表明，FreqNav在超越强基线模型的同时实现了约3倍的推理加速。实际部署进一步证明了其在长时程空中自主性方面的有效性、效率和实际潜力。

## Abstract
Object-oriented aerial vision-and-language navigation (VLN) requires searching for a described target and landing on it precisely, under long-horizon and closed-loop control. Guided by a target-descriptive instruction during navigation, perceptual priorities dynamically evolve: early-stage exploration prioritizes low-frequency spatial layout, and then shifts to high-frequency target details. Existing VLN methods model the varying perceptual requirements across navigation stages with identical visual tokens, leading to interference from irrelevant objects and background clutter. To this end, we therefore formulate long-horizon aerial navigation as a frequencypreference shift from spatial structure to local detail and propose FreqNav, a lightweight frequency-routing adaptive perception framework. Under a fixed computational budget, FreqNav dynamically reallocates visual tokens across frequency components according to the current navigation stage. A Frequency Token Router selects stage-relevant visual representations from dual-view observations, while a Phase-dependent Grounding Module anchors visual evidence through explicit supervision. A Diffusion Transformer then predicts smooth trajectories for continuous control. Experiments show that FreqNav outperforms strong baselines while achieving approximately 3x faster inference. Real-world deployment further demonstrates its effectiveness, efficiency, and practical potential for long-horizon aerial autonomy.

## 1. 论文的核心问题与整体含义

- **任务背景**：面向目标的空中视觉语言导航（Object-Oriented Aerial VLN）要求无人机（UAV）在长时程（long-horizon）、闭环控制条件下，根据自然语言指令自主搜索目标并精确着陆。该能力在城市搜救、物流配送、自动巡检等场景中具有重要应用价值。
- **核心矛盾**：导航过程中感知优先级会随阶段动态变化——早期目标不可见时，需要以低频全局空间布局为主进行探索；后期目标可见时，需要转向高频局部细节以实现精确对准和着陆。然而，现有空中VLN方法（如CMA、TravelUAV-DA、NavFoM、LongFly、AeroVLA等）普遍采用**静态统一视觉令牌分配**，用完全相同的方式处理所有导航阶段，导致无关物体和背景杂波对感知造成干扰。
- **核心洞察**：作者将长时程空中导航形式化为一个**频率偏好转移（frequency-preference shift）**过程——从早期"全局空间结构推理"过渡到后期"局部目标细节锚定"，并据此提出动态频率路由的感知新范式。

## 2. 论文提出的方法论

### 2.1 核心思想

FreqNav在**固定计算预算**下，根据当前导航阶段动态地在不同频率分量间重新分配视觉令牌——保留低频场景核心（core），同时为目标条件证据库（evidence bank）分配自适应令牌，从而获得信息密度更高的视觉表示，并提升推理效率。

### 2.2 模型总览

整体以Qwen2.5-VL（3B）为骨干，包含三个核心模块：

**① Frequency Token Router（频率令牌路由器）** ：

- **特征空间频谱分解**：对前视/下视双视角的特征网格（非原始像素）做二维DCT变换，在频域保留通道维度（式2）。
- **固定低频核心**：通过低通裁剪重建每视角的空间特征，得到前视核心与下视核心，保留全局语义。
- **自适应频带库**：定义三个重叠频谱掩码（low: r≤2, mid: 2≤r≤4, high: r≥4），与两个视角组合成6个候选频带库（B^v,b），分别承载粗布局、物体尺度结构、局部边界/纹理级证据。
- **目标条件离散路由**：将目标描述文本嵌入直接映射为6维logits，用Gumbel-Softmax（straight-through估计器）实现端到端可微的离散路由选择（式6），最终路由令牌拼接为 [前视核心, 下视核心, 自适应选择库]（式7）。

**② Phase-dependent Grounding（阶段相关接地模块）** ：

- 在路由令牌后追加128个可学习接地查询（排列为16×8网格并注入二维位置编码），经VLM深层自注意力交互后输出查询状态 Q_t（式8）。
- 辅助热力图解码器将查询状态映射为2D空间热力图，监督目标为3步后的专家航点（hg=3），显式迫使查询定位未来航点，将阶段选择的视觉证据蒸馏为具体空间表示。

**③ DiT-based Action Generation（DiT动作生成）** ：

- 采用Flow Matching框架，以扩散Transformer（DiT）参数化，从高斯噪声出发沿线性概率路径（式9）生成连续航点块 ⟨dx, dy, dyaw⟩ 及停止概率。
- 训练分两阶段：第一阶段用LoRA微调Qwen骨干进行多模态感知；第二阶段冻结VLM，训练DiT控制器。
- 推理时16步Euler求解，采用单步重规划（K=1）策略避免误差累积。

## 6. 论文的主要结论与发现

- **性能领先**：FreqNav在Seen集取得SR 51.55%（+3.59 vs AeroVLA）、SPL 41.67%（+3.13）；Unseen Object集SR 57.23%、OSR 70.75%、SPL 47.00%全部最优；Unseen Map集SR 39.04%、SPL 30.50%最优。Hard轨迹上的提升幅度最大（Seen Hard：SR+7.40、SPL+5.88），印证了频率路由在"长距离搜索+精确终端接近"组合场景下的独特价值。
- **效率显著提升**：将128个标准视觉令牌压缩至50个路由令牌（压缩61%），推理速度提升约3倍，且效果反而优于未压缩基线——说明3D导航环境的视觉特征存在大量空间冗余。
- **频率路由有效性的直接证据**：10/50路由方案优于50/50方案（过多自适应令牌引入环境噪声，导致注意力分散），支持"稀疏、高信息密度表示更适合目标条件决策"的假设。
- **设计选择的最优性**：单步航点（K=1）优于多步块预测（K=2/3），因为拓扑节点间的状态转换代表显著视点变化，多步块预测加剧协变量偏移；接地地平线hg=3最优（过长导致过度平滑/查询表示同质化）。
- **实际可用性**：真实部署下VLM推理延迟0.17s/step，全链路重规划0.5s/step，显著小于物理飞行执行时间，满足闭环导航的实时性要求。

## 7. 优点

- **问题建模视角新颖**：首次将空中VLN显式建模为"频率偏好转移"过程，从信号处理角度统一了"搜索"与"到达"两个导航阶段的感知差异，概念清晰且可解释性强。

- **模块化验证充分**：消融实验揭示了各个设计变量的非平凡最优解（不是越大越好/越多越好），提供了具有指导意义的设计洞察。
