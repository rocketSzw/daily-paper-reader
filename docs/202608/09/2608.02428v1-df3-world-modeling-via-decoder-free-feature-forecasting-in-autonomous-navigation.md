## 摘要
从视频序列预测未来状态是自主机器人系统面临的关键挑战，也是世界建模的基本目标。先前的基于像素级别的生成方法不可避免地过度强调任务无关的细节，导致计算开销过大。虽然基于潜在空间的方法试图通过直接预测特征来缓解这一问题，但在状态到任务映射中持续依赖重型解码器仍是计算瓶颈。在这项工作中，我们提出了无解码器特征预测（DF$^3$），一种全新的框架，完全在潜在空间内建模世界演变并直接导出任务输出，彻底消除了对解码器的需求。具体而言，DF$^3$将可学习的空间查询注入冻结的视觉基础模型的末端模块，直接提取未来状态表示。通过采用一种轻量级、统一的运动感知上下文融合（MACF）机制，将粗粒度流扭曲与细粒度潜在互相关无缝集成，这些查询与历史令牌表示交互，以显式对齐并预测下一帧的特征。随后，一组专门的任务查询探测这些预测特征以完成下游任务。在公共基准上的广泛实验以及在机器人模拟器中的零样本部署表明，DF$^3$在实现与最先进方法相当性能的同时，为集成感知与控制提供了优异的效率和灵活性。

## Abstract
Forecasting future states from video sequences is a critical challenge for autonomous robotic systems and a fundamental objective of world modeling. Prior generative methods operating at the pixel level inevitably overemphasize task-irrelevant details, leading to prohibitive computational overhead. While latent-based approaches attempt to mitigate this by predicting features directly, the persistent reliance on heavy decoders for state-to-task mapping remains a computational bottleneck. In this work, we propose Decoder-Free Feature Forecasting (DF$^3$), a novel framework that models world evolution entirely within the latent space and directly derives task outputs, completely eliminating the need for a decoder. Specifically, DF$^3$ injects learnable spatial queries into the terminal blocks of a frozen vision foundation model to extract future state representations directly. By employing a lightweight, unified Motion-Aware Context Fusion (MACF) mechanism that seamlessly integrates coarse flow warping with fine-grained latent cross-correlation, these queries interact with historical token representations to explicitly align and forecast the feature of the next frame. Subsequently, a specialized set of task queries probes these forecasted features for the downstream task. Extensive experiments on public benchmarks and zero-shot deployment in a robotic simulator demonstrate that DF$^3$ achieves performance comparable to state-of-the-art methods while offering superior efficiency and flexibility for integrated perception and control.

## 2. 论文提出的方法论

- **核心思想**：提出 **DF³（Decoder-Free Feature Forecasting）** 框架，在冻结的视觉基础模型（基于DINOv3的ViT）内部，通过注入可学习查询实现未来特征的预测及下游任务的直接输出，全流程不依赖任何解码器。
- **整体流程（DF³ Pipeline）**：
  1. 以历史帧序列 $\{I_1,...,I_T\}$ 作为输入，通过冻结的ViT编码器（分为早期层 $L_1$ 和末端层 $L_2$）。
  2. 取早期层 $L_1$ 的中间特征（包含patch tokens和prefix tokens）作为上下文表示 $F_{L_1}$。
  3. 将一组可学习的**预测查询（prediction queries）** $Q_{pred}$ 直接注入末端ViT块 $L_2$，与上下文特征拼接后经自注意力交互，输出对应未来帧的中间特征。
  4. 由**运动感知上下文融合（MACF）** 模块对预测查询进行进一步精炼，得到最终预测特征 $\hat{F}_{L_1}(I_{T+1})$。
  5. 对下游任务，注入**任务查询（task queries）** $Q_{task}$ 至相同末端块，与预测特征交互，经轻量MLP头输出任务结果（如语义分割的掩码与类别logits）。
- **结构化查询注意力**：在注入查询的ViT块中应用非对称注意力掩码——上下文token之间可自由互相注意，但禁止回看预测查询；预测查询可关注所有token。这种因果设计防止信息泄漏，保证上下文表征不被查询污染。
- **MACF（Motion-Aware Context Fusion）机制**：由两条并行分支融合而成：
  - **光流变形分支（Warp）**：由预测查询经MLP预测稠密潜在光流场 $\Delta p$，据此将最近历史帧的特征图 $f_{L_1}^{patch}(I_T)$ 变形为粗略对齐的未来特征 $\tilde{f}_{warp}$，再与当前查询状态求差获得更新方向。
  - **潜在互相关分支（Xcorr）**：在相邻两历史帧特征之间计算局部窗口内的软匹配（cosine similarity）获得历史语义运动速度 $V_{hist}$（当前特征与匹配的上一帧特征的差），再经MLP投影为运动注入信息。
  - **动态融合**：将两分支信息拼接后经MLP融合，由学习到的sigmoid门控机制 $G$ 动态调制残差，叠加到初始查询上得到最终预测。全局prefix tokens则由轻量时间外推器预测。
- **训练目标**：纯特征级监督，不依赖解码器联合训练。对预测特征与真实冻结编码器特征计算**余弦相似度损失**（对齐方向）+ **Huber损失**（稳定幅度），兼顾patch和prefix tokens。

## 8. 不足与局限

- **精度差距**：相比DINO-Foresight仍有约2个mIoU的精度差距，中期预测差距略大；MO-mIoU在中期下降明显（56.5 vs 57.6），表明动态目标预测精度有待提升。
