## 摘要
通过传统强化学习开发可部署的运动策略通常需要复杂的奖励设计和昂贵的训练时间。虽然可微分模拟提供了一种高效的替代方案，但能够将这些策略端到端迁移到物理硬件的开源工具仍然有限。本文介绍了Open-DiffLoco，一个利用可微分模拟训练可部署盲态四足运动策略的开源框架。该框架在MuJoCo XLA (MJX)中实现了短视界演员-评论家（SHAC）算法，并训练了一个可迁移到真实硬件上的本体感觉策略。部署的策略移除了特权演员观测，包括机体线速度，并且不依赖参考轨迹。它还使用了大幅简化的奖励函数，使机器人能够在没有传统强化学习流程中通常使用的复杂辅助奖励的情况下发现行走模式。当部署在物理硬件（宇树Go2四足机器人）上时，训练好的策略能够跟踪全向速度指令，均方根误差低于0.2 m/s，速度可达1 m/s以上，并且对不平坦地形和外部物理干扰（如侧向推力）保持鲁棒性。在报告的所有配置中，训练在单块NVIDIA GeForce RTX 5080 GPU上使用低于6 GB的显存，并在约20-60分钟内完成。作为SHAC的算法扩展，我们提出了雅可比增强值估计（JAVE），它监督评论家的雅可比矩阵，以改进早期的一阶策略梯度训练。据我们所知，Open-DiffLoco是首个使用可微分模拟训练可部署运动策略的开源框架。部署视频和源代码可在以下网址获取：https://diffloco.martin-opat.com/

## Abstract
Developing deployable locomotion policies through conventional reinforcement learning often requires complex reward engineering and expensive training times. While differentiable simulation offers a highly efficient alternative, open-source tools capable of end-to-end transfer of these policies to physical hardware remain limited. This paper introduces Open-DiffLoco, an open-source framework for training deployable blind quadruped locomotion policies with differentiable simulation. The framework implements the Short-Horizon Actor-Critic (SHAC) algorithm in MuJoCo XLA (MJX) and trains a proprioceptive policy that transfers to real-world hardware. The deployed policy removes privileged actor observations, including base linear velocity, and does not rely on reference trajectories. It also uses a substantially simplified reward function, enabling the robot to discover walking patterns without the complex auxiliary rewards typically used in conventional reinforcement learning pipelines. When deployed on physical hardware (a Unitree Go2 quadruped), the trained policy tracks omnidirectional velocity commands with root-mean-square error below 0.2 m/s, reaches speeds above 1 m/s, and remains robust to uneven terrain and external physical disturbances, such as lateral pushes. Across the reported configurations, training uses under 6 GB of VRAM on a single NVIDIA GeForce RTX 5080 GPU and completes in approximately 20-60 minutes. As an algorithmic extension to SHAC, we propose Jacobian-Augmented Value Estimation (JAVE), which supervises the critic Jacobians to improve early first-order policy-gradient training. To our knowledge, Open-DiffLoco is the first open-source framework for training deployable locomotion policies using differentiable simulation. Deployment videos and source code are available at: https://diffloco.martin-opat.com/

- **研究动机**：传统强化学习（如 PPO）训练四足机器人运动策略依赖模型无关（model-free）方法，将模拟器视为黑盒，使用零阶梯度（ZoG）估计，存在样本效率低、训练时间长、奖励工程复杂的问题。可微分模拟（Differentiable Simulation）将模拟器视为玻璃盒，通过反向传播环境动力学计算一阶梯度（FoG），理论上可获得高信息量的梯度，大幅提高样本效率。
- **核心痛点**：尽管可微分模拟潜力巨大，但当前相关最优方法多依赖封闭源码或自定义框架，社区难以复现与使用；同时可微分模拟在接触丰富的场景中面临数值不稳定性，且奖励函数必须严格可微，这限制了常规 RL 中已验证的复杂奖励（如步态奖励）直接迁移。
- **整体意义**：本文提出 **Open-DiffLoco** —— 据作者所述，这是**首个**使用可微分模拟训练**可部署**运动策略的开源框架，填补了可微分模拟从训练到真实硬件部署之间的空白。该框架在主流模拟生态 MuJoCo XLA（MJX）中实现 SHAC 算法，训练出可直接部署到 Unitree Go2 四足机器人的盲态（blind）运动策略，并以极低的算力成本验证了可微分模拟在真实世界部署中的可行性。

### 2. 方法论：核心思想、关键技术细节

- **核心思想**：用一阶梯度（FoG）替代零阶梯度进行策略优化，在短视界（short-horizon）内通过反向传播穿越模拟器动力学获得密集且低方差的梯度信号，从而绕过 PPO 等算法所需的复杂辅助奖励工程；同时通过简化奖励、移除特权观测、免参考轨迹，使训练得到的策略可直接部署到真实硬件。
- **框架设计**：整体系统模块化，由 YAML 配置入口、核心学习模块、环境模块、硬件部署模块组成。训练算法（SHAC / JAVE）与网络结构（MLP）可互换，策略可用自定义 C++ / ROS2 栈部署到真实机器人。
- **奖励设计**：仅使用极简的**可微**奖励项（见下表），包括速度跟踪、高度保持、竖直速度惩罚、躯干直立、关节偏差、动作率、动作幅度、角速度惩罚等。作者明确表示，利用这些基础奖励在相同设定下使用 PPO（MuJoCo Playground）无法成功收敛，表明可微分模拟的一阶梯度能够"免费"提供传统 RL 中需要辅助奖励才能获得的学习信号。

| 奖励项 | 表达式 |
|---|---|
| 前向速度跟踪 | −(vx − vcmd_x)² |
| 侧向速度跟踪 | −(vy − vcmd_y)² |
| 偏航角速率跟踪 | −(ωz − ωcmd_z)² |
| 高度保持 | exp(−10(h − 0.3)²) |
| 竖直速度惩罚 | −0.5vz² |
| 躯干直立 | 0.5(−gz) |

| 横滚/俯仰角速度 | −0.05(ωx² + ωy²) |

- **观测空间**：部署策略移除特权观测（如机体线速度），仅依赖本体感觉（proprioception），无需部署时的速度估计器。
- **SHAC 算法**：短视界演员-评论家（Short-Horizon Actor-Critic）算法，截断可微 rollout 至短视界 h，以学习到的值函数 Vϕ 替代剩余回报，缓解长视界反向传播的数值不稳定性。
- **JAVE 扩展（Jacobian-Augmented Value Estimation）**：针对 SHAC 的一个核心问题——即使值函数 Vϕ 逐点精确，其局部雅可比误差仍可能偏置 actor 梯度（论文附录 II 给出严格证明：L2 有界值误差无法约束梯度误差）。JAVE 通过**监督 critic 雅可比矩阵**，在 TD 损失基础上增加 Bellman 梯度损失，使 critic 的局部几何形状更准确。梯度目标通过一个学习的动力学模型 Fψ 估计观测空间转移来构造，从而提升早期策略梯度训练稳定性，并允许使用更长的分析视界。

### 6. 论文的主要结论与发现

- **可微分模拟 + 极简奖励即可训练可部署策略**：SHAC 在仅有约 10 项可微基础奖励、无参考轨迹的条件下即可自主发现稳定步态（如小跑、疾驰），而 PPO 在相同奖励条件下无法收敛，说明一阶梯度有效弥补了奖励稀疏性与梯度方差问题。
- **移除特权观测不影响部署性能**：策略仅依赖本体感觉（无线性速度观测），仍能在真实环境中实现良好速度跟踪与抗扰。
- **JAVE 的有效性**：JAVE 通过监督 critic 雅可比提升了早期训练稳定性与梯度质量，允许使用更长的分析视界（h=32 vs h=16），但最终性能提升不是决定性的。
- **训练成本极低**：单张 RTX 5080、低于 6 GB 显存、约 20–60 分钟训练时间，远低于传统 RL 的典型训练成本，使可微分模拟训练具有高度可及性。
- **真实部署可行性**：在 Unitree Go2 上验证了速度跟踪 RMSE < 0.2 m/s、最高速度 > 1 m/s、对不平地形及侧推干扰的鲁棒性。

### 7. 优点

- **开源贡献突出**：首个可微分模拟训练可部署运动策略的开源框架，代码、配置、部署栈全部公开，破解了此前该类工作闭源的困境。
- **模块化设计**：YAML 配置驱动，算法、网络、环境可替换，便于迁移到其他机器人平台。
- **极简奖励 + 无特权观测 + 无参考轨迹**：大幅降低奖励工程成本，策略更接近真实部署条件，自主发现步态，展示出可微分学习的范式优势。
- **训练资源门槛极低**：单 GPU、< 6 GB 显存、20–60 分钟即可完成，为算力有限的实验室/开发者提供了现实可用的工具。
- **算法创新（JAVE）**：对 SHAC 的 critic 学习进行了理论驱动的改进，且附有严格的数学证明（L2 值误差无法约束梯度误差）和启发式分析。
- **理论与实践完整闭环**：覆盖算法推导、仿真评估、真实硬件部署、开源发布，全链路清晰且可复现。

### 8. 不足与局限

- **训练速度的墙钟时间仍不理想**：尽管样本效率比 PPO 高约 100 倍，但 FoG 方法每步计算成本更高，整体墙钟训练时间仍不如高度优化的 RSL-RL 等成熟框架，工程落地效率受限。
- **高速运动仍是瓶颈**：超过 2 m/s 的训练存在困难，真实世界高速部署尚未完全实现；实验中的快速剖面呈现明显性能平台期（最大速度约 2 m/s）。
- **步态切换未研究**：虽然该框架能发现不同步态，但显式的步态间转换机制尚未纳入实验范围。
- **JAVE 改进有限**：其优势主要体现在训练早期和梯度稳定性上，对最终策略性能的提升不显著；Bellman 梯度算子的收缩条件（收敛性保证）尚未从理论上确立，当前实现仅采用完全冻结动作端点（η=0）。
- **隐式地形模型局限**：使用倾斜重力与接触缩放脚力模拟地形，而非真实网格地形，无法反映地面几何变化引起的复杂接触动力学；对"盲态"策略而言虽合理，但限制了对不平地形的评估深度。
- **真实实验定量维度偏少**：仅报告速度跟踪 RMSE，缺乏抗扰定量指标、不同控制频率下表现、长时间运行稳定性等分析；对手动命令输入的依赖性（ROS2 可选）也增加了可复现性难度。
