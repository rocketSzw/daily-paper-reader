## 摘要
在扰动驱动的目标运动下，多旋翼飞行器的自主空中对接构成了一项受约束的非线性轨迹优化挑战。本工作将对接任务表述为基于降阶非线性模型并附加扰动状态的有限时域最优控制问题。所得问题在滚动时域框架内采用序列凸规划求解，以生成动态可行的对接轨迹。结合带噪声测量的状态估计以实现鲁棒的相对运动预测，并在高保真刚体MuJoCo仿真环境中验证轨迹执行。所提框架针对静止和匀速目标运动进行评估，表明在满足几何捕获约束的同时能够可靠收敛到对接接口。定量地，该方法将对接锥违规和终端状态误差保持在规定容差内，并在锥半角低至10度时实现一致、安全的对接性能。在风速扰动标准差高达0.5的情况下仍能鲁棒运行，同时保持有界接近速度和稳定的控制输入。这些结果证明了基于SCP的轨迹优化框架在估计不确定性下对扰动鲁棒空中对接的有效性。

## Abstract
Autonomous mid-air docking of multi-rotor vehicles under disturbance-driven target motion poses a constrained non-linear trajectory optimization challenge. This work formulates the docking task as a finite-horizon optimal control problem based on a reduced-order nonlinear model augmented with disturbance states. The resulting problem is solved using sequential convex programming within a receding-horizon framework to generate dynamically feasible docking trajectories. State estimation with noisy measurements is incorporated to enable robust relative motion prediction, while trajectory execution is validated in a high-fidelity rigid-body MuJoCo simulation environment. The proposed framework is evaluated for stationary and constant-velocity target motions, demonstrating reliable convergence to the docking interface while satisfying geometric capture constraints. Quantitatively, the method maintains negligible docking-cone violations and terminal state errors within prescribed tolerances, and achieves consistent, safe docking performance for cone half-angles as low as 10 degrees. Robust operation is observed for wind disturbance levels up to a standard deviation of 0.5, while preserving bounded approach velocities and stable control effort. These results demonstrate the effectiveness of the SCP-based trajectory optimization framework for disturbance-robust aerial docking under estimation uncertainty.

## 1. 核心问题与整体含义

- **研究动机**：多旋翼无人机在空中完成自主对接（drone-to-drone docking）是协同无人机系统的关键能力，但在实际环境中面临目标运动受扰动、动力学欠驱动、气动干扰、传感噪声以及严格运动学/动力学约束等多重挑战。
- **核心问题**：当目标无人机非静止且受到扰动漂移时，如何在有限时域内生成满足几何捕获约束、避障约束和物理可行性约束的对接轨迹，是一个非线性约束轨迹优化问题。
- **研究意义**：论文将该问题建模为有限时域最优控制问题，并利用序列凸规划（SCP）在滚动时域内求解，从而在保证实时性的同时处理非线性动力学和非凸约束，为空中对接提供了一种鲁棒且可扩展的优化框架。

## 2. 方法论

### 总体思路
- 采用“两阶段”对接范式：先进行远距离拦截与对准，再进入满足几何对接锥约束的受限接近阶段。
- 将非线性最优控制问题通过 SCP 迭代凸化为一系列二阶锥规划（SOCP）子问题，并在滚动时域（receding horizon）内重规划。

### 系统建模
- 使用 **降阶非线性模型** 进行轨迹优化，状态包括位置、速度、滚转角、俯仰角和推力加速度，并将外部风扰动作为附加状态估计。
- 控制输入为滚转角指令、俯仰角指令和推力指令。
- 动力学方程描述了推力矢量与平移运动的主导耦合关系，并引入一阶执行器时间常数；忽略偏航动力学，适用于小相对偏航角场景。
- 在每个 SCP 迭代中，对非线性动力学进行线性化，并用前向欧拉离散化；同时引入虚拟控制项保证凸子问题可行性。

### 状态估计
- 针对目标无人机，采用离散卡尔曼滤波器（基于常速度模型）从带噪声位置测量中估计目标位置和速度。
- 滤波后的目标状态在预测时域内前向传播，为 SCP 提供目标的相对运动预测。

### SCP-NMPC 公式
- **代价函数**：最小化位置/速度/姿态误差、控制能量、虚拟控制惩罚和对接锥松弛惩罚，并设置终端代价促进捕获。
- **信任域与虚拟控制**：限制每次迭代状态与控制相对名义轨迹的偏差；虚拟控制保证线性化误差下的可行性。
- **约束条件**：
  - 执行器限制：滚转角、俯仰角限幅，推力上下限；
  - 飞行包线：最大平移速度；
  - 对接锥约束：通过相对位置和对接轴方向凸化为二阶锥约束；
  - 碰撞避免：利用凸包体之间的符号距离约束避撞，对静态障碍采用线性化超平面约束；
  - 终端成功捕获条件：相对距离和速度分别小于设定容差。

### 控制架构
- 外层：NMPC/SCP 生成低频滚转、俯仰、推力指令；
- 内层：高频 PD 控制器跟踪姿态指令，实现完整刚体动力学仿真闭环。

## 6. 主要结论与发现

- 所提出的 SCP-NMPC 框架能够在静止目标和匀速移动目标两种场景下生成动态可行的对接轨迹，并在 MuJoCo 高保真仿真中成功完成对接。
- 对接锥违规极小，终端状态误差在预设容差内；在半锥角低至 \(10^\circ\) 时仍能保持稳定、安全的对接性能。
- 风扰动标准差 \(\sigma \le 0.5\) 时，系统保持鲁棒，对接时间合理，控制能量有界；当 \(\sigma\) 增大到 0.8 以上时，任务在有限预测时域内无法完成，对接锥约束和终端收敛条件反复被违反。
- 增大对接锥角可放宽接近约束，从而缩短对接时间。
- 整体结论：SCP 结合滚动时域优化适合作为空中对接的实时轨迹规划方法，对目标漂移和传感不确定性具有较好的鲁棒性。
