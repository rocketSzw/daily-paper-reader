## 摘要
无人机视觉语言导航（UAV-VLN）要求智能体遵循语言指令，从稀疏的多视角观测中推断空间结构，并在复杂的室外环境中执行可行的三维运动。尽管近期大规模语言模型取得了进展，但大多数现有方法仍直接将视觉语言输入映射到动作，提供的显式场景接地和未来感知空间推理有限。我们提出AirForesight，一种用于UAV-VLN的当前到未来空间地图想象框架。AirForesight首先从多视角观测中学习结构化当前地图表示。该表示通过当前地图重建和未来轨迹预测联合监督，鼓励其同时编码当前场景结构和未来运动意图。在结构化因果注意力下，当前空间知识被传播到未来地图推理，并将产生的当前和未来表示聚合以预测下一个三维路点。为使空间想象与导航更相关，我们引入跨空间规划一致性损失，鼓励预测的地图空间轨迹与由真实路点位移导出的专家动作方向之间的一致性。在OpenUAV和AerialVLN-S上的实验以及大量消融研究证明了该框架的强性能，并支持其有效性和稳定性。

## Abstract
Unmanned Aerial Vehicle Vision-Language Navigation (UAV-VLN) requires agents to follow language instructions, infer spatial structure from sparse multi-view observations, and execute feasible 3D motion in complex outdoor environments. Despite recent progress with large language models, most existing methods still map vision-language inputs directly to actions, providing limited explicit scene grounding and future-aware spatial reasoning. We propose AirForesight, a current-to-future spatial map imagination framework for UAV-VLN. AirForesight first learns a structured current-map representation from multi-view observations. This representation is jointly supervised by current-map reconstruction and future-trajectory prediction, encouraging it to encode both present scene structure and future motion intent. Under structured causal attention, the current spatial knowledge is propagated to future-map reasoning, and the resulting current and future representations are aggregated to predict the next 3D waypoint. To make spatial imagination more relevant to navigation, we introduce a cross-space planning consistency loss that encourages directional agreement between the predicted map-space trajectory and the expert action direction derived from the ground-truth waypoint displacement. Experiments on OpenUAV and AerialVLN-S, together with extensive ablations, demonstrate strong performance and support the effectiveness and stability of the proposed framework.

- **现有方法不足**：
  - 早期方法依赖循环网络或跨模态注意力策略，近期方法引入大语言模型（LLM）/多模态大语言模型作为导航骨干，但仍普遍将语言指令和多视角观测直接映射为航点预测。
  - 缺乏显式的当前场景接地：没有把离散观测组织成结构化空间状态，智能体容易过度依赖短期视觉线索。

  - 空间想象与动作执行之间联系弱：即使引入中间空间预测，也常作为辅助目标优化，与下游动作生成的一致性不强。
- **论文目标**：提出 AirForesight，通过“当前地图 → 未来轨迹 → 未来地图 → 航点预测”的结构化空间想象流程，增强 UAV-VLN 的显式场景理解与前瞻性空间推理，并通过跨空间规划一致性损失，将地图空间推理与动作空间执行对齐。

## 2. 论文提出的方法论

### 2.1 核心思想
- 将导航决策建立在对当前场景结构显式编码的基础上，同时通过结构化因果注意力将当前空间知识传播到未来地图推理，最终聚合当前与未来空间表征预测下一个 3D 航点。
- 空间地图仅用于训练监督，不要求在线稠密地图构建，避免增加导航延迟。

### 2.2 整体架构与关键模块
- **多模态输入编码**：语言指令由文本分词器处理，多视角 RGB 图像经 EVA-CLIP 与 Q-Former 编码，每张图压缩为 17 个视觉 token（1 个全局上下文 token + 16 个局部内容 token），与文本 token 拼接成统一序列。
- **可学习查询 token**：引入三组 token：
  - `<cur_map>`：当前地图 token，共 9 个；
  - `<fut_map>`：未来地图 token，共 9 个；
  - `<waypoint>`：航点 token，1 个。
- **骨干网络**：使用 Vicuna-7B 作为 LLM 骨干，大部分参数冻结，仅训练视觉投影器、LoRA 参数、空间解码器、地图/轨迹头与航点解码器，属于参数高效配置。
- **当前空间地图建模（CSMM）**：
  - 当前地图 token 仅关注语言与视觉输入，得到潜在地图表示 `Z_cur_map`；
  - 轻量 MAE 解码器将其转为稠密空间特征 `F_cur`，由线性分类头生成当前语义地图；
  - 通过加权交叉熵损失 `L_cur_map` 监督；监督语义图由离线自动标注流程生成（LLM 提取语义类别 + GroundingDINO + MobileSAM 分割 + 深度反投影到无人机局部 2D 栅格）。
- **未来轨迹想象**：
  - 当前空间特征同时输入二值轨迹头，预测 n 步未来轨迹掩码；
  - 监督掩码由未来真实航点投影到当前地图平面得到；
  - 使用加权二值交叉熵损失 `L_traj` 监督，使当前地图表征同时编码场景结构与未来运动意图。
- **未来地图想象（FSI）**：
  - 未来地图 token 在结构化因果注意力下，关注多模态输入以及前面当前地图 token，得到未来地图表征；
  - 与当前地图共享 MAE 解码器和分类头，预测未来地图 `M_{t+n}`，用加权交叉熵损失 `L_fut_map` 监督。
- **结构化因果注意力**：
  - 当前地图 token → 只关注多模态输入；
  - 未来地图 token → 关注多模态输入 + 当前地图表征；
  - 航点 token → 关注多模态输入 + 当前地图 + 未来地图表征；
  - 同一组内的 token 互相掩码，鼓励提取互补信息。
- **航点预测**：
  - 航点 token 聚合上述所有表征，MLP 解码器输出归一化方向 `u_{t+1}` 与距离 `d_{t+1}`；
  - 导航损失为：`L_nav = |d_hat - d| + (1 - cos(u_hat, u))`；
  - 预测航点后，用 TravelUAV 的轻量路径解码器生成可执行的局部路径。
- **跨空间规划一致性损失（CPCL）**：
  - 从预测未来轨迹掩码的局部邻域中用 PCA 估计地图空间主方向 `v_map`；
  - 从真实航点位移投影到地图平面得到专家动作方向 `v_action`；
  - 用余弦距离 `L_cons = 1 - cosine(v_map, v_action)` 约束两者方向一致；
  - 避免直接将轨迹与预测航点对齐，从而防止早期训练中不成熟航点预测带来的误差传播。

### 2.3 优化目标
- 两阶段训练：
  - 第一阶段：仅优化 `L_nav`，建立基础航点预测能力；
  - 第二阶段：联合优化 `L_nav + λ_spatial(L_cur_map + L_traj + L_fut_map) + λ_cons L_cons`。

## 6. 论文的主要结论与发现

- AirForesight 通过显式学习当前地图、未来轨迹与未来地图，显著改善了 UAV-VLN 的导航性能，在 OpenUAV 和 AerialVLN-S 上均取得领先结果。
- 当前空间地图建模（CSMM）能有效提升场景接地，未来空间想象（FSI）补充未来运动与空间状态信息；二者结合更好地服务航点预测。
- 跨空间规划一致性损失（CPCL）是整体提升的关键，能有效减少地图空间轨迹与专家动作方向之间的不一致，进而提升 SR、OSR、SPL 并降低 NE。
- 结构化因果注意力实现了“当前→未来→航点”的信息单向流动，让未来地图推理基于当前空间知识，并让航点预测聚合两种空间表征。
- 地图 token 扰动实验表明，学习到的地图表征确实携带了可用的空间信息，并实际参与导航决策。
- 无需在线稠密地图构建，AirForesight 的推理延迟仅比 TravelUAV 高约 6.18%，远低于显式空间先验方法的额外开销。

## 7. 优点

- **创新性强**：将“当前地图重建 + 未来轨迹预测 + 未来地图想象 + 航点预测”组织为一种因果一致的空间想象流程，超出以往直接将视觉语言输入映射为动作的做法。
- **显式场景接地**：在训练时用伪标签语义地图监督当前/未来地图表征，使得模型具备结构化空间理解，而不是仅依赖隐式特征。
- **未来感知**：通过未来轨迹与未来地图的联合监督，模型能对运动后的环境状态进行推理，这比单纯预测局部第一视角更利于长程导航。
- **规划一致性设计合理**：CPCL 使用真实航点位移作为稳定专家方向参考，而不用不成熟的预测航点，避免早期训练误差传播，同时桥接地图空间与动作空间。
- **推理高效**：空间地图仅用于训练监督，不增加在线稠密重建负担，实际推理开销增加很小。
- **伪标签成本低**：离线标注总成本约 8.42 美元，且经人工抽检具有较高准确率。
- **实验清晰且充分**：多数据集、多难度、多消融、多随机种子、效率分析、定性可视化与扰动分析相互印证，结论可信度高。

## 8. 不足与局限

- **伪标签质量存在误差**：监督地图依赖自动标注流程，若语义类别提取、开放词汇检测与分割、深度观测或 3D→2D 投影有误，会传入训练；虽然平均准确率较高但并非完美。
- **CPCL 的 PCA 方向估计对轨迹形态敏感**：适合局部平滑轨迹，对急转弯、稀疏轨迹掩码或局部几何模糊的情况可能不够准确；未考虑更柔性的曲线对齐方法。
- **未来轨迹信息传递方式局限**：轨迹掩码不直接重新编码为未来地图分支输入，而是通过共享当前地图表征间接传播，可能限制了更细粒度的路径条件未来想象。
- **开放场景泛化仍不足**：在 Unseen Map / Unseen Object 上的性能明显下降，说明环境与语义偏移仍是挑战。
- **模型部分依赖视觉语言输入**：地图 token 并非唯一决策来源，扰动实验显示模型仍可从原始输入中保留一定导航能力，说明地图表征的“必要性”不完全彻底。
- **实验范围局限**：主要结论建立在仿真环境（Unreal Engine 4 + AirSim）中，未涉及真实无人机部署、真实传感器噪声、动态障碍物等；也未报告完整的训练时长与能耗信息。
- **潜在偏差**：伪标签由 LLM 与检测分割模型生成，可能受到预训练模型的类别偏见或场景先验影响；人工抽查样本量为 100 条轨迹，覆盖有限。
