## 摘要
零样本物体目标导航（ZSON）要求机器人在从未进入过的建筑中找到指定物体类别。主流方法使用视觉-语言价值图为前沿打分：每个决策都是对当前地图的又一次argmax，而该分数背后的证据在做出决策的那一刻就被丢弃。将大型视觉-语言模型置于感知-行动循环中的系统通常仅从当前视角按固定计划查询它；机器人几分钟前走过的房间永远不会被重新考虑，调用失败也没有明确的回退方案。我们将机器人已经看到的内容转化为深思熟虑的对象。我们的分层快慢智能体让价值图控制器每一步都持续运行，并在移动时写入坐标锚定记忆：一个由房间类型和已确认物体实例组成的语义网格，以及一个有界的带姿态标注关键帧存储。视觉语言模型（VLM）在写入之前筛选每个候选检测。一个深思熟虑层在有界的推理-检索-行动循环中读取该记忆。它由反应层计算出的结构事件唤醒，首先在文本上推理，并且只对仅靠文本无法区分的候选召回第一人称视图。每次调用和每次运行的上限约束了其调用次数，一个免调用的第一层解决了最常见的停滞，任何失败都会将控制权返回给反应式控制器。我们的系统在HM3D v1 val上达到68.75%的成功率（SR），在MP3D val上达到47.29%，是这里比较的零样本方法中最高的成功率。在所有2000个HM3D情节的配对比较中，通过argmax而非深思熟虑来选择远处前沿会损失3.40个SR点（95%置信区间[1.70, 5.05]）；而对每个前沿都进行深思熟虑并不能挽回这些损失。

## Abstract
Zero-shot object-goal navigation (ZSON) requires a robot to find a named object category in a building it has never entered. The prevailing approach scores frontiers with a vision--language \emph{value map}: every decision is another argmax over the map as it currently stands, and the evidence behind that score is discarded the moment it is taken. Systems that place a large vision--language model inside the perception--action loop typically query it on a fixed schedule from the current view alone; a room the robot walked through minutes earlier is never reconsidered, and a failed call has no defined fallback. We turn what the robot has already seen into the object of deliberation. Our hierarchical fast--slow agent leaves the value-map controller running at every step and writes a \emph{coordinate-anchored memory} as it moves: a semantic grid of room types and confirmed object instances, together with a bounded store of pose-tagged keyframes. A VLM screens each candidate detection before it is written. A deliberative layer reads this memory in a bounded reason--retrieve--act loop. It wakes on structural events the reactive layer computes, reasons first over text, and recalls a first-person view only for candidates that text alone cannot separate. Per-invocation and per-run caps bound its calls, a call-free first tier resolves the most frequent stall, and any failure returns control to the reactive controller. Our system reaches 68.75% SR on HM3D v1 \texttt{val} and 47.29% on MP3D \texttt{val}, the highest success rate among the zero-shot methods compared here. Choosing among far frontiers by argmax instead of deliberating costs 3.40 SR points in a paired comparison over all 2000 HM3D episodes (95\% CI [1.70, 5.05]); deliberating over every frontier does not recover them.

## 1. 论文的核心问题与整体含义

- **问题背景**：零样本物体目标导航（Zero-Shot Object-Goal Navigation, ZSON）要求机器人在从未进入过的室内建筑中，根据自然语言指定的物体类别（如“床”、“马桶”、“植物”）找到目标实例，且不能针对该类别进行任何专门训练。
- **现有方法的不足**：
  - 主流基于“视觉-语言价值图”（vision-language value map）的方法对每个前沿（frontier）打分，然后反复使用 argmax 选择下一步，决策所依据的证据在做出决策后立即被丢弃。
  - 引入大模型（LLM/VLM）的系统通常按固定时间表、仅基于当前视图进行查询，无法重新考虑机器人几分钟前经过的房间；调用失败时没有明确的回退机制。
  - 这些系统缺乏处理“结构性僵局”（如局部规划器被杂乱环境卡住、只剩远处前沿、前沿集合耗尽、目标在另一层楼）的能力。
- **整体含义**：论文主张把机器人已经看到的历史信息转化为“深思熟虑的对象”，通过分层“快慢”架构，让反应式控制器持续运行，同时在必要时让一个预算受限的深思层去重新审视坐标锚定的记忆（语义网格+关键帧），从而显著提升零样本导航成功率。

## 2. 论文提出的方法论

### 2.1 核心思想
- **分层快慢架构**：
  - **反应式控制器（Fast）**：始终运行，负责感知、建图、局部运动，基于 ASCENT（VLFM 家族）改进。
  - **深思熟虑控制器（Slow）**：仅在“结构性事件”触发时被唤醒，运行一个有界的“推理-检索-行动”（Reason–Retrieve–Act, 类似 ReAct）循环，产生类型化指令交给反应式控制器执行。
- **“快慢”分工**：深思只负责“重定向”机器人，而不是驱动每一步；反应式控制器始终掌握底层运动控制。

### 2.2 关键技术细节
- **坐标锚定记忆（Coordinate-Anchored Memory）**，包含两个层级：
  - **语义网格（Semantic Grid）**：粗粒度栅格（0.4m 单元），聚合 8×8 占据像素；每个单元存储：
    - 房间类型投票直方图（累积而非覆盖，抑制瞬时误分类）；
    - 覆盖该单元的视角关键帧索引环；
    - 稀疏物体实例表（类别、反投影世界坐标、观察次数、支撑关键帧）。
    - 物体实例被“确认”（可检索）的条件是至少被观察到两次，以抑制一次性误检。
  - **关键帧存储（Keyframe Store）**：有界、低分辨率的关键帧缩略图，按平移/旋转阈值采样，并附带姿态、楼层、步数、房间标签和可见物体；按楼层容量驱逐，避免新楼层覆盖旧楼层记忆。
  - **检索接口**：给定查询世界坐标，返回局部房间估计与置信度、附近已确认实例、覆盖统计、排序后的候选关键帧。图像召回遵循严格回退阶梯：精确足迹命中 → 宽松足迹搜索 → 前沿发现帧 → 空结果（继续纯文本）。检索从不中断控制。
- **检测验证门（Verification Gate）**：每个候选目标检测在融合进物体图（可授权停止的地图）之前，由 VLM 查看当前帧裁剪框+候选类别，给出接受/拒绝。拒绝的检测不会进入物体图，因此无法授权停止。
- **事件触发的深思熟虑（Event-Triggered Deliberation）**，共四类结构性僵局：
  1. **接触停滞（Contact stalls）**：基于滑动窗口内累计碰撞次数判断机器人被困。恢复采用分层策略：第一层（免调用）压制当前前沿目标并强制重新规划；若仍停滞，再用 VLM 从当前视图查询逃逸方向，执行动作宏，并可将之前失败方向作为显式负样本。
  2. **远处前沿（Distant frontiers）**：当最近前沿距离超过阈值 \(d_{\text{far}}\) 时触发。循环先用文本描述（房间估计、附近物体、目标与房间的固定知识图谱关联）让模型选择或要求图像；只有文本不能区分时，才检索最多两个候选的存储关键帧，进行第二轮图像调用。
  3. **前沿耗尽（Frontier exhaustion）**：当无前沿可用且未找到目标时，不直接停止，而是将当前楼层的关键帧均匀抽样成一张索引蒙太奇图，用单次图像调用询问是否有被忽略的通道（楼梯、门、开口）。识别出的视图姿态变成持久目标，并重新启用附近被抑制的探索目标。每楼层有调用上限。
  4. **楼层切换（Floor changes）**：当前楼层停滞且知道其他楼层时，用纯文本的每楼层摘要调用 VLM 决定是否切换楼层。
- **仲裁与预算控制**：
  - 单一仲裁器按固定优先级执行：恢复动作宏 > 楼梯状态机 > 目标检测/深思目标。
  - 深思目标“持久”，防止反应式控制器过早抢占。
  - 双重预算：单次调用最多 3 轮推理、单次最多 2 张图像；每次运行的模型调用上限为 20 次（其中图像调用最多 10 次）；另有每步看门狗（单次决策超过 180 秒则禁用模型调用）和熔断器（连续失败后禁用）。
  - 失败开放（fail-open）：任何失败路径（内存空、服务中断、解析失败、预算耗尽）都回到反应式控制器，确保机器人不会没有控制器。
- **关于触发策略的说明**：当“何时调用”“如何花费证据预算”“启用哪些记忆能力”被设计为三个可独立开关，分别对应实验中的消融。

## 5. 实验数量与充分性

- **主实验**：两个基准（HM3D v1 val、MP3D val）、七种方法对比。
- **消融实验**（五组，每组在同一 2000 个 HM3D 情节上测试）：
  1. **Greedy Frontier**：去掉“远处前沿深思”，改用 argmax 选择，SR 下降 3.40 点；
  2. **Always-Deliberate**：去掉触发策略，每个前沿选择都唤醒深思，SR 65.35% → 64.80%，反而低于 Greedy Frontier；
  3. **One-Shot**：保留触发但改为一次性提供所有图像（而非自适应检索），SR 下降 3.70 点；
  4. **w/o Semantic Grid**：去掉语义网格（只保留关键帧文字层），SR 下降 3.35 点；
  5. **w/o Rescan**：去掉“前沿耗尽重扫”功能，SR 下降 0.25 点。
- **统计显著性**：对 Greedy Frontier 差距给出配对 bootstrap 95% CI [1.70, 5.05] 和 McNemar 检验（χ²=15.06, p<0.001），其他差距也给出 CI。
- **针对性分析**：
  - 失败类别分解（假阳性、假阴性、无前沿、步数耗尽），用于归因各组件贡献；
  - Rescan 触发率 6.1%，其中 41.4% 从记忆视图产生新目标；
  - 验证门拒绝 16.7% 的候选检测。
- **评估充分性**：实验覆盖两个难易不同、规模不同的基准，消融设计精准地隔离了“触发策略”“证据获取方式”“记忆类型”“重扫”等设计维度，并使用统计检验，整体较为充分、客观和公平（所有方法在同一仿真协议下比较，同一 2000 情节用于消融）。

## 6. 论文的主要结论与发现

- 分层快慢架构显著优于纯反应式基线：HM3D SR 68.75%、MP3D SR 47.29%，均为对比方法中最高，且 SPL 也领先，说明成功不是靠走更远的路换来的。
- **深思熟虑的收益来自“何时调用”而非“调用多少”**：Always-Deliberate（每次都深思）的 SR 低于 Greedy Frontier（从不深思远处前沿），说明不必要的深思反而有害。
- **按需获取证据（自适应图像召回）很重要**：One-Shot（将所有图像一次性给模型）即使调用次数更少，仍然损失 3.70 SR 点，证明“只在文本无法区分时召回视图”能更有效地利用图像证据。
- **语义网格的抽象层不可替代**：w/o Semantic Grid 与完整系统调用次数几乎相同，却损失 3.35 点，且该损失主要来自“过早停止”（no-frontier）类失败，说明文本可推理的抽象记忆是图像记忆的必要补充。
- **验证门有效阻止错误检测进入最终物体图**。
- **记忆中的历史观察是有价值的证据**：系统能把“几分钟前路过但没细看的区域”重新召回并据此决策。
- **失败开放（fail-open）和预算控制是实际可部署性的关键**。

## 7. 优点

- **架构设计新颖且合理**：把 ReAct 循环放在反应式控制器之下，而非替代它；慢速系统只在结构性僵局时介入，避免每步调用大模型，显著降低计算开销。
- **记忆设计具有层次性**：“语义网格（文本/抽象）+ 关键帧（图像/具体）”共享坐标框架，支持先文本后图像的证据获取策略，兼顾效率与信息量。
- **严格的预算与失败管理**：模型调用按单次和全程双重上限约束，所有失败路径明确回到反应式基座，系统鲁棒性高。
- **触发条件来自反应层已有计算**，无需额外感知，工程上易于实现。
- **检测验证门前置**，防止错误检测被融合成不可撤销的地图内容，设计富有洞见。
- **消融实验设计精细**，能清楚区分三个相互缠绕的因素（触发策略、证据获取方式、记忆内容），并给出统计置信区间。
