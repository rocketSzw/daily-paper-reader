## 摘要
空中视觉语言导航（VLN）要求具身智能体随时间整合视觉证据、规划未来动作，并在部分可观测条件下判断是否已到达导航目标。尽管最近的VLA模型提供了一种有前景的感知到动作的范式，但由于历史上下文有限、规划时域短以及隐式终止不可靠，将其适应于空中导航仍然具有挑战性。为应对这些挑战，我们提出了DreamFly，一种基于Dream-VLA的扩散式空中VLN框架。DreamFly引入了因果对齐的历史记忆，仅利用当前决策步骤之前的观测来增强当前视觉表示，从而在不泄露未来信息的情况下实现时间推理。我们进一步将导航表述为后退时域扩散规划，其中策略预测一个K步动作块，但仅执行第一个动作后重新规划。这种“规划K步、执行一步”的策略将未来动作作为辅助规划目标，同时保持闭环视觉反馈。最后，LiteStop直接从初始全掩码状态下的动作logits估计停止概率，将显式终止与动作生成解耦。在OpenFly基准上的实验表明，在已见和未见环境中均有持续改进。DreamFly在test-seen/test-unseen划分上分别达到32.04%/29.46%的SR和28.22%/23.54%的SPL，在两项指标上均优于所有对比方法，同时实现了最低导航误差。这些结果证明了联合建模历史上下文、未来动作结构和显式终止对于空中VLN的有效性。

## Abstract
Aerial vision-language navigation (VLN) requires an embodied agent to integrate visual evidence over time, plan future actions, and determine when it has reached a navigation goal under partial observability. Although recent VLA models offer a promising perception-to-action paradigm, adapting them to aerial navigation remains challenging due to limited historical context, short planning horizons, and unreliable implicit termination. To address these challenges, we propose DreamFly, a diffusion-based aerial VLN framework built on Dream-VLA. DreamFly introduces a causally aligned historical memory that augments the current visual representation using only observations preceding the current decision step, enabling temporal reasoning without future information leakage. We further formulate navigation as receding-horizon diffusion planning, where the policy predicts a $K$-step action chunk but executes only the first action before replanning. This plan-$K$, execute-one strategy uses future actions as auxiliary planning targets while preserving closed-loop visual feedback. Finally, LiteStop estimates the stop probability directly from action logits at the initial all-mask state, decoupling explicit termination from action generation. Experiments on the OpenFly benchmark demonstrate consistent improvements in seen and unseen environments. DreamFly achieves 32.04%/29.46% SR and 28.22%/23.54% SPL on the test-seen/test-unseen splits, respectively, outperforming all compared methods on both metrics while attaining the lowest navigation error. These results demonstrate the effectiveness of jointly modeling historical context, future action structure, and explicit termination for aerial VLN.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- 空中视觉语言导航（Aerial VLN）要求无人机（UAV）在大型 3D 环境中，依据自然语言指令和依序获取的自我中心图像，自主导航至目标位置。与地面 VLN 相比，空中 VLN 具有以下特点：
  - 无人机需同时协调水平位移、垂直运动与视角调整，高度变化会同时影响视野范围、地标尺度、可见细节和障碍可见性。
  - 城市空中环境尺度大、遮挡严重，单帧观测仅覆盖局部场景，局部决策误差容易随时间累积。
  - 导航过程本质上是部分可观测、闭环的序列决策问题：当前动作影响后续状态，新观测又反向更新对任务进度和空间方位的估计。
- 尽管近期 Vision-Language-Action（VLA）模型为“感知到动作”的端到端控制提供了新范式，但直接将其应用到空中 VLN 仍面临三个关键挑战：
  1. **历史信息不足**：策略若主要依赖当前观测，会丢失先前出现的关键地标信息；现有记忆方法虽关注“保留什么历史信息”，却未明确刻画“信息何时进入历史分支”的因果时间边界。
  2. **规划视界短**：单步动作预测缺乏前瞻性；虽然动作分块（action chunking）能捕获短期动作结构，但如何在保持闭环重规划的同时利用未来动作间的依赖关系，仍未得到充分探索。
  3. **终止判定隐式且不可靠**：将“停止”视为普通动作与运动动作一同生成，难以处理过早停止与过晚停止的不对称风险。过早停止会不可逆地结束导航，造成严重后果。
- 论文因此提出 **DreamFly**，在 Dream-VLA 扩散策略骨干上，联合显式建模“历史上下文、未来动作结构、终止判定”，形成时间一致的闭环决策过程，以提升空中 VLN 在已见与未见环境中的性能。

## 2. 论文提出的方法论

### 2.1 核心思想

DreamFly 将空中 VLN 视为观测→记忆检索→扩散规划→终止评估→执行→记忆更新的因果闭环循环。其三个核心模块相互配合：

- **因果对齐历史记忆（Causally Aligned Historical Memory）**：为历史记忆设立严格时间边界，只允许当前决策步之前的观测进入历史分支。
- **后退时域扩散规划（Receding-Horizon Diffusion Planning）**：用扩散模型联合预测 K 步离散动作块，但只执行第一步，随后基于新观测重新规划。
- **LiteStop 解耦终止模块**：从初始全掩码状态的动作 logits 中直接估计停止概率，不依赖动作生成过程。

### 2.2 因果对齐历史记忆

- **时间边界定义**：决策步 t 的历史记忆为 \(M_{<t} = F_{mem}(I, \{O_\tau\}_{\tau<t})\)，即仅包含之前观测的信息。采用“先读后写”协议：生成动作时读入 \(M_{<t}\)，当前观测 \(O_t\) 的信息只能在后续决策步写入记忆。
- **候选构建**：使用冻结的 CLIPSeg 稠密路由器和 OWLv2 区域路由器，从指令相关区域提取视觉候选；OWLv2 区域特征被映射到 CLIPSeg 视觉特征空间。
- **长时记忆更新**：通过活动轨迹累积跨观测证据；满足条件时通过“持续提升”或“单观测提升”进入 16 个长时记忆槽。每个槽包含锚点特征、原型特征（可选）、原型存在标志和距上次更新的时间信息。
- **记忆条件化视觉表示**：
  - 当前图像 tokens \(Z_t\) 作为查询，记忆槽嵌入作为键/值，做带有效槽掩码的多头交叉注意力，得到检索到的历史上下文 \(C_t\)。
  - 通过门控残差连接将 \(C_t\) 融入当前视觉 tokens：\(\tilde{Z}_t = Z_t + M_{img} \odot G_t \odot (C_t W_O)\)，其中门控项和输出投影零初始化，保证初始为恒等映射。
- **因果一致性**：训练与部署使用相同的记忆构建机制和因果可见边界；训练使用专家轨迹的前缀记忆，部署使用在线逐步累积的记忆，两者状态可能不同，但因果约束一致。

### 2.3 后退时域扩散规划

- **离散动作分块**：预测长度为 K 的动作块 \(\hat{a}_t=[\hat{a}_t^0,\dots,\hat{a}_t^{K-1}]\)，其中第一个为当前动作，其余为未来动作。未来动作仅作为辅助规划目标，不承诺连续执行。
- **训练目标**：
  - 使用有效前缀监督：轨迹末尾不足 K 步时，以 Stop 填充但由有效掩码 \(v_{t,h}\) 排除填充位置的损失。
  - 采用确定性几何核（geometric kernel）计算上下文权重 \(c_{t,h}\)，降低非关键上下文 token 的影响。
  - 采用水平衰减权重 \(\gamma^h\)（\(\gamma<1\)），强调近期动作。
  - 损失在完整词汇表上计算交叉熵，但对所有动作槽位置进行掩码，一次前向同时预测所有槽位。
- **扩散生成**：推理时从全 [MASK] 状态开始，进行 S 步迭代离散扩散；每步按单调 origin 采样器概率将掩码转移为动作 token；转移时抑制非动作 token 的 logits，保证输出为合法动作。生成完整动作块后才进行终止评估。
- **后退时域执行**：生成完整动作块后，若 LiteStop 未触发，则执行第一个动作 \(\hat{a}_t^0\)；若为 Stop 则终止；否则执行运动并获得新观测，再重新规划完整动作块。其余未来动作被丢弃，不缓存执行——保持闭环反馈。

### 2.4 LiteStop：解耦终止控制

- **表示**：复用初始全掩码前向的动作 logits 网格 \(H_t^{(0)} \in \mathbb{R}^{K\times |A|}\)（所有 K 个动作位置、所有合法动作类别），将其向量化后经 LayerNorm 和两层 MLP，得到停止概率 \(p_t^{stop}=\sigma(W_2 SiLU(W_1 LN(vec(H_t^{(0)}))) + b_1 + b_2)\)。
- **训练**：以专家动作是否为 Stop 作为二元标签（未来位置或填充的 Stop 不参与），使用带正类权重 \(\lambda_+=4.0\) 的二元交叉熵损失。训练时冻结完整导航策略，仅训练 LiteStop 参数。
- **推理终止决策**：\(d_t^{term}=d_t^{stop} \lor \mathbb{I}[\hat{a}_t^0 = a_{stop}]\)，即 LiteStop 触发或动作级 Stop 均会终止；LiteStop 在完整扩散生成之后、执行任何动作之前评估，并非提前退出机制。

## 3. 实验设计

### 3.1 数据集与 Benchmark

- **数据集**：基于 OpenFly 数据集。预处理包括修正 Forward 6m 的动作编码、重映射约 19 万步非标准动作标签、移除预打包的历史关键帧、仅保留当前 RGB 观测。训练集含 20 个子集、85,785 条轨迹、1,356,622 个决策步。
- **评估环境**：test-seen 包含 UE BigCity 和 6 个 AirSim 城市环境（共 1,392 条轨迹）；test-unseen 包含 UE SmallCity（404 条轨迹）。
- **评价指标**：导航误差（NE，越低越好）、成功率（SR）、预言成功率（OSR）、路径加权成功率（SPL，越高越好）。

### 3.2 对比方法

- Random：均匀随机采样动作。
- Action Sampling：按训练集动作分布采样（强随机基线）。
- Seq2Seq：经典序列到序列策略。
- CMA：跨模态匹配模型。
- AerialVLN：空中 VLN 专用方法。
- OpenFly-Agent：直接评估官方发布 checkpoint（以避免训练流程不一致带来的差异）。
- 其余学习型基线使用相同的处理后训练数据、相同的优化步数训练，确保公平比较。

### 3.3 主要结果

- DreamFly 在 test-seen 上取得 NE 44.87m、SR 32.04%、OSR 46.77%、SPL 28.22%；在 test-unseen 上取得 NE 45.29m、SR 29.46%、OSR 46.78%、SPL 23.54%。
- 在 SR 和 SPL 上全面超越所有对比方法，同时 NE 最低；随机与动作采样基线虽存在非零成功率，但论文通过“初始距离是否在成功半径内”的条件成功率分析指出，其高成功率主要来自有利的初始位置，并非真正的目标导向导航。

### 3.4 消融实验

- 渐进式消融：从 Dream-VLA 基线开始，依次加入因果记忆、后退时域规划、LiteStop，性能逐步提升。
- 留一消融：去除记忆（w/o Memory）、去除动作块（w/o Chunk）、去除 LiteStop（w/o LiteStop）均导致性能下降。
- 距离分组分析：按初始最短路径距离将轨迹分为近、中、远三组，分析各组件贡献：LiteStop 在近距离组贡献最大（终止决策更关键）；记忆在中距离贡献突出；记忆与动作块在远距离互补。

### 3.5 定性分析

- 展示了三个代表性轨迹：去掉记忆后导航误差由 10.9m 恶化至 43.5m；去掉动作块后误差由 2.2m 恶化至 58.1m；去掉 LiteStop 后模型进入目标区域后漂移、最终误差 23.0m，而未去除的变体在 12.5m 处成功停止。

## 6. 主要结论与发现

1. **因果对齐的历史记忆有效**：仅使用当前步之前的观测构建历史，配合门控交叉注意力融合，可显著提升导航成功率，且不会泄露未来信息。
2. **后退时域扩散规划有效**：预测 K 步动作块但只执行一步，使未来动作作为辅助规划目标，同时保持闭环重规划能力，改善了动作一致性。
3. **显式终止判定必要**：LiteStop 从初始全掩码 logits 中独立估计停止概率，能有效防止进入目标区域后继续漂移，从而提升 SR 并降低 NE。
4. **联合建模优于单一改进**：三个组件互补，联合使用时达到最佳性能；距离分组分析显示各组件在不同导航阶段承担不同功能。
5. **泛化性验证**：在 test-unseen 环境上同样取得最优 SR 和 SPL，证明模型具备一定的跨环境泛化能力。

  - 因果记忆采用“先读后写”协议，在训练和部署中均保持一致的时间可见性，概念清晰。
  - 后退时域规划兼顾了动作分块的前瞻性和闭环反馈，避免开环执行的错误累积。
  - LiteStop 与主策略解耦，不修改动作策略，训练时冻结骨干网络，降低了训练复杂度和干扰。
- **实验设计细致**：
  - 对比了随机基线和动作分布采样基线，并通过初始距离条件成功率揭示其“假成功”的本质，体现了对基线的深刻批判性分析。
  - 消融实验覆盖增量和减量双视角，结论更可靠。
  - 距离分组分析增强了组件作用的解释性。
- **定性分析扎实**：三个示例分别对应三个组件的失败模式，直观展示了各自的贡献。

## 8. 不足与局限

- **实验覆盖有限**：仅在 OpenFly 单一基准上评估，未在多数据集上验证；未报告 std/多随机种子结果，统计显著性未知。
- **实际应用限制**：目前仅在仿真环境验证，尚未部署到物理 UAV；论文自身也承认了这一点，未来需检验传感噪声、环境扰动、sim-to-real 域迁移下的鲁棒性。
- **基线与公平性风险**：OpenFly-Agent 直接使用官方 checkpoint，而其他基线使用处理后数据重新训练，两者数据协议可能不完全一致；尽管论文有意避免复现差异，但仍有隐含的不公平风险。
- **LiteStop 阈值选择依赖校准集**：阈值通过一个较小的 64 轨迹校准集来选择，可能对该集合敏感，且不同环境的最优阈值可能不同；论文未提供阈值敏感性分析。
- **记忆构建过程复杂**：依赖 CLIPSeg 和 OWLv2 两个冻结模型，且包含活动轨迹、提升规则等较多手工设计；训练与部署的记忆状态可能因分布差异（专家 vs 策略）而出现不一致，虽然因果约束一致，但记忆内容质量可能受到影响。
- **计算开销未透明报告**：未说明算力资源，也未比较推理延迟或内存开销；12 步扩散 + 完整动作块生成可能带来额外延迟，对实时 UAV 控制可能构成挑战。
- **语言指令利用深度有限**：记忆构建和动作预测虽使用指令，但未显式建模指令的细粒度子目标分解，对复杂长指令的解析能力可能受限。
