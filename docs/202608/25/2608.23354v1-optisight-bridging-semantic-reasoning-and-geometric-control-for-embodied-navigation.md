## 摘要
自主室内导航需要语义理解和精确的几何控制。我们提出了OptiSight，一种混合框架，通过有限状态思维链架构将视觉语言模型推理与确定性视觉伺服相结合。Grounded-SAM定位开放词汇目标，而相机投影几何将视觉观察转换为导航命令，无需密集建图。VLM仅在关键决策点被查询，减少了计算开销，而几何控制处理连续导航。在AI Habitat中的实验表明，在各种室内场景中，包括避障和语义歧义，都能实现可靠的零样本导航，同时内存占用在8GB VRAM以内。源代码可在 https://github.com/avanalperen/OptiSight-Python-Multimodal-CoT-for-Visual-Reasoning 获取。

## Abstract
Autonomous indoor navigation requires both semantic understanding and precise geometric control. We propose OptiSight, a hybrid framework that combines Vision-Language Model reasoning with deterministic visual servoing through a finite-state Chain-of-Thought architecture. Grounded-SAM localizes open-vocabulary targets, while camera projection geometry converts visual observations into navigation commands without requiring dense mapping. The VLM is queried only at key decision points, reducing computational overhead while geometric control handles continuous navigation. Experiments in AI Habitat demonstrate reliable zero-shot navigation across diverse indoor scenarios, including obstacle avoidance and semantic ambiguity, while operating within an 8~GB VRAM budget. The source code is available at https://github.com/avanalperen/OptiSight-Python-Multimodal-CoT-for-Visual-Reasoning.

- 自主室内导航（如无人机、机器人在室内场景中的移动）本质上要求系统**同时具备高层语义理解能力**（识别目标物体、理解指令、应对歧义）与**低层精确几何控制能力**（避障、对准目标、规划连续运动轨迹）。

## 2. 论文提出的方法论

**核心思想**
- 构建一个 **有限状态思维链（Finite-State Chain-of-Thought, CoT）混合架构**，将导航过程分解为“语义推理”与“几何控制”两个层次的协同：
  1. **语义推理层**：仅在遇到需要语义理解的关键决策点（例如“当前看到的是什么？”“目标在哪里？”“下一步该往哪个方向探索？”）时，才调用视觉语言模型进行推理。
  2. **几何控制层**：在常规导航与连续运动阶段，交由确定性的视觉伺服（Visual Servoing）和相机投影几何处理，从而避免高频调用大模型，显著降低计算开销。

**关键技术细节**
- **开放词汇目标定位（Grounded-SAM）**：使用 Grounding-SAM 模型对图像中用户以自然语言描述的目标进行开放词汇检测与分割，从而在无需预定义类别列表的情况下识别和定位导航目标。
- **无稠密建图的导航命令生成**：目标确定后，利用**相机投影几何（Camera Projection Geometry）** 将二维图像坐标中的目标位置转换到相机/机器人坐标系，并直接用确定性几何公式计算转向角、前进距离等底层控制命令，无需构建任何稠密地图。
- **VLM 按需查询机制**：VLM 并非每帧都被调用，而是被一个有限状态机（Finite-State Machine）触发，只在关键决策点（如场景切换、目标丢失、出现语义歧义或需要解释当前状况）时被“唤醒”。这种方式将 VLM 的高成本推理限制在最少的必要次数，几何控制则全程接管连续运动。
- **算法流程（文字描述）**：
  1. 系统接收自然语言导航指令，VLM 对指令进行语义理解并提取目标描述。
  2. 若目标已在当前视野内，则用 Grounded-SAM 进行目标定位，获得图像中的坐标边界框。
  3. 利用相机内参和投影几何，将目标图像坐标转换为机器人本体坐标系中的相对位置，计算转向与前进指令。
  4. 若目标不在视野内，则由 VLM 推理决定“探索方向”（例如向左侧走廊移动），随后系统进入几何控制模式执行该决策。
  5. 在此过程中持续进行避障检测，遇到障碍或语义歧义时再次唤醒 VLM 进行重新决策，随后继续循环，直至到达目标位置。
