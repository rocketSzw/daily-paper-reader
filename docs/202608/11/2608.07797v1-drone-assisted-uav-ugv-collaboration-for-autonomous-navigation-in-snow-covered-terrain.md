## 摘要
本文提出了一种用于高海拔积雪地形的UAV-UGV协作导航框架，在该环境中，能见度降低和地面不稳定使得传统方法失效。我们引入了一种自定义的高效U-Net架构，在实时道路分割的计算约束下工作，利用一种新颖的合成雪数据增强技术实现了96.5%的分割精度。对于无人机定位，我们实现了扩展卡尔曼滤波器（EKF），融合机载GPS和IMU数据，最大观测位置误差为±0.5米。无人车的位置通过使用YOLOv5和来自无人机RGB-D相机的深度数据的视觉跟踪管道确定。一种动态路径规划算法利用该分割结果来适应雪堆漂移，使得在遮蔽测试环境中以最小偏差实现成功导航。

## Abstract
This paper presents a collaborative UAV-UGV navigation framework for high-altitude, snow-covered terrain, where reduced visibility and unstable ground render conventional methods ineffective. We introduce a custom efficient U-Net architecture that falls under the computational constraints for real-time road segmentation, utilizing a novel synthetic snow data augmentation technique to achieve 96.5% segmentation accuracy. For UAV localization, we implement an Extended Kalman Filter (EKF) fusing onboard GPS and IMU data, achieving a maximum observed positional error of +-0.5 meters. The UGV position is determined via a visual tracking pipeline using YOLOv5 and depth data from the UAV's RGB-D camera. A dynamic path planning algorithm utilizes this segmentation to adjust for snow drifts, enabling successful navigation in obscured test environment with minimal deviation.

## 1. 核心问题与研究动机

- **背景**：高海拔积雪环境（冰冻圈）是野外机器人领域最具挑战性的场景之一。极端温度、恶劣天气以及积雪覆盖导致传统视觉感知和运动控制系统大规模失效。
- **核心矛盾**：积雪的“漂白效应”使道路边界、车道标线等导航线索几乎完全消失；高反照率造成相机过曝，传感器无法区分平坦雪地与深雪坑；LiDAR在降雪中会产生“体噪声”，将雪花误判为障碍物。
- **具体问题**：地面车辆在深雪中行驶时车轮滑移严重，轮式里程计失效，车辆容易偏离既定路径。传统方案（重型有人机械、人工遥控）后勤复杂且对操作员构成重大安全风险。
- **研究价值**：随着北极地区军事后勤、边境巡逻、灾害搜救等自主操作需求增长，亟需一种能在视觉缺失和机械失稳条件下工作的导航系统。
- **核心假设**：通过将感知（UAV）与运动执行（UGV）解耦，利用无人机的高空正射视角将复杂的三维感知问题简化为二维航拍映射问题，从而规避地面视角下积雪障碍难以辨识的几何局限，提升整体系统的生存能力。

## 2. 方法论与关键技术

### 2.1 系统架构总览

系统由三个紧密耦合的子系统构成，核心设计原则是**感知与执行的完全解耦**：

- **空中感知节点（UAV）**：承担全部环境感知与计算任务，搭载RGB-D相机、IMU、GPS，采用边缘计算方案在机载运行分割和SLAM算法。
- **地面执行节点（UGV）**：刻意设计为“无传感器”平台——不搭载任何环境感知或定位传感器，完全依赖无人机下发的轨迹指令进行导航。
- **通信桥接**：基于ROS中间件，无人机通过ROS话题实时发布UGV的位置与速度信息，实现消息队列式的协作。

### 2.2 道路语义分割（自定义U-Net）

- 针对低对比度场景，采用自定义U-Net架构：五级编码器-解码器结构，通道数从64递增至1024，卷积层配以批归一化和ReLU激活，跳跃连接恢复空间细节。
- 输入为归一化RGB图像，输出道路/非道路二元分割掩码。

**数据增强策略（核心亮点）**：
- 训练集仅**95张图像**，使用Albumentations库进行几何增强：随机旋转（±60°）、水平/垂直翻转。
- 引入**合成雪注入增强**：向训练图像中人为添加模拟雪景效果，这是应对标注数据匮乏的关键策略。

**训练配置**：Adam优化器，动态学习率从2×10⁻³衰减至5×10⁻⁷；二元交叉熵损失函数；训练10,000轮。

### 2.3 多模态建图（RTAB-Map）

- 采用RTAB-Map图优化SLAM算法，将U-Net生成的道路掩码投影到深度点云上，构建带语义标签的占据栅格图（可通行道路/障碍物/未探索区）。
- 使用**前沿探索算法**自动识别未知-已知边界，生成飞行指令，实现未知区域覆盖。

### 2.4 UAV定位（扩展卡尔曼滤波）

- 构建**15维运动学状态向量**（位置、姿态及其一阶和二阶导数），融合100Hz IMU数据与GPS绝对位置更新，确保平滑无漂移的飞行状态估计。
- 值得注意：选择EKF而非UKF，前者在计算效率上更契合无人机机载资源约束。

### 2.5 UGV视觉追踪（YOLOv5 + 深度信息）

- 无人机通过YOLOv5s模型从RGB视频流中检测UGV（mAP@0.5达到0.989），利用相机内参和深度梯度计算UGV相对于无人机的精确三维位姿及偏航角。
- 附录给出完整的基于深度的UGV位姿提取算法流程（含图像裁剪、ROI归一化、形态学处理、PCA椭圆拟合求朝向角）。

### 2.6 自适应路径规划与控制

- **全局规划**：采用Timed Elastic Band（TEB）规划器，将轨迹视为受障碍物排斥力、目标吸引力和AGV运动学约束共同作用下的弹性带，优化生成考虑最小转弯半径的路径。
- **局部规划**：集成Open Motion Planning Library（OMPL），使用Reeds-Shepp曲线生成曲率连续的平滑运动基元，降低打滑风险。
- **动态适应**：无人机实时分割检测到新的雪堆或道路可通行性变化后，立即更新代价地图，路径规划器随之在线重算最优轨迹，实现“自适应雪堆规避”。
- **底层控制**：采用Pure Pursuit控制器追踪路径，通过追逐前瞻点计算转向角，保证在光滑界面上的稳定平滑控制。
