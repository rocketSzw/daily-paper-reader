## 摘要
通用机器人策略旨在将多模态观测和语言任务指令映射到跨多样任务的动作。然而，现有方法通常将未来表示为固定的、短期的视频-动作块。这种短期未来捕捉了用于动作执行的局部场景演化，但它并未明确描述指定任务应如何从当前阶段过渡到下一阶段的分阶段语义未来。因此，我们区分了机器人操作中两种互补的未来：用于捕捉局部场景演化的短期物理未来和用于表示任务进度的分阶段语义未来。我们引入了JEPA-WAM，它通过Stage-JEPA（一种以目标为条件的联合嵌入预测架构（JEPA）预测器）增强了基于Motus的世界动作模型（WAM）。给定当前观测和任务指令，Stage-JEPA使用冻结的V-JEPA2编码器提取当前状态表示，并预测下一推断阶段的潜在目标。在干净和随机化环境中的50个RoboTwin 2.0任务中，JEPA-WAM实现了90.25%的总体成功率，并将成功执行中平均执行步数相对于最强基线减少了5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce JEPA-WAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, JEPA-WAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

## 1. 核心问题与整体含义（研究动机和背景）

- 现有通用机器人策略（VLA、WAM）通常将“未来”建模为**固定长度的短期视频-动作块**，只能描述局部场景的短期演化，如物体运动、接触、局部视觉变化。
- 该类方法缺少对**任务阶段级语义未来**的显式建模：即“任务应从当前阶段推进到下一个有意义的对象状态或关系状态”，例如物体空间对齐、归属关系转移、抓取-放置的进度。
- 作者认为，直接预测远处目标图像也不合适，因为像素级预测会偏重外观而忽视任务完成；因此提出用 JEPA（联合嵌入预测架构）在表征空间中预测下一阶段的潜在目标。
- 整体思路：将机器人未来建模拆分为两个互补尺度：
  - **短期物理未来**：局部视频动作演化，交给世界动作模型（WAM）。
  - **分阶段语义未来**：任务进度目标，交给 Stage-JEPA。
- 论文提出 **JEPA-WAM**，在 Motus WAM 基础上加入 Stage-JEPA，用预测的下一阶段潜在表示指导短期视频预测与动作生成。

## 2. 方法论核心思想与关键技术细节

### 核心思想

- 给定当前观测 `o_t` 和任务指令 `l`，Stage-JEPA 预测下一阶段目标潜在表示 `Y_stage_t`；
- 将该预测作为内部条件注入 WAM，WAM 再预测短期视觉未来 `V_short_t` 和动作块 `A_t`。
- 形式化：  
  - 经典 WAM：`p(V_short_t, A_t | o_t, s_t, l)`  
  - JEPA-WAM：`p(V_short_t, A_t | o_t, s_t, l, Y_stage_t)`，其中 `Y_stage_t = f_θ(o_t, l)`

### 两阶段训练

- **Stage I：训练 JEPA 预测器**
  - 自动构建阶段监督对，无需人工阶段标签：
    - 在轨迹中每隔 8 帧采样候选中心，用冻结的 V-JEPA2 编码 64 帧片段；
    - 通过片段级与 token 级表示变化打分，再经时间 NMS（半径 r=3，最多 5 个）选出关键帧；
    - 关键帧连同首末帧构成阶段边界，每个当前帧 `t` 与其下一边界 `b_{i+1}` 构成稠密训练对。
  - 使用冻结 V-JEPA2 编码器提取当前与目标片段的潜在表示；
  - 可训练的目标条件 JEPA 预测器（+指令适配器）预测下一阶段 token，池化后与目标表示做**余弦相似度损失**：
    - `L_stage = 1/B Σ (1 - (ẑ_target)^T z_target)`
  - 只优化预测器和指令适配器，编码器冻结。

- **Stage II：训练阶段条件化的 WAM**
  - WAM 基于 Motus，采用 Mixture-of-Transformers：视频生成专家、动作专家、视觉语言理解专家，三者通过 Tri-modal Joint Attention 交互。
  - 将冻结的 Stage-JEPA 输出注入视频流：
    - `h_t = P_ψ(Pool(Ẑ_target_t))`
    - `α = 0.2σ(β)`，为一个全局有界标量门控
    - `Ẍ_vt = X_vt + α h_t`
  - 训练损失为视频损失 + 动作损失 + 门控正则：
    - `L_reg = λ_g α² + λ_ρ(ρ - ρ₀)²`，其中 `ρ = ||αh_t|| / ||X_vt||`
  - 推理时：维护因果 64 帧观测缓冲（不足时重复最早帧），Stage-JEPA 预测阶段目标，WAM 生成视频未来和动作块，闭环执行、再规划。

## 3. 实验设计

### 数据集与 Benchmark

- 使用 **RoboTwin 2.0** 双臂操作仿真 benchmark，覆盖 50 个任务。

- 另有**真实机器人 LIFT2（ARX R5）平台**验证，包含 Cube_Grasp 和 Power_Strip 两个任务，采用 0-100 任务进度评分，每任务 20 次评估。

## 6. 主要结论与发现

- JEPA-WAM 在 50 个 RoboTwin 任务上：
  - 干净环境成功率 **91.42%**；
  - 随机化环境成功率 **89.08%**；
  - 总体平均成功率 **90.25%**；
  - 相对最强基线 Motus，干净环境提升 2.76 个百分点，随机化环境提升 2.06 个百分点。
- 在七类语义任务中，干净环境 5/7 类超过 Motus，随机化环境 6/7 类超过 Motus。
- 提升最明显的是**交接、目标放置、容器打包、排列堆叠、工具使用**等需要显式任务阶段转换的任务。
- 对单纯依赖抓取几何和接触稳定的“抓取-提升”类任务，提升有限；对需要精确接触、受限运动和精确时机的“机构交互”任务，阶段信号间接注入仍不充分。
- 消融实验表明：
  - 去除 JEPA 分支降幅最大，说明阶段条件路径提供了短时 WAM 之外的有用信息；
  - 不注入未来潜在而只改变当前观测表示，效果下降，说明“未来目标注入视频流”很重要；
  - 不做 Stage-I 训练仍具竞争力，说明预训练 V-JEPA2 预测器自带有用的视觉结构，但阶段对训练可进一步提升。
- 执行效率：
  - 所有 rollout 平均 episode 长度从 156.28 降至 132.80，降 15.02%；
  - 仅在成功 rollout 中，平均长度从 79.57 降至 74.82，降 **5.97%**；
  - 说明阶段指导能减少冗余纠正动作，使策略更直接地推进任务。
- 真实机器人 LIFT2 上，JEPA-WAM 平均任务进度分 48.00，优于 π0.5 的 41.50。

## 7. 优点

- **概念创新**：清晰区分“短期物理未来”与“阶段级语义未来”，弥补了现有 VLA/WAM 对任务进度建模不足的空白。
- **方法务实**：使用 JEPA 潜在预测而非像素预测，避免外观干扰，适合任务语义层面的目标表示。
- **训练无需人工标注**：通过冻结 V-JEPA2 表示变化的启发式自动推断阶段边界，具有可扩展性。
- **模块化设计**：Stage-JEPA 与 WAM 解耦，可移植到其他具有视觉条件流的 WAM。
- **消融全面**：能清楚证明各组件贡献，特别是“未来潜在注入”设计优于仅作用于当前观测。
- **结果扎实**：50 任务大范围仿真 + 真实机器人验证，且报告执行效率指标，验证了实用价值。
- **门控注入设计**：全局有界标量门控 + 比例正则，控制阶段信号对视频 token 的干预强度，比较稳定。

## 8. 不足与局限

- **基准/对比范围有限**：主要对比 Motus 及少数 VLA，未与最新阶段引导方法（如 VISTA、WorldDP、StaKe 等）直接比较。
- **仿真环境的普遍性受限**：机器人平台为 RoboTwin 双机械臂仿真，未在更多物理仿真器或大规模真实多任务场景中验证。
- **真实实验规模小**：LIFT2 仅 2 个任务、每任务 20 次评估，统计显著性不足，且评分方案较粗。
- **部分任务反而表现倒退**：
  - 如 `Put Object Cabinet` 随机化情况下明显低于 Motus（54% vs 71%）；
  - `Scan Object` 随机化下 52% vs 66%；
  - 部分任务提升微弱或持平。
- **短期未来作为未来目标有结构前提**：V-JEPA2 需要 64 帧输入，推理时不足需 padding；阶段边界和切片存在跨阶段/重叠，Stage-I 目标是“时间上下文式”表征而非严格外推。
- **对精密操作和力控任务帮助有限**：阶段信号是间接条件注入，不能提供接触力、受限运动、精确时序信息，在“关节/设备交互”类任务上优势不明显。
- **阶段自动检测依赖启发式**：基于 V-JEPA2 特征变化的 NMS 关键帧选择可能受演示质量影响，且缺少人工语义对齐验证。
