## 摘要
我们提出了一种用于无人机的实时语义导航框架，旨在提高目标导航任务的时间效率。我们方法的核心是一个大型语言模型，它解释用户提供的自然语言指令，并对检测到的物体和空间上下文进行语义推理，以优先考虑高概率的搜索区域。该系统结合了实时物体检测、三维空间映射和多项式样条插值，以实现平滑且可行的无人机轨迹规划。与依赖离线推理或受模拟器限制的动作空间的先前方法不同，我们的框架可以实时运行，基于新观察不断更新语义相关性。在模拟和实际环境中的实验表明，在保持高搜索精度的同时减少了任务持续时间，突显了LLM引导推理在实现高效的基于无人机的目标导航中的有效性。

## Abstract
We present a real-time semantic navigation framework for Unmanned Aerial Vehicles (UAVs) focused on improving time efficiency in the Object Goal Navigation (ObjectNav) task. Central to our approach is a Large Language Model (LLM) that interprets user-provided natural language instructions and performs semantic reasoning over detected objects and spatial context to prioritize high-probability search regions. The system combines real-time object detection, 3D spatial mapping, and polynomial spline interpolation for smooth and feasible UAV trajectory planning. Unlike prior methods that rely on offline reasoning or simulator-constrained action spaces, our framework can operate in real time, continuously updating semantic relevance based on new observations. Experiments in both simulated and real-world settings demonstrate reductions in mission duration while maintaining high search accuracy, underscoring the effectiveness of LLM-guided reasoning for time- efficient UAV-based ObjectNav.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：利用 LLM 作为语义推理引擎，根据用户指令和实时检测到的物体及其 3D 位置，动态评估每一个候选物体附近出现目标物体的概率，优先引导无人机飞向高概率区域进行细致搜索，从而避免全局遍历扫描。

- **四阶段流程**：
  1. **环境体素表示**：使用 OctoMap 构建三维占据网格，将空间划分为自由空间 \(S_{free}\)、占据空间 \(S_{occ}\)、未知空间 \(S_{unk}\)，用于导航和物体 3D 定位。
  2. **物体检测与语义接地**：
     - 视觉感知模块 \(VP(I_k)\)：用 YOLO11 对图像帧做 2D 物体检测，输出边界框、类别和置信度。
     - 3D 位置估计模块 \(PE(o_k, S_{occ})\)：利用相机内参将物体像素坐标转换为 3D 方向向量，再从无人机当前位姿向 OctoMap 做光线投射，得到第一个占据体素即为物体位置。
     - 对多次观测进行 DBSCAN 聚类，合并同一物体的重复检测，得到不一致的物体集合 \(O\)。
  3. **LLM 引导的决策逻辑**：
     - 概率相关模块 \(PR(O,T,D) \rightarrow O^*\)：计算每个物体 \(O_i\) 的后验概率 \(P(O_i|D,T) \propto P(D|O_i,T) \cdot P(O_i|T)\)，其中 \(P(O_i|T)\) 表示语义先验（基于共现常识），\(P(D|O_i,T)\) 表示观测数据似然。
     - LLM 根据系统提示、用户指令、检测到的物体及其 3D 坐标、已访问区域等信息，输出三个内容：Flag（是否存在超过阈值的相关物体）、Most relevant（最优物体及其坐标，即 \(O^*\)）、Explanation（推理解释）。
     - 决策规则：若最高概率低于最小阈值，则执行默认扫描策略（如沿墙飞行）以收集更多数据；若超过阈值，则围绕 \(O^*\) 进行细致搜索；若期间某个物体概率超过高阈值，则认为目标已找到，停止搜索；若细致搜索未找到目标，则更新知识 \(D\)，降低该物体概率，重新分配概率到其他物体。
  4. **轨迹规划与细致搜索**：
     - 先使用 A* 算法在 3D 空间规划离散路径到达相关物体附近。
     - 再用 7 阶多项式样条插值生成平滑、可动态飞行的连续轨迹。
     - 细致搜索轨迹为绕相关物体的圆形（或受限于障碍物的半圆形）轨迹，固定半径和高度，并剔除与障碍物相交的航点，确保无人机从多角度观察，提高遮挡物体的检出率。

- **系统整体输入输出可表示为**：\(PR(PE(VP(I_k), S_{occ}), T, D) \rightarrow O^*\)。

## 6. 论文的主要结论与发现

- LLM 引导的语义搜索相比传统全局扫描，**显著缩短任务时间和飞行路径**：

- 系统能够处理**部分遮挡**目标，细致搜索环绕轨迹提高了检出率。
- 使用**轻量级 YOLO + LLM** 的组合可实现实时语义推理，避免 VLM 的计算开销，并成功在**真实无人机**上运行。

## 7. 优点：方法或实验设计上有哪些亮点

- **实时性强**：与依赖离线推理或 VLM 的方法不同，本框架支持机载（或低延迟外置）实时推理，后续 LLM 推理与飞行并行，不增加总搜索时间。
- **零样本泛化**：无需针对任务训练，LLM 起到语义常识引擎的作用，可适应新物体类别和未见环境。
- **轻量高效**：避免使用计算密集的 VLM，仅用 YOLO 检测 + LLM 推理，兼顾语义丰富度和实时性。
- **考虑真实物理约束**：采用 A* + 7 阶多项式样条生成平滑可飞轨迹，而非离散动作空间，更适合 UAV 应用。
- **模块化设计**：视觉感知、空间表示、3D 定位、概率推理、轨迹规划解耦，便于替换或升级单个组件（如换用 LiDAR 或其他检测器）。
- **实验设计公平性**：STI/PLR 仅在双方成功试验上计算，减少偏差；随机起点设置提高了统计严谨性。
