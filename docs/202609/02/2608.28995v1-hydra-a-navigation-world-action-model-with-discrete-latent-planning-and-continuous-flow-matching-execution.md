## 摘要
世界模型使机器人能够想象可能的未来，但利用这一能力进行实时控制却受到表示错位的制约：生成模型与规划器在解耦流形上运行，因此规划器缺乏可搜索的共享结构，而必须将每个候选解码回高维像素空间进行评估。这一解码步骤成为物理硬件实时控制的主要障碍。本文提出Hydra，一种离散世界动作模型，通过将规划器（包括采样器与评估器）纳入模型内部来弥合这一差距。Hydra在视觉状态、物理位姿与控制动作之上建立统一的潜在流形，并通过模态特定的向量量化瓶颈将该流形压缩为运动动力学意图与视觉状态的离散词汇表。由于候选现在直接从这个共享流形中抽取，采样由模型自身对观测的理解所引导，而非盲目提出，并且评估在离散空间内原生完成：候选根据运动学-感知代价排序，无需解码到像素。我们将此称为离散潜在规划（DLP）。由于仅对离散意图进行规划无法提供物理驱动所需的平滑连续指令，Hydra将DLP与条件流匹配相结合，将每个选定意图映射为用于执行的连续轨迹。在两个物理机器人平台上评估时，Hydra在目标导向规划方面优于最先进的世界模型，同时在闭环执行能力上匹敌或超越领先的反应式基础策略。

## Abstract
World models let robots imagine possible futures, but exploiting this capability for real-time control is bottlenecked by a representation misalignment: the generative model and the planner operate on decoupled manifolds, so the planner has no shared structure to search over and must instead decode every candidate back into high-dimensional pixel space to evaluate it. This decoding step is a major obstacle to real-time control on physical hardware. In this paper, we present Hydra, a discrete World Action Model that closes this gap by moving the planner, both the sampler and the evaluator, inside the model. Hydra establishes a unified latent manifold over visual states, physical poses, and control actions, then compresses this manifold through modality-specific Vector-Quantized bottlenecks into discrete vocabularies of kinodynamic intents and visual states. Because candidates are now drawn directly from this shared manifold, sampling is informed by the model's own understanding of the observation rather than proposed blind, and evaluation happens natively within the discrete space: candidates are ranked by a Kinematic-Perceptual Cost, without ever decoding to pixels. We term this Discrete Latent Planning (DLP). Because planning over discrete intents alone cannot supply the smooth, continuous commands physical actuation requires, Hydra pairs DLP with conditional Flow Matching, which maps each selected intent to a continuous trajectory for execution. Evaluated on two physical robotic platforms, Hydra outperforms state-of-the-art world models in goal-directed planning, while matching or exceeding the closed-loop execution capabilities of leading reactive foundation policies.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心痛点**：世界模型（World Models）让机器人能够“想象”未来的状态序列，但将这一能力用于实时控制时存在严重的**表示错位（Representation Misalignment）**问题。
- **问题具体表现**：
  - 生成模型与规划器运行在**相互解耦的流形（decoupled manifolds）**之上，规划器没有可共享的结构可供搜索；
  - 由于生成空间与规划空间不一致，规划器对候选轨迹的评价必须**逐一解码回高维像素空间**，依赖 LPIPS 等感知度量进行目标比对，造成巨大的计算开销；
  - 连续采样空间随规划时域呈指数膨胀，使规划器陷入两难：要么采样过稀疏而找不到好路径，要么耗费大量算力评估大量不可行轨迹。
- **研究定位**：Hydra 针对这一难题，将“规划器”移入世界模型内部，以**离散潜在空间中的搜索**替代连续空间中的盲目采样，从而让世界模型真正服务于物理机器人的实时闭环控制。

## 2. 论文提出的方法论

### 2.1 整体框架：三种导航范式的演化
论文将当前基础导航模型划分为三种范式：
- **反应式策略（Reactive Policy）**：如 ViNT、GNM、NoMaD，直接建立从观测历史到动作的映射，缺少对未来后果的预测，无法规避局部极小值（如死角）；
- **视觉世界模型（解耦规划）**：如 NWM，以外部规划器（CEM/MPPI）采样动作为条件预测未来图像，存在采样效率低、需像素级解码评估的缺陷；
- **世界动作模型（统一规划，Hydra 所属）**：联合建模视觉、位姿和动作三种模态的未来生成流，**规划器内置于世界模型内部**，采样与评估均在共享的离散流形上进行。

### 2.2 核心架构：三大机制
1. **统一多模态编码（早期融合 Early Fusion）**
   - 视觉观测经冻结的 Stable Diffusion VAE 编码为潜在表示；
   - 低维位姿、动作先经**傅里叶特征映射**增强表达，再广播到统一长度、与视觉潜在表示**相加**形成一个统一 token 序列（而非将不同模态 token 交错拼接）；
   - 引入**学习的模态掩码策略**（余弦退火课程式随机掩码），应对部署时模态缺失并促进无条件探索；
   - Transformer 编码器生成上下文 token，压缩机器人历史的“位置、内容与方式”。

2. **不对称量化瓶颈**
   - 使用**模态专属向量量化（VQ）码本**：视觉码本规模 2048，位姿码本 64，动作码本 64；
   - 不对称容量分配保留了高保真视觉预测能力，同时确保运动学意图的快速检索；
   - 该离散化将预测不确定性约简为**词表上的分类分布**，为 KPC 代价中的熵项提供了廉价的计算方式。

3. **多模态生成流匹配**
   - 采用整流流匹配（Rectified Flow Matching）作为概率路径生成手段，定义了图像、位姿、动作三个流解码器；
   - 每个解码器以离散上下文 token 与时间步为条件，预测从高斯噪声到真实目标的线速度场，以向量场回归损失端到端训练。

### 2.3 离散潜在规划（DLP）与运动学-感知代价（KPC）
- **无偏初始化与搜索**：无外部目标时以掩码未来状态获得无偏专家先验；加入经过指数平滑的 Gumbel 噪声（双来源随机性），在保持时间平滑性的同时探索不同拓扑路径；
- **运动学-感知代价（KPC）** 对候选意图序列 τ 定义如下多目标代价：

$$J_{KPC}(\tau) = C_{geo} + \sum_{t=1}^{T} \gamma^t \left( \lambda_{img} C_{img}^{(t)} + \lambda_{prior} C_{prior}^{(t)} + \lambda_{ent} C_{ent}^{(t)} + \lambda_{vq} C_{vq}^{(t)} \right)$$

  - **Cgeo（几何目标）**：目标点欧氏距离，需解码；
  - **Cimg（视觉目标）**：与视觉目标潜在嵌入的 MSE；
  - **Cprior（无偏专家先验）**：在无碰撞人类示教拟合的先验上的负对数似然，间接度量路径合理性；
  - **Cent（视觉预测熵）**：Shannon 熵，预测不确定性在遮挡/模糊区域增大的惩罚项；
  - **Cvq（流形拒绝）**：连续意图向量与其最近视觉码本嵌入间的余弦量化误差，检测超出安全导航流形的 OOD 状态；
  - **γ** 为时间折扣因子，对即时违规施加更大惩罚，弱化远期不确定状态的影响；
  - 除 Cgeo 外所有项均在潜在空间计算，无需逐候选解码。

### 2.4 路径跟随执行策略
Hydra 在外部全局规划器引导下可作为局部路径跟随器，包含两种互补模式：
- **运动学空间无分类器引导（CFG）**：在潜在空间中对无条件先验与目标条件之间的线性插值外推，效率高但长距离时存在**流形偏离**风险；
- **子目标采样**：在离散码本流形上采样候选轨迹，依据与全局参考路径的截断 Chamfer 距离评分，每条候选均经过 VQ 重量化，保证落在合法语义空间内。

1. **离散潜在搜索显著优于连续采样规划**：Hydra 在无遮挡环境中达到 10/10、遮挡与盲角场景各 8/10 的成功率，而 NWM 因规划耗时超过 500 秒无法部署（0/10），VertiFormer 因无结构先验采样导致 0% 的障碍场景成功率；
2. **规划实时性提升巨大**：Hydra 约 0.9 秒完成一次规划，相对 NWM 实现 **约 500 倍以上**的加速；
3. **生成保持时间一致性**：在 16 秒长时域视频生成中，Hydra 的 FVD（19.16）优于 NWM/B（22.11）与 VertiFormer（81.03），说明离散瓶颈没有破坏时间一致性，反而较连续潜空间有更好的抗累积误差能力；
4. **局部路径跟随能力匹敌反应式策略**：尽管输入航路点远比稠密目标图像稀疏，Hydra 在成功率和人为干预次数上与 ViNT/NoMaD 相当或更优；
5. **自动编码器的量化误差与预测熵可作为互补防碰撞信号**：两者在临近物理遮挡时同步上升，在生成器产生“幻觉”后同步下降，构成像素无关的安全评估机制；
6. **早期融合的紧凑世界动作模型相比大规模通用 WAM（如 DreamZero 14B）更适合需要多次前向搜索的实时任务**，Hydra 以 143M 参数量实现了物理机器人上的实时规划。

## 7. 优点

- **方法原创性与问题切入点准确**：识别了生成模型与规划器之间存在表示错位的深层问题，并系统性提出“把规划器放进世界模型”的解决方案；
- **概念上的优雅统一**：通过量化词表同时约束视觉与运动学语义，令“采样-评估-选择-解码执行”全链路在同构空间内完成，逻辑自洽；
- **KPC 代价函数设计精巧**：Cvq、Cent、Cprior 三者从不同角度检测不安全轨迹且互为补充，消融实验显示三者均单独贡献避障能力；
- **实验设计务实且场景多样**：覆盖两种物理实体，多种拓扑挑战（遮挡、盲角、走廊、长距离），且包含对基线更有利的稠密目标图像条件，比较时相对坦诚；
- **实现中重视物理真实性与实际约束**：使用未归一化动作数据以区分不同平台速度尺度；早期确定的线性锚定保证训练稳定性；训练使用可变预测时域以兼容不同规划周期；附录中对搜索随机源、温度退火、Top-K 约束等实现细节阐述充分；
- **对失败案例的深入剖析**：详尽讨论了目标盲初始化导致的转弯失败、行人丢失、流形偏离、Cvq 假阳性等，提升了论文可信度。

## 8. 不足与局限

- **计算资源与可扩展性未充分讨论**：论文未报告训练所需 GPU 资源、时长，物理实验中推理仍依赖 24GB 专业工作站，与实际宣称的“边缘部署”存在差距；训练时视觉码本来自大体积 VAE 解码器，并未完全脱离高算力先决条件；
- **流形拒绝信号的识别精度有限**：Cvq 无法区分“结构新颖的危险障碍”与“视觉复杂但可通行的纹理”（如繁茂树叶导致假阳性），也可能对同质平面墙壁的障碍漏报；该信号缺乏语义层面的因果区分能力；
- **动态代理与行人处理能力脆弱**：受码本有损量化的低通滤波作用与 Stable Diffusion VAE 的频谱偏置影响，行人在生成中被“抹除”或平滑进背景，限制了社交导航场景部署；
- **视觉词表规模与实时性的内在张力**：更大的码本能提升表达能力与泛化能力，但码本检索成本随规模增大与实时性能需求直接冲突，模型面临表达力—延迟的结构性折衷；
- **长距离自主规划尚不成熟**：Hydra 的即时搜索受限于无偏种子初始化并结合少量迭代预算，在不可逆的决策点（如唯一分岔口）容易因决策迟缓而选错分支，反映搜索内迭代次数与实际反应时间之间的预算矛盾；
- **目标可见性问题**：图像目标代价 Cimg 在目标不可见时实际上伤害成功率（80% 降至 20%），说明视觉目标项必须依据可见性条件启用，不能无条件使用（论文后续实验已经据此禁用）；
- **应用范围限制**：实验集中于静态环境、近距离（约 8 米）与中低速度场景；无大规模真实世界长期部署、无标准公开 benchmark 的数值化对比（部分依赖自建物理场景），难以直接与其他 SOTA 方法在相同数据集上数值可复现地横向比较。
