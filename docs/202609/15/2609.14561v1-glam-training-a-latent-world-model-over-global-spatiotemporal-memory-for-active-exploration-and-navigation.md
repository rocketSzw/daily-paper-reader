## 摘要
主动探索和语义导航要求具身智能体从部分观测中构建记忆，预测已观测空间记忆的演化如何支持未来运动，并将该预测转化为可执行的规划。我们提出 GLAM，一个以目标为条件、在全局时空记忆上训练的潜在世界模型，以及围绕它构建的完整导航系统 GLAM NAV。给定历史地图 token、导航目标和当前机器人位姿，GLAM 联合预测未来地图表示和以机器人为中心的航路点潜在表示，从而能够在共享表示空间中推断未来空间上下文和导航意图。该模型遵循类 JEPA 的潜在预测范式，直接作用于地图级潜在 token，而非 RGB 重建，并使用预训练的航路点编码器-解码器在 GLAM NAV 中监督和解码导航规划。训练数据通过在 Habitat 中回放 HM3D v0.2 场景资产上的 ObjectNav 专家轨迹，并将其切分为多时间尺度的预测样本而收集。在受控的 HM3D-ObjectNav 子集复现设置下，GLAM NAV 在成功率和路径长度加权成功率上均优于复现的 BSC-Nav 基线。

## Abstract
Active exploration and semantic navigation require an embodied agent to build memory from partial observations, predict how the evolution of observed spatial memory may support future motion, and convert that prediction into actionable plans. We present GLAM, a goal-conditioned latent world model trained over global spatiotemporal memory, and GLAM NAV, the complete navigation system built around it. Given historical map tokens, a navigation goal, and the current robot pose, GLAM jointly predicts future map representations and robot-centric waypoint latents, allowing future spatial context and navigation intent to be inferred in a shared representation space. The model follows a JEPA-like latent prediction paradigm, operates directly on map-level latent tokens rather than RGB reconstruction, and uses a pretrained waypoint encoder-decoder to supervise and decode navigation plans within GLAM NAV. Training data are collected by replaying ObjectNav expert trajectories in Habitat over HM3D v0.2 scene assets and slicing them into multi-timescale prediction samples. On a controlled HM3D-ObjectNav subset reproduction setting, GLAM NAV improves over a reproduced BSC-Nav baseline in both success rate and success weighted by path length.

- **整体含义**：论文给出 GLAM（目标条件潜在世界模型）与 GLAM NAV（围绕它的完整导航系统），把记忆、预测、规划统一到同一表示空间，试图为语义导航提供一条"预测式记忆"的新路线。作者明确把神经科学对应关系作为**计算设计原则**，而非对生物神经环路的直接实现。

## 2. 方法论

### 2.1 核心思想

- GLAM 是 **goal-conditioned latent world model**：以历史地图 token、目标描述、当前机器人位姿为输入，**一次前向**联合预测两类输出：
  - 未来地图表示（future map tokens）；
  - 机器人中心的路点潜在（robot-centric waypoint latents）。
- 遵循 **JEPA 式潜在预测范式**：直接回归连续的未来表示，**不重建未来 RGB**。
- 形式化（式 1）：
  - \((\hat{Z}_{t+1:t+F}, \hat{E}^w_{t+1:t+F}) = F_\Theta(Z_{t-H+1:t},\ g,\ p_t,\ Q_v,\ Q_w)\)
  - \(H\) 为历史长度，\(F\) 为预测视界；\(Q_v, Q_w\) 分别是未来地图预测与路点潜在预测的**可学习 query**；视觉 query 与路点 query 在同一次前向中共享 memory/goal/pose 上下文。
- **全局记忆**指"对已探索环境的在线表示"，而非完整或预建好的场景地图。

### 2.2 地图 token 编码

- 由 **4 个 RGB-D 视角**构造：提取视觉特征 → 投影到体素网格 → 在每个体素内融合。
- 体素坐标表示在**当前机器人坐标系**中，并用**三维空间 RoPE** 编码位置。
- token 序列截断或零填充到固定长度，并用**有效性掩码**标记非填充位置。
- 线性输入投影把视觉特征映射到主干使用的 **2560 维**表示。

### 2.3 路点潜在编码（含预训练编解码器）

- 路点定义为机器人中心平面位姿增量 \((\Delta x, \Delta y, \Delta\theta)\)，归一化并做 sin/cos 航向编码（式 2）：
  - \(u = [\text{clip}(\Delta x/s_x,-1,1),\ \text{clip}(\Delta y/s_y,-1,1),\ \sin\Delta\theta,\ \cos\Delta\theta]^\top\)，\(e_w=\phi(u)\in\mathbb{R}^{2560}\)
  - 平移尺度 \(s_x, s_y\) **仅由训练集估计**。
- 编码器 \(\phi\) 为两层 MLP（\(4 \to d_a \to 2560\)）+ LayerNorm。
- **预训练阶段**：\(\phi\) 与轻量解码器 \(\rho\) 联合最小化归一化路点 \(u\) 的重建 MSE；该阶段**独立于世界模型**。
- 之后 \(\phi, \rho\) **冻结**：\(\phi\) 为世界模型训练提供路点潜在监督；\(\rho\) 在推理时把预测潜在解码为归一化路点 \(\hat{u}_j=\rho(\hat{e}^w_j)\)（式 3）。

### 2.4 训练损失

- 训练时优化：**Qwen3.5-0.8B 主干**、输入投影、可学习 query、两个回归头。
- 目标函数（式 4）：\(L = \lambda_v \text{MSE}_{m_v}(\hat{Z}, Z^*) + \lambda_w \text{MSE}_{m_w}(\hat{E}^w, \phi(U^*))\)
  - \(Z^*\) 为冻结视觉编码器 + 确定性建图管线产生的未来地图目标；
  - \(U^*\) 为归一化专家路点，经 \(\phi\) 得到目标潜在；
  - \(m_v, m_w\) 为有效性掩码；\(\lambda_v, \lambda_w\) 平衡两项。
- **掩码 MSE**（式 5）：按有效目标位置数与目标表示维度 \(d\) **双重归一化**（路点项 \(d=2560\)，地图项取未来地图特征维度）。
- 两项均直接监督连续表示，**不使用语言模型交叉熵损失**。

### 2.5 训练数据构造

- 在 Habitat 中回放 HM3D v0.2 上的 ObjectNav **专家轨迹**，保留原始场景、起点位姿、目标类别与专家 rollout。
- 记录 RGB-D、机器人位姿、执行动作、由观测导出的地图特征，并额外存储探索过程中的**frontier 序列**及其对应的更新后地图特征。
- 将轨迹切成含"历史地图 token / 未来地图目标 / 未来路点潜在"的训练对。
- 统计：**577 个 episode、145 个场景、55,392 个交互步**，按 1 fps 约 **15.4 小时**观测；经多预测间隔与历史窗口切片得到 **12,101 个多时间尺度预测样本**（仅代表本研究所用子集，非完整 HM3D）。

### 2.6 GLAM NAV 系统流程

- 四个组成部分：**感知/检索/目标验证模块**、**时空记忆模块**、**GLAM 预测核心**、**规划与控制层**。
- 时空记忆由 **landmark memory + graph-voxel memory** 组成，更新时比较新旧观测，决定单元是**新增、融合还是刷新**；检索时用语义信息及其潜在特征定位最相关的候选导航位置。
- 完整循环：环绕观测并更新在线地图 → 依据目标从两类记忆中检索相关区域 → 若目标已被验证则直接导航到该位置；否则用 GLAM 预测未来地图上下文与路点潜在 → 解码路点计划 → 执行选定运动分支 → **仅用真实观测更新记忆**并重新验证目标 → 重复"探索–检索"循环直至成功或终止。
- 明确边界：GLAM 只预测未来地图结构与导航意图，**几何执行、可达性检查、避障运动**由系统其余部分负责。

## 3. 实验设计

- **Benchmark**：HM3D ObjectNav（基于 HM3D-Semantics v0.2，Habitat 生态的标准具身物体导航基准）。共 216 个语义标注的真实室内 3D 重建场景，划分为 145 训练 / 36 验证 / 35 测试场景；目标类别 6 类（chair、sofa、potted plant、bed、toilet、TV）。
- **评测协议**：标准 ObjectNav 协议——在预算内执行 STOP、距有效目标实例 **1.0 m 以内**、且目标在停止位置**可见**；智能体从随机位姿与朝向出发，无预建地图、无特权目标坐标。
- **受控复现设置**：在 HM3D 的 **50% 子集**上评测，保持相同 split 与协议；**复现 BSC-Nav 作为参考方法**，在同一批评测 episode 上运行 GLAM NAV，使两者在场景分布、目标类别、任务难度上匹配。作者明确声明**不与全量基准/不同 HM3D 版本/不同输入模态/不同协议的数字直接比较**。
- **对比方法**：仅一个基线——复现的 **BSC-Nav**（Ruan et al., 2026, Nature Communications，"Brain-inspired spatial intelligence for embodied agents"）。
- **指标**：Success Rate (SR) 与 Success weighted by Path Length (SPL)。作者还建议后续报告应包括首次验证目标观测的路径长度、碰撞率、超时率、误停率、含冻结特征服务与可训练预测器的运行时。
