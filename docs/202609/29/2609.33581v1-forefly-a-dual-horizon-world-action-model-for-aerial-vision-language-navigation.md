## 摘要
空中视觉语言导航（AVLN）要求无人机在复杂三维环境中沿长轨迹保持可靠的指令跟随。然而，现有 AVLN 方法大多是反应式的，或局限于单时域预测，忽视了不同时间时域间互补的未来线索。为解决这一局限，我们提出 ForeFly，一种双时域潜在世界动作模型，可同时预测用于局部连续性的近端未来，以及用于长程引导的自适应航路关键未来。时域特定的前瞻查询由近期视觉记忆与航路关键视觉记忆预置，为未来预测提供具有历史感知的上下文。为利用它们在动作生成中的不同作用，我们引入前瞻引导的动作精炼（FGAR），其非对称地利用近端前瞻进行局部动作增强，并利用航路关键前瞻进行特征级校正和航路级引导。在 TravelUAV 和 UAV-ON 基准上的实验表明，ForeFly 在已见和未见设置中均持续优于强基线，验证了双时域前瞻和 FGAR 学习的有效性。代码见：https://github.com/kunhuiW/ForeFly

## Abstract
Aerial Vision-Language Navigation (AVLN) requires UAVs to maintain reliable instruction following over long trajectories in complex 3D environments. However, existing AVLN approaches are predominantly reactive or limited to single-horizon prediction, overlooking complementary future cues across different temporal horizons. To address this limitation, we propose ForeFly, a dual-horizon latent world action model that predicts both a proximal future for local continuity and an adaptive route-critical future for long-range guidance. Horizon-specific foresight queries are primed with recent and route-critical visual memories, providing history-aware context for future prediction. To exploit their distinct roles in action generation, we introduce Foresight-Guided Action Refinement (FGAR), which asymmetrically exploits proximal foresight for local action enhancement and route-critical foresight for feature-wise correction and route-level guidance. Experiments on the TravelUAV and UAV-ON benchmarks show that ForeFly consistently outperforms strong baselines across seen and unseen settings, validating the effectiveness of dual-horizon foresight and FGAR learning. The code is available at: https://github.com/kunhuiW/ForeFly

## 1. 核心问题与整体含义

- **任务背景**：空中视觉语言导航（Aerial Vision-Language Navigation, AVLN）要求无人机（UAV）理解自然语言指令，在复杂开放的三维环境中自主导航。相比地面 VLN，AVLN 面临搜索空间大、连续 3D 运动、视角剧变、几何约束弱等挑战，且指令常涉及远处地标、航路级空间关系与长时域事件。
- **核心痛点**：
  - 现有方法大多处于**反应式范式（reactive）**，仅依据已观测到的视觉—语言证据推断动作，缺乏对未来视觉状态与导航关键事件的显式预判。
  - 在连续 3D 运动中，局部决策误差会迅速累积为显著轨迹偏移——错过一个转弯点或地标切换即可能导致偏离指令相关航路且难以恢复。
  - 已有引入"未来预测"的工作多为**单时域（single-horizon）**，聚焦近期视觉连续性，忽略不同时间尺度上互补的未来线索（如即将到来的转弯、地标转换、接近目标区域）。
- **整体含义**：论文主张将 AVLN 从"反应式动作预测"重构为"**双时域前瞻（dual-horizon foresight）**"，在紧凑潜空间中同时建模近端与航路关键两类未来，并把前瞻信息转化为动作生成的具体指导。

## 2. 方法论

### 2.1 核心思想
ForeFly 是一个**回顾式双时域潜在世界动作模型（dual-horizon latent world action model）**：先在近期与航路关键视觉记忆中为时域特定的前瞻查询提供依据，再预测互补的近端与自适应航路关键未来潜变量，最后通过 FGAR 以非对称方式将双时域前瞻注入航点生成。

### 2.2 问题形式化
- 给定指令 I、轨迹历史 P≤t、观测历史 O≤t，构造导航上下文 C_t = (I, P≤t, O≤t)。
- 目标联合分布分解为：
  - **世界模型项**：p_W(Z^p_{t+1}, Z^c_{t+κ_t} | C_t)
  - **动作项**：p_A(a_t | C_t, Z^p_{t+1}, Z^c_{t+κ_t})
- 动作表示为当前 UAV 坐标系下的四元组 a_t = (Δx_t, Δy_t, Δz_t, Δρ_t)，其中方向向量模长为 1，Δρ_t ≥ 0 为移动幅度。
- 注意：**κ_t 是自适应时间偏移**，由航路关键目标构造决定，**仅用于监督标签构造，不作为模型输入**（避免未来信息泄漏）。

### 2.3 关键技术一：双记忆前瞻查询预置（Dual-Memory Foresight Query Priming）
- **近期视觉记忆 M^p_t**：保留最近 R=5 帧前视观测的全部 17 个 token（1 个全局 + 16 个局部），保留细粒度外观与空间细节，支撑短期视觉连续性。
- **航路关键视觉记忆 M^c_t**：由三类锚点构成——初始帧、转弯事件（转角 α_i ≥ τ_p = 20°）、以及每隔 τ_g = 30 m 累积行程的距离覆盖锚点；每个锚点仅存全局 token，用于概括稀疏的航路级事件。
  - 转弯锚点定义：v_i = (p_i − p_{i−1})/‖p_i − p_{i−1}‖₂，α_i = arccos(v_iᵀ v_{i+1})。
  - 覆盖锚点定义：在两个相邻事件锚点 u<v 之间，选择使 |s(u,j) − mτ_g| 最小的状态 j*_m（s 为累积行程距离），防止长直段上目标时域过长。
- **时域特定查询预置**：可学习的近端查询 Q^p 与航路关键查询 Q^c 分别对 M^p_t、M^c_t 做注意力，得到历史感知查询 Q̃^p_t、Q̃^c_t。
- **在线更新（Algorithm 1）**：仅使用已执行轨迹前缀；转弯需观测到下一状态才能确认，覆盖锚点以当前步作为临时边界；**未来锚点绝不进入模型输入**。

### 2.4 关键技术二：双时域未来潜变量预测
- MLLM（LLaMA 2-7B）统一处理指令特征 ℓ、轨迹编码 e^traj、当前观测 x_t，以及 Q̃^p_t、Q̃^c_t 与可学习动作查询 Q^a，解码得到：
  - H^p_{t+1}（近端未来）、H^c_{t+κ_t}（航路关键未来）、H^a_t（动作表示）
- **不做像素重建**：共享投影头 g(·) 将两个未来表示映射到紧凑视觉嵌入空间，监督信号为对应未来观测的视觉编码 ψ(o)，避免重建纹理、光照、背景等与导航无关的细节。
- 近端分支始终对齐紧邻的下一帧（δ_p = 1）；航路关键分支对齐下一个转弯/覆盖/终止锚点（δ_c = κ_t），其时间偏移随演示航路几何自适应。

### 2.5 关键技术三：前瞻引导动作精炼（FGAR）
- **近端未来增强**：以动作表示为 query，近端潜变量为 key/value 做交叉注意力，得到 C^p_t = Attn_p(H^a_t, Ẑ^p_{t+1})，将航点决策锚定在可预期的短期视角、局部几何与场景布局变化上。
- **非对称航路关键条件化**：不让两类未来被平等对待。近端增强表示作为"执行载体"，航路关键未来作为"高层控制器"：
  - 先由 C^p_t 对 Ẑ^c_{t+κ_t} 做注意力得到 R^c_t；
  - **特征级变换（FiLM 式）**：[γ_t, β_t] = φ_film(R^c_t)，T^p_t = (1 + γ_t) ⊙ C^p_t + β_t，用于放大/抑制局部动作证据的特定维度并引入事件相关偏移，而不丢弃局部可执行的几何信息。
  - **并行航路级引导路径**：B^c_t = φ_bias(Attn_b(sg(H^a_t), sg(Ẑ^c_{t+κ_t})))，使用 **stop-gradient** 使其成为只读消费者，防止加性路径沦为优化捷径；主调制路径保持可微，以联合优化未来预测与下游动作效用。
- **最终动作**：â_t = φ_act(LN(H^a_t + T^p_t + B^c_t))，其中 H^a_t 为残差基，T^p_t 保留局部可执行性并注入事件条件校正，B^c_t 提供加性航路级引导。

### 2.6 训练目标
- 未来潜变量对齐损失 L_W：两个时域预测与对应未来观测视觉表示的 Frobenius 范数平方误差（按 token 数归一化）。
- 动作损失 L_A：方向余弦误差 (1 − d̂_tᵀ d_t) + 幅度 L1 误差 |Δρ̂_t − Δρ_t|。
- 总目标：L = L_W + L_A。
- **两阶段训练**：第一阶段用简单 MLP 头替换 FGAR 以稳定未来表示学习与航点预测；第二阶段恢复 FGAR 并联合优化全部可训练组件。

## 6. 主要结论与发现

- **TravelUAV Unseen**：相比 SpatialFly，NE 降低 8.02 m，SR/OSR/SPL 分别提升 3.40/8.46/3.43 个百分点；Hard 子集 SR 从 25.71% 提升到 31.09%，长程优势最明显。
- **TravelUAV Seen**：在自主方法中全面最优；相比 SpatialFly，Full 与 Easy 子集 SR 分别提升 3.21 与 4.96 个百分点；Easy 子集 OSR 略低于 SpatialFly，但 Hard 子集 OSR 高出 6.62 个百分点。
- **UAV-ON**：Seen 上 SR 25.13%、OSR 36.30%、SPL 16.31%，分别超过最强竞争结果 2.41/5.82/7.18 个百分点；Unseen 上 SR 从 17.57% 提升到 22.68%（+5.11），OSR 31.44%、SPL 14.59% 均为最高。
- **消融结论**：
  - 单时域（近端或航路关键）均优于 Baseline，说明显式建模未来有益；两者组合进一步提升，证明互补而非冗余。
  - 航路关键单独在 Seen 上增益更大，近端单独在 Unseen 上更好，暗示两时域承担不同泛化角色。
  - Foresight Query Priming 在 Unseen 上增益更显著（SR 21.75%→23.61%，SPL 16.29%→19.73%）。
  - FGAR 增益最大：Seen NE 从 64.41 m 降到 48.74 m，SR 从 33.08% 升到 41.75%；Unseen SR 从 23.61% 升到 28.86%。说明**仅有未来预测不够，如何把前瞻条件化到动作生成才是关键**。
  - 直接融合双未来（拼接+交叉注意力）相对 MLP 头提升有限，验证非对称条件化设计优于对称融合。
- **定性发现**：ForeFly 生成的 220 m 轨迹贴近 226 m 真值航路，而基线在关键转弯点决策错误导致偏离失败；航路关键前瞻能预判即将到来的转弯。

- **实验覆盖较全面**：两个基准、seen/unseen、easy/hard、

目标级偏移、环境级偏移、长度分层，以及人工上界与随机/固定动作下界，能较立体地刻画方法优势所在。

- **消融层次分明**：先做组件级消融（Baseline → 单时域 → 双时域 → 查询预置 → FGAR），再做 FGAR 内部设计消融（MLP Head / 直接融合 / 去加性路径 / 完整 FGAR），能够逐步归因增益来源，而不是只给出一个"Full 最好"的结论。
- **可复现性基础信息较全**：给出了骨干模型、视觉编码器、LoRA 学习率、锚点阈值（τ_p = 20°、τ_g = 30 m）、前瞻槽数（17）等关键超参，便于后续复现与对比。
- **对"预测 vs 利用"的洞察**：实验明确指出仅有未来潜变量预测不足以带来大幅提升，真正的增益来自 FGAR 的前瞻条件化方式，这一结论对世界模型类导航工作具有一般性参考价值。

## 8. 局限与可改进之处

- **资源与效率信息缺失**：论文仅报告使用 4×RTX 5090，未给出训练时长、GPU 小时、显存峰值、推理时延与参数量增量。考虑到引入了 LLaMA 2-7B + EVA-ViT-G + 双时域预测头 + FGAR，部署开销值得关注，但论文未做效率-精度权衡分析。
- **超参与锚点阈值缺少敏感性分析**：τ_p = 20°、τ_g = 30 m、R = 5、N_p = N_c = 17 等均为手工设定，未验证其对不同场景密度（如密集城区 vs 开阔山地）的鲁棒性。不同数据集是否需要不同阈值也未讨论。
- **κ_t 自适应性依赖真值轨迹几何**：航路关键时域的监督标签由演示轨迹的转弯/覆盖锚点构造，虽避免了泄漏，但其"航路关键"的定义本质上是几何驱动的，未必与指令语义上的关键事件（如"经过红色屋顶后左转"）完全对齐。
- **统计严谨性不足**：未报告多随机种子的均值与方差，也未做显著性检验；单次实验结果的波动可能影响小幅度提升（如 2–3 个百分点）的可靠性判断。
- **定性分析偏少且偏乐观**：仅 1 例轨迹对比与 3 组未来可视化，且可视化借助辅助 latent-diffusion 重建器（非模型原生输出），缺乏系统失败案例归因（例如：是未来预测错了，还是 FGAR 没用上？）。
- **基线公平性难以完全核实**：不同数据集上的基线可能未在同一调参预算下复现，部分基线（如 NavFoM、SpatialFly）与本文并非完全同设定，跨方法比较需谨慎。
- **未涉及动态/退化场景**：如风扰、GPS 漂移、光照剧变、动态障碍等实际 UAV 部署中的关键因素均未纳入评估。
- **双时域仅有二档**：论文论证了"单时域不足、双时域互补"，但未探讨是否更多时域（如三档：帧级 / 事件级 / 目标级）能进一步获益，或是否存在时域数量与收益的饱和点。

## 9. 总结与启发

- **一句话概括**：ForeFly 把空中视觉语言导航从"看一步走一步"的反应式决策，升级为"在紧凑潜空间中同时预判近端视觉演化与航路关键转折，并以非对称方式把前瞻注入航点生成"的双时域世界动作模型。
- **核心方法论贡献**可归纳为三点：
  1. **双记忆前瞻查询预置**——用细粒度近期记忆与稀疏航路关键记忆，分别为两个时域提供时域特定的查询上下文，且在线更新严格无泄漏；
  2. **潜空间双时域预测**——以未来观测的视觉编码为监督，而非像素重建，把预测目标压缩到与导航相关的语义层面，并让航路关键时域随几何自适应；
  3. **FGAR 非对称条件化**——近端未来作"执行载体"、航路关键未来作"高层控制器"，配合 FiLM 式调制与 stop-gradient 加性引导，既保留局部可执行几何，又避免优化捷径。
- **最具迁移价值的洞察**：对于任何"预测未来 + 决策"的具身智能框架，"预测得准"与"用得好"是两件事；ForeFly 的消融（FGAR 增益远大于单纯引入未来预测）提示，**未来表征的条件化结构设计可能比未来预测本身更决定性能上限**。
- **对后续工作的启示**：
  - 可探索语义驱动的"关键事件"定义（结合指令中的指代与事件谓词），替代纯几何锚点；
  - 可将双时域扩展为多时域或自适应时域数量，并研究其时域粒度与任务长度的关系；
  - 需补齐效率、鲁棒性与统计显著性报告，推动该方向从"点上升级"走向"可部署验证"。
