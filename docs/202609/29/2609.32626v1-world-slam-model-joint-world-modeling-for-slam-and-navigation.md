## 摘要
我们提出世界SLAM模型（World SLAM Model, WSM），一个将SLAM范式直接引入下游导航的统一框架。WSM并非仅将SLAM视为提供位姿、地图或令牌（tokens）的上游模块，而是采用其核心机制，包括具有持久记忆的增量状态更新以及对累积误差的后端优化，以在交互过程中维持一致的世界状态。给定当前观测和导航目标，WSM预测未来视觉状态，并联合估计其相机运动与稠密几何，从而将视觉预测锚定在不断演化的空间世界状态中。随着新观测的到来，该空间状态持续更新，并为动作生成与闭环导航提供基础。WSM以联合导航--SLAM目标进行端到端训练，使下游导航能够直接受益于SLAM式的状态维护与优化，同时保持精确的几何估计。实验表明，导航性能得到提升，同时SLAM精度也很高，凸显了SLAM作为长时程世界建模与具身交互内在机制的潜力。

## Abstract
We introduce World SLAM Model (WSM), a unified framework that brings the SLAM paradigm directly into downstream navigation. Rather than treating SLAM merely as an upstream module that provides poses, maps or tokens, WSM adopts its core mechanisms, including incremental state updates with persistent memory and backend refinement of accumulated errors, to maintain a consistent world state during interaction. Given the current observation and a navigation goal, WSM predicts future visual states and jointly estimates their camera motion and dense geometry, grounding visual prediction in an evolving spatial world state. This spatial state is continuously updated as new observations arrive and provides the basis for action generation and closed-loop navigation. WSM is trained end-to-end with a joint navigation--SLAM objective, enabling downstream navigation to benefit directly from SLAM-style state maintenance and refinement while preserving accurate geometric estimation. Experiments demonstrate improved navigation performance together with strong SLAM accuracy, highlighting the potential of SLAM as an intrinsic mechanism for long-horizon world modeling and embodied interaction.

# World SLAM Model（WSM）论文总结

## 1. 核心问题与研究动机

- **背景**：SLAM 长期是机器人领域的核心空间模块，从观测流中估计相机运动与场景结构，为下游导航/控制提供位姿与地图。近年端到端导航模型试图省去显式 SLAM，但仍依赖空间信息（深度输入、外部真值定位或预训练 3D 重建模型）。
- **核心问题**：直接使用 SLAM 的输出（位姿、地图、token）仍使**状态估计与导航被分开优化**，导航目标无法塑造世界状态的学习与维护方式；几何信息始终被当作"上游估计"喂给导航模块。
- **核心主张**：导航不仅应受益于 SLAM **估计了什么**，更应受益于 SLAM **如何持续维护与修正世界状态**（增量状态更新、持久记忆、后端误差修正）。
- **整体含义**：世界模型天然需要持续处理观测、保留历史、预测未来演化并更新状态，这与 SLAM 机制高度契合。因此 SLAM 应作为长时程世界建模的**内在计算结构**，而非外部的几何估计来源。

## 2. 方法论

### 2.1 核心思想
- 提出 WSM，将 SLAM 机制直接嵌入下游导航，形成**空间估计、记忆、预测、动作共享的闭环模型**。
- 由两个角色构成：**生成专家**（dream 未来观测）与 **SLAM 专家**（估计世界状态，兼作逆动力学模型）。
- 流程：SLAM 专家从当前观测估计深度与相机位姿 → 生成专家在目标条件下 dream 未来观测 → 同一 SLAM 专家从 dreamed 帧反推未来世界状态与相机轨迹 → 执行后新观测回灌，形成**预测—交互—更新**闭环。持久 KV cache 支持跨交互步的增量处理。

### 2.2 关键形式化
- 观测经 Wan2.2 因果 VAE 编码，时间压缩率 M=4；度量状态 $s_t=(d_t,\{g_{t,m}\})$（深度 + 相机位姿），按 K 步 chunk 处理。
- 视觉 dreaming：$\hat{o}_{t+1}\sim p_\theta(\cdot|o_{\le t},s_{\le t})$（式1）。
- SLAM 世界状态：$s_{t+1}=f_\psi(o_{t+1}|o_{\le t},s_{\le t})$（式2）、$\hat{s}_{t+1}=f_\psi(\hat{o}_{t+1}|\dots)$（式3），同一 $f_\psi$ 作用于真实与 dreamed 序列。
- 局部后端修正漂移：$s_{t-k+1:t}=f_\psi(o_{t-k+1:t}|o_{\le t-k},s_{\le t-k})$，$k\le K$（式4）。
- 起—目标导航：目标 $p_{goal}\in\mathbb{R}^3$（首帧相机坐标系）条件化 dreaming（式5），其恢复的位姿序列即度量规划。

### 2.3 架构与自回归建模
- 单一 **Mixture-of-Transformers（MoT）** 含三个专家：RGB 生成专家、深度专家、位姿专家（后两者合称 SLAM 专家）；各专家参数独立，所有 token 经每层联合自注意力交互。
- 目标 token 仅通过 cross-attention 条件化生成专家。
- 训练序列采用 teacher-forcing：每 chunk 含 clean tokens（$O_n,S_n$ 作上下文）与 prediction tokens（噪声 RGB + 零深度/单位位姿的状态查询），所有 chunk 单次前向并行监督。
- 注意力掩码：保持跨 chunk 时序、chunk 内联合预测；clean token 按帧因果且 RGB/状态历史解耦；噪声 RGB 与状态查询互不可见以防信息泄漏。

### 2.4 训练
- **预训练（联合 teacher-forcing）**：RGB 用 flow matching 损失 $L_{FM}$；深度用 log 归一化后 VAE latent 的 MSE $L_d$；位姿用 smooth-L1 监督绝对与相对位姿 $L_{abs}+L_{rel}$。总目标 $L_{pre}=L_{FM}+\lambda_d L_d+\lambda_p(L_{abs}+L_{rel})$。
- **后训练（安全优先强化学习）**：因模仿预训练存在协变量偏移，且随机采样可能撞障碍，采用 DiffusionNFT。用 SLAM 专家把生成视频转为度量轨迹，**无需模拟器**即可用占据地图与专家轨迹打分。奖励含安全门控：$r_i = s_i\exp(-C_i/T)/\sum_j s_j\exp(-C_j/T)$，$s_i$ 表示无碰撞；代价 $C_i$ 为沿轨迹的测地进度与专家进度的 MSE。仅更新生成专家的自注意力 LoRA，SLAM 专家冻结。

### 2.5 推理
- 每次规划生成目标条件的 RGB 序列，SLAM 专家单次前向直接回归未来深度与位姿（无迭代去噪）；底层控制器跟踪短前缀后回灌新观测。
- 局部后端重估当前 chunk 内已观测帧的状态并替换估计（RGB token 不变）；生成的帧在每步后丢弃，持久历史只保留真实观测帧；KV cache 跨规划步复用。

## 6. 主要结论与发现

- **导航**：WSM 在两个场景取得最高 SR/SPL——Home 70.3/66.3、Commercial 73.9/71.8，较 LoGoPlanner 分别提升 10.7 和 8.1 个百分点，且仅用 RGB。
- **SLAM**：位姿估计 ATE RMSE 0.021 m，优于微调 SLAM-Former 的 0.041 m；但稠密重建 Acc. RMSE 0.062 m 差于 0.041 m（推测因深度编码在面向外观的 VAE latent 空间）。
- **SLAM IDM 消融**：去掉 SLAM 专家后 SR 下降约 36 个百分点（Home 28.1、Commercial 32.1），说明共享 SLAM 专家的定位建图对目标锚定至关重要。
- **局部后端**：带来 SR/SPL 提升 Home +2.0/+1.1、Commercial +1.3/+1.3，说明精化近期状态可减少历史误差累积。
- **后训练**：SR 提升 5.7/5.4 个百分点，SPL 提升 4.8/4.9 个百分点，主要源于"dream 何种未来"的改变。
- **总体结论**：导航受益于 SLAM 的状态维护与修正机制，SLAM 可作为长时程世界建模与具身交互的内在机制。

## 7. 优点

- **视角新颖**：将 SLAM 从"上游几何估计模块"重新定义为世界建模的内在计算机制，问题立意清晰。
- **架构统一**：用单一 MoT 将生成与 SLAM 专家通过联合自注意力耦合，深度与位姿互见联合回归，设计简洁。
- **训练目标联合**：几何与导航目标共同塑造共享世界状态表示，端到端训练。
- **无需模拟器的 RL 后训练**：利用 SLAM 专家将生成视频转为度量轨迹，直接对安全性（无碰撞）与进度一致性打分，仅更新 LoRA 并冻结 SLAM 专家，避免奖励被轨迹估计器"刷高"，设计巧妙。
- **仅 RGB 输入**：不依赖外部里程计、深度传感器或独立 3D 重建模型，部署独立性好。
- **增量与闭环**：持久 KV cache + 局部后端重估，兼顾效率与漂移修正；消融逐项验证了各组件价值。

## 8. 不足与局限

- **几何保真度权衡**：深度编码在面向外观的 Wan2.2 VAE latent 空间，牺牲几何精度，稠密重建指标弱于 SLAM-Former。
- **内存与算力随帧增长**：历史 KV cache 未压缩，内存与计算随观测帧数线性增长，**限制长时程部署**（作者列为未来工作）。
- **实验覆盖有限**：导航仅在模拟 benchmark 上评测，无真实机器人验证；SLAM 仅与 SLAM-Former 对比；场景限于室内 Home

与 Commercial 两类模拟室内场景，未覆盖室外、动态、大规模或光照剧烈变化的环境；SLAM 评测也局限于同一数据分布，跨数据集/跨域泛化性未验证。
- **对比基线覆盖偏窄**：SLAM 侧仅与 SLAM-Former（发布版 + 微调版）对比，缺少与 ORB-SLAM3、DROID-SLAM、DPV-SLAM 等经典或学习型 SLAM 系统的位姿/重建对比；导航侧也未与端到端视频世界模型类方法（如 UniPi、iVideoGPT 等）直接比较，难以判断"SLAM 内化"相对"纯生成式世界模型"的净收益。
- **评测指标维度偏少**：导航仅报告 SR/SPL，未评估轨迹平滑性、能耗、推理延迟随步数增长、失败模式分布等部署相关指标；SLAM 仅报告 ATE 与稠密重建 Acc.，缺少尺度漂移、回环一致性、长序列漂移曲线等分析。
- **超参与奖励设计敏感性未知**：后训练的 group size、采样步数、安全门控温度、代价权重等均未做敏感性消融；奖励依赖专家轨迹的测地进度，可能对专家质量与轨迹分布敏感。
- **复现门槛较高**：48×A100 的预训练 + 后训练规模，叠加 Wan2.2 生成先验，完整复现成本高；论文亦未报告训练墙钟时间，难以评估训练效率。
- **局部后端作用范围有限**：仅重估当前 chunk 内已观测帧（$k\le K$），更长时程的全局一致性仍依赖 KV cache 的历史积累，未引入显式全局优化或回环。

## 9. 总体评价与启示

- **定位**：WSM 属于"概念驱动 + 工程整合"型工作，最大贡献不在于单点指标领先，而在于提出并初步验证了 **"SLAM 机制作为世界模型内在计算结构"** 这一范式——几何、记忆、预测、动作共享同一状态维护过程。
- **证据强度**：消融链条较为完整且方向一致——移除 SLAM 专家导致 SR 掉约 36 个百分点、局部后端带来 +1~2 个百分点、后训练再带来 +5 个百分点，因果关系相对清晰，支撑了核心主张。
- **可迁移性**：单一 MoT 承载多专家 + 冻结 SLAM 专家作为"无模拟器奖励打分器"的设计，思路可迁移到其他需要几何一致性与安全约束的生成式决策任务（如操作、自动驾驶轨迹生成）。
- **开放问题**：长时程内存增长、几何保真度短板、真实世界闭环验证，是三条最值得跟进的方向；若能结合 KV cache 压缩/稀疏化与独立几何 latent，或可同时缓解内存与重建精度问题。
