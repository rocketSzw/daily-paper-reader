## 摘要
世界动作模型为视觉导航智能体提供了一种方式，使其能够预判候选动作将如何改变未来观测，并基于预测结果采取行动。对于无人机而言，该能力必须在严格的精度与效率约束下运行。我们提出 DroneWAM，一种用于无人机视觉导航的高效世界动作模型。DroneWAM 采用基于 JEPA 的架构，直接在表征空间中建模未来状态，避免了显式生成未来图像的开销。预训练的 Resampler 进一步将稠密编码器特征压缩为更少的潜在 token，从而减少每个想象步骤中重复的计算。我们还引入自适应 rollout，其中经偏好训练的 Gate 根据当前场景自适应地分配预测深度。为支持更丰富的空中运动下的学习，我们构建了 DroneNav-6D，一个模拟视觉导航数据集，包含同步的 RGB 观测、6 自由度飞行轨迹、控制指令以及随机风扰动。在 DroneNav-6D 上，DroneWAM 在对比方法中取得了最佳轨迹精度。自适应 rollout 进一步将平均预测深度从 8 降至 4.58，同时提升轨迹精度，表明预测计算可以更有效地在不同场景间进行分配。代码与数据将发布。

## Abstract
World-action models give visual navigation agents a way to anticipate how candidate actions will change future observations and to act from the predicted consequences. For drones, this capability must operate under tight accuracy and efficiency constraints. We present DroneWAM, an efficient world-action model for drone visual navigation. DroneWAM adopts a JEPA-based architecture to model future states directly in representation space, avoiding the cost of explicit future image generation. A pretrained Resampler further compresses dense encoder features into fewer latent tokens, reducing the computation repeated at each imagined step. We also introduce adaptive rollout, where a preference-trained Gate adaptively allocates prediction depth according to the current scene. To support learning under richer aerial motion, we construct DroneNav-6D, a simulated visual navigation dataset with synchronized RGB observations, 6-DoF flight trajectories, control commands, and randomized wind disturbances. On DroneNav-6D, DroneWAM achieves the best trajectory accuracy among the compared methods. Adaptive rollout further reduces the average prediction depth from 8 to 4.58 while improving trajectory accuracy, demonstrating that predictive computation can be allocated more effectively across scenes. \href{https://github.com/1e12Leon/DroneWAM}{Codes and data} will be released.

  - 现有航空导航基准多采用 4-DoF 运动（平移 + 偏航），对 roll/pitch 覆盖不足，限制了更完整的空中世界动作建模。

## 2. 论文提出的方法论

### 核心思想
- 采用 **JEPA 式架构**，直接在表征空间预测未来状态，避免未来图像生成的高昂成本。
- 使用预训练 **Resampler** 将稠密视觉编码器特征压缩为少量 latent token，降低每个想象步骤的重复计算。
- 引入 **自适应 rollout**：由偏好训练的 Gate 根据当前场景决定预测深度，简单场景少预测，模糊场景多预测。

### 关键技术细节
- **问题设定**：
  - 以目标图像 `g` 指定导航目标；每个控制步输入 RGB 观测 `o_t`、运动状态 `s_t`、已执行动作 `a_≤t`。
  - 观测与目标图像共享冻结视觉编码器 `E` 和 Resampler `R_ρ`，得到 `z_t = R_ρ(E(o_t))`、`z_g = R_ρ(E(g))`。
  - 世界动作模型预测未来 latent 状态和 H 步动作计划。
- **三阶段训练**：
  1. **Resampler 预训练**：冻结视觉编码器，将 dense token 压缩为 128 个 latent token，并用轻量 Decoder 重建原始编码器特征；使用特征重建与时间一致性目标。之后冻结编码器与 Resampler，丢弃 Decoder。
  2. **Predictor 与 Planner 训练**：
     - Predictor 基于观测上下文 `C_t`、目标 latent `z_g` 和已预测 latent，自回归预测未来 latent 状态。
     - 世界预测损失为时间折扣 latent 损失：对 K_max 步预测误差按 `γ^(k-1)` 加权平均。
     - Planner 在每个想象深度 `k` 生成完整 H 步 6-DoF 动作计划，并从当前位姿积分得到预测轨迹。
     - Planner 损失使用相对绝对轨迹误差 rATE 与相对位姿误差 rRPE，在所有想象深度上平均；总损失为 `L_WAM = λ_WM L_WM + λ_PLA L_PLA`。
  3. **Gate 偏好训练**：
     - 冻结整个 WAM，对每个样本评估所有想象深度 `k`，计算代价 `C_i,k = rATE/ε_A + rRPE/ε_R + λ_c k/K_max`。
     - 最低代价深度作为偏好样本，其余作为拒绝样本。
     - Gate 输入仅包含推理时可得信息，如观测 latent、预测 latent 历史、动作计划历史、相邻预测变化、近期 6-DoF 运动、当前速度、想象深度等。
     - 使用 DPO 风格参考调整奖励优化 Gate，仅更新 Gate；随后在独立校准集上确定各深度停止阈值 `η_k`。
- **自适应推理**：
  - 在每个控制步，Predictor、Planner、Gate 迭代执行。
  - 停止深度定义为 `τ_t = min({k | K_min ≤ k ≤ K_max, q_t,k ≥ η_k} ∪ {K_max})`。
  - 最终选择停止前得分最高的动作计划 `κ_t = arg max q_t,k`，只执行该计划第一步，之后以滚动时域方式重新观测与规划。
  - 预测深度 `k` 与动作计划内时间索引 `h` 是两个不同时间维度：`k` 控制想象步数，`H` 是计划长度。

## 6. 论文的主要结论与发现

- DroneWAM 在 DroneNav-6D 开环评估中取得最佳轨迹精度：
  - ATE 从 FastWAM 的 1.8366 降至 1.1062，Rel.ATE 从 0.1919 降至 0.0578。
  - 推理延迟从 712.33 ms 降至 483.29 ms，实现更好的精度—效率权衡。
- 闭环导航中：
  - DroneWAM 任务进度从 FastWAM 的 0.510 提升到 0.774，轨迹误差与 MSE 更低，延迟更低。
  - 但所有方法均未完成完整复杂任务，说明尚不适合真实部署。
- 自适应 rollout：
  - 平均预测深度从 8 降至 4.58，延迟降低 22.4%，同时轨迹误差更低。
  - 随机停止虽计算量相近，但性能明显更差，说明收益来自合理分配预测深度，而非单纯截断。
- Resampler：
  - 将 512 token 压缩到 128 token，延迟降低 18.3%，轨迹精度几乎不变；进一步压到 16 token 则精度明显下降。
- Gate 泛化：
  - 在五个环境中，seen 与 unseen 的 Rel.ATE 最大差距仅 0.0034，Rel.RPE 最大差距 0.0010，未显示明显过拟合。
- LIBERO 迁移：
  - 自适应 rollout 将推理延迟从 890.8 ms 降至 411.9 ms，降低 53.8%，同时归一化 RMSE 和 gripper 准确率略有提升。
  - 分 suite 均优于固定 D8，平均深度约 3.56。
- Easy route：
  - DroneWAM 成功率达 88%，高于 NWM 的 74% 和 FastWAM 的 72%。
  - 表明复杂场景失败主要来自长时程视觉定位与误差累积，而非闭环机制完全失效。

## 7. 优点

- **方法设计亮点**：
  - 在 latent 表征空间预测未来，避免显式 RGB 生成，计算效率高。
  - Resampler 从空间维度压缩视觉 token，自适应 rollout 从时间维度压缩想象步数，二者互补。
  - Gate 使用偏好学习决定何时停止，而非固定深度，使预测计算按场景动态分配。
  - 推理时保留最高分计划，允许停止深度与最终选择深度不同，增强灵活性。
- **数据贡献**：
  - DroneNav-6D 提供 6-DoF 飞行、同步 RGB、控制指令和随机风扰动，比传统 4-DoF 数据覆盖更完整的空中运动。
  - 自动仿真采集管线可扩展，支持未来更大规模数据构建。
- **实验设计亮点**：
  - 同时评估开环预测与闭环导航，并补充 LIBERO 跨域迁移。
  - 消融覆盖组件、rollout 策略、token 数、深度分析、Gate 泛化等。
  - 使用环境级交叉验证检验 Gate 泛化，减少过拟合疑虑。
  - 定量指标与定性轨迹可视化结合。

## 8. 不足与局限

- **闭环任务成功率低**：
  - 在完整复杂闭环 benchmark 中，所有方法均未完成任何 episode。
  - Easy route 下成功率 88%，说明长时程视觉定位、误差累积和复杂环境仍是瓶颈。
- **仿真到现实差距**：
  - 数据全部来自 AirSim 仿真，未在真实无人机平台验证。
  - 随机风扰动虽增加多样性，但仍不能完全代表真实气动、感知噪声和动态环境。
- **模型限制**：
  - 固定 token 预算和有限想象时域可能需要针对不同场景与算力调整。
  - 性能依赖预训练编码器和 Resampler 保留的信息。
  - Gate 存在错误早停风险，案例研究中出现应继续 rollout 但提前停止的情况。
- **实验覆盖与公平性风险**：
  - 闭环主实验仅对比 FastWAM 和 NWM，基线数量有限。
