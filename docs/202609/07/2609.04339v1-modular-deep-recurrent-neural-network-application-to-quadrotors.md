## 摘要
引入了一种模块化深度递归神经网络（RNN），以促进部署各种RNN架构，并自动计算基于梯度的学习方法的导数。模块化带来了一系列新架构，其中之一包括前馈层间连接。通过在多层的RNN中添加前馈层间连接，观察到RNN学习和建模高阶动态及非线性的能力显著提高。多层RNN在空间上的梯度消失/爆炸问题也通过前馈连接得到缓解。这些结果通过四旋翼飞行器案例研究得到验证，在该案例中，我们特定的网络结构学习了高度动态模型，而现有方法无法快速或根本无法泛化。

## Abstract
A modular deep Recurrent Neural Network (RNN) is introduced to facilitate the process of deploying various architectures of RNNs, and to automatically compute derivatives for gradient-based learning methods. The modularity leads to a set of new architectures, one of which includes feedforward inter-layer connections. By adding feedforward inter-layer connections in a multi-layer RNN, it is observed that the capability of the RNN to learn and model high-order dynamics and nonlinearities is significantly improved. The problem of vanishing/exploding gradient in space for a multilayer RNN is also alleviated using feedforward connections. These results are demonstrated using a quadrotor case study, for which a model of the altitude dynamics is learned with our particular network structure, while existing methods are unable to generalize as quickly or at all.

### 2.1 核心思想
- 每个隐藏层 \( G_i \) 视为一个**局部递归的 MIMO 动态子系统**，其状态方程为：
  \[
  x_i(k) = A_i y_i(k-1) + B_i u_i(k) + b_i
  \]
  \[
  y_i(k) = f_i(x_i(k))
  \]
- 通过一个 **(L+2) × L 的连接矩阵 C** 表示层间、输入到层、层到输出的连接有无（0/1），从而将 RMLP、NARX 以及带全连接的新架构统一到一个通用定义之下。独立输入对应第 L+1 行，输出取自第 L+2 行。
- 论文中所谓的“MODERNN”特指具有**所有层间前馈连接**的版本，即每个层都接收所有前层的输出，并连接到输出层。

### 2.2 关键技术细节
- **模块化自动求导**：将所有权重整合为一个向量 \( p = [p_1^T, …, p_L^T]^T \)，每一层独立计算其参数。输出层对权重参数的 Jacobian 采用**递归更新规则**：
  \[
  J_{y_i}(k) = \text{diag}(f_i'(x_i(k))) [A_i J_{y_i}(k-1) + B_i J_{u_i}(k) + \Gamma_i(k)]
  \]
  其中 \( \Gamma_i(k) \) 表示局部权重对全局权重的导数。因模块化定义，任意修改架构后仅需调整连接矩阵，不必重新推导解析导数。
- **训练算法**：采用 **Levenberg-Marquardt（LM）** 算法，以 SSE 为目标函数，权重更新律为：
  \[
  \Delta p = -(J^T J + \lambda I)^{-1} J^T e
  \]
- **Algorithm 1 中的四层嵌套循环**：
  - **l1 循环**：从数据集中分批选择训练+验证轨迹；
  - **l2 循环**：通过 nv 折交叉验证划分训练集和验证集；
  - **l3 循环**：反复执行 LM 优化，以验证集误差不再下降为早停条件；
  - **l4 循环**：自适应调节阻尼因子 λ（按 2/3 或 3/2 倍增/倍减）。
- **初始化与零状态设定**：网络从零状态开始训练，输入样本也从静止点（如四旋翼落地状态）开始，避免随机初始化带来的不合理初始状态。

## 6. 论文的主要结论与发现

- **核心结论**：
  - **前馈层间连接**是缓解多层 RNN “空间梯度消失/爆炸” 的有效手段。误差信息能通过多条路径回传，条件数病态问题得到缓解，使得普通梯度训练方法（如 LM）在多层架构上也可用。
  - 带前馈连接的 MODERNN 在相同层数和神经元数下，其学习高阶非线性动态系统的能力显著强于 RMLP 和 NARX。
- **性能发现**：
  - MODERNN 在 minibatch 很小时（ntr = 5）仍可收敛，而 NARX 和 RMLP 在 ntr = 5、10 时全部失败。
  - 最小可行 MODERNN 仅需 48 个权重即可学会该复杂动态，且训练时间（0.5 h）远低于 RMLP（5.5 h）与 NARX（7.5 h）。
  - 在学习同一动态时，MODERNN 可大幅降低网络规模与训练开销，且 Hessian 条件数显著优于对比方法。
