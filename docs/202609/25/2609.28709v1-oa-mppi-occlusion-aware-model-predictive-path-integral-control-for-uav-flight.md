## 摘要
自主无人机在杂乱且部分未知的环境中飞行时，不仅需要推理已观测到的障碍物，还需要推理传感器无法观测到的遮挡区域。我们提出了 OA-MPPI，一种面向四旋翼飞行的障碍物与遮挡感知的模型预测路径积分（MPPI）控制扩展方法，它考虑了可能从这些区域出现并进入飞行器路径的移动智能体。在每个规划步骤，我们从在线占据地图中提取 3D 遮挡边界，并用其建模隐藏智能体在预测时域内可能到达的区域。我们惩罚在 MPPI 滚动优化中进入这些扩展区域的轨迹，这些轨迹由非线性四旋翼动力学生成，并考虑各旋翼推力限制。我们在仿真和硬件飞行实验中验证了所提方法，完整流程在飞行器上实时运行。结果表明，与基线 MPPI 相比，两种设置下与遮挡边界的间距均有所增加，并且在仿真中避开了一个从遮挡区域出现的智能体。

## Abstract
Autonomous UAV flight through cluttered and partially unknown environments requires reasoning not only about observed obstacles but also about occluded regions that the sensor cannot observe. We present OA-MPPI, an obstacle- and occlusion-aware extension of Model Predictive Path Integral (MPPI) control for quadrotor flight that accounts for potential moving agents emerging from these regions into the vehicle's path. At every planning step, we extract a 3D occlusion boundary from the online occupancy map and use it to model the regions that hidden agents could reach over the prediction horizon. We penalize trajectories that enter these expanding regions within MPPI rollouts generated using nonlinear quadrotor dynamics and accounting for individual rotor thrust limits. We validate the proposed approach in simulation and hardware flight experiments, with the complete pipeline running onboard the vehicle in real time. Results show increased clearance from occlusion boundaries compared to baseline MPPI in both settings, as well as avoidance of an agent emerging from occlusion in simulation.

## 2. 论文提出的方法论

### 2.1 核心思想

- 使用 **Model Predictive Path Integral（MPPI）** 控制，通过大量采样轨迹的前向 rollout 评估非凸、不可微成本。
- 每个规划周期从在线占据地图中提取 **3D 遮挡边界**，并假设隐藏智能体可能以速度上界 `v_target` 从遮挡区域出现。
- 在预测时域内，围绕遮挡边界构造随时间扩张的 **keep-out 区域**，并惩罚进入该区域的轨迹。
- 使用非线性四旋翼动力学和单旋翼推力限制生成可行 rollout，最终只执行更新后动作序列的第一个动作。

### 2.2 感知与遮挡边界提取

- 使用 FAST-LIO 进行状态估计，使用 ROG-Map 维护滑动局部占据栅格。
- 地图单元分为：occupied、known-free、unknown。
- 对障碍物进行膨胀，生成 `M_inf`，用于将无人机近似为点进行碰撞检测。
- **Algorithm 1** 提取 3D 遮挡边界：
  - 将局部地图中的占据单元投影到以无人机为中心的方位/俯仰角分箱；
  - 每个分箱保留最小距离，形成有序距离剖面；
  - 相邻分箱距离跳变超过阈值 `τ` 时识别为轮廓边缘；
  - 从边缘沿径向向外采样长度为 `L` 的门控线段，构成遮挡边界集合 `B`。
- 对 `B` 构建 k-d tree，查询任意点到遮挡边界的最短距离 `d_B(p)`。
- 该方法基于占据地图而非原始 LiDAR 扫描模式，因此对旋转 LiDAR、非重复扫描 LiDAR、深度相机等传感器较友好。

### 2.3 四旋翼动力学与 MPPI

- 状态：`x = [p, q, v, ω]`，即位置、姿态、速度、机体角速度。
- 控制输入：`u = [c, ω_d]`，即集体推力和期望机体角速度。
- 通过可行性投影 `Π(x, u)` 将采样输入映射为满足执行器限制的输入：
  - 饱和角速度；
  - 计算期望力矩；
  - 通过 mixer 矩阵恢复单旋翼推力；
  - 裁剪单旋翼推力后反算可行推力和力矩。
- 使用半隐式欧拉离散传播动力学。
- MPPI 参数示例：`H = 30`，`K = 500`，`Δt = 0.1 s`，`λ = 0.1`。

### 2.4 成本函数

- 目标成本：`ℓ_goal` 和终端目标成本 `ℓ_goal,H-1`，终端项权重更高。
- 速度塑形成本：`ℓ_velocity`，距目标越近，对残余速度惩罚越强。
- 障碍碰撞成本：`ℓ_col = w_col · 1[线段与 M_inf 相交]`。
- 遮挡风险成本：`ℓ_occ = w_col · 1[d_B(p) < r_keep(t)]`。
- keep-out 半径：`r_keep(t) = d_safe + v_target · t`，随时间线性扩张。
- 控制正则：惩罚输入及其变化率。
- 总成本为各 rollout 时域内各项之和。

### 2.5 安全处理

- MPPI 本身不保证硬安全约束，因此增加两层验证：
  1. 对平均后的 nominal 动作序列前向仿真，检查是否碰撞；
  2. 检查每个采样 rollout 是否在时域内碰撞。
- 若平均轨迹不安全，或所有 rollout 均不可行，则命令无人机在上一已验证安全状态悬停。
- 引入 **braking tail**：每个 rollout 后段使用确定性制动策略，使轨迹尽量以零速度终止，并保持姿态水平。
