## 摘要
空中视觉-语言导航要求无人机遵循自然语言指令并在复杂的城市环境中导航。准确的导航依赖于局部和全局空间信息，它们分别支持即时动作定位和长程路径规划。然而，现有的零样本方法通常在单一空间尺度上运行，要么依赖于从当前观测在线构建的局部表示，要么依赖于从历史经验离线构建的全局记忆。为了解决这一局限性，我们提出了AirAnchor，一种通过空间锚点桥接局部与全局空间信息的新范式，并将两者整合到一个共享的导航框架中，实现决策的全面空间定位。AirAnchor包含三个核心组件：（1）查询驱动的空间锚点定位，从视觉观测中识别与决策相关的锚点，并将其组织为局部空间表示；（2）持久对象空间记忆，以增量方式维护对象知识库作为持久的全局空间记忆，并检索与地标相关的空间先验；（3）空间信息感知的导航代理，将局部和全局空间信息显式整合到智能体框架中用于决策。在AerialVLN上的大量实验表明，AirAnchor显著优于现有的零样本基线，验证了所提范式的有效性和效率。

## Abstract
Aerial Vision-and-Language Navigation requires drones to follow natural-language instructions and navigate through complex urban environments. Accurate navigation relies on both local and global spatial information, which support immediate action grounding and long-horizon path planning, respectively. However, existing zero-shot methods typically operate at a single spatial scale, relying either on local representations constructed online from current observations or on global memories built offline from historical experience. To address this limitation, we propose AirAnchor, a new paradigm that bridges local and global spatial information through spatial anchors and integrates both into a shared navigation framework, enabling comprehensive spatial grounding for decision-making. AirAnchor consists of three core components: (1) Query-Driven Spatial Anchor Grounding, which identifies decision-relevant anchors from visual observations and organizes them into local spatial representations; (2) Persistent Object Spatial Memory, which incrementally maintains an object knowledge base as persistent global spatial memory and retrieves landmark-related spatial priors; and (3) a Spatially-Informed Navigation Agent, which explicitly integrates both local and global spatial information into an agentic framework for decision-making. Extensive experiments on AerialVLN demonstrate that AirAnchor substantially outperforms existing zero-shot baselines, validating the effectiveness and efficiency of the proposed paradigm.

## 2. 论文提出的方法论

**核心思想**：以“空间锚点”为共享原语，统一局部与全局空间表征——局部锚点（当前观测中与决策相关的语义−几何参考）组织为 EAG 图；对象锚点持续累积为全局 SOKB 记忆库；最终由导航代理在技能层面统一调用。

AirAnchor 由三个核心组件构成：

**① 查询驱动空间锚点定位（Query-Driven Spatial Anchor Grounding）**

- **锚点查询与选择**：利用 MLLM，以当前导航上下文 Cₜ =（当前子任务、导航进度、规划）为条件，从视觉观测中主动查询 **K = 3 个**决策相关的空间锚点，包括：
  - **对象锚点（object anchors）**：当前视野内与决策相关的空间持久对象，包含语义标签和外观描述；
  - **方向锚点（directional anchors）**：以像素坐标指定的射线方向，用于探测该方向的深度支持的自由移动范围。
- **空间线索定位**：利用深度图 Dₜ 和 UAV 位姿 pₜ 进行反投影（back-projection），计算每个锚点的空间线索：
  - rₜ,ᵢ = (ϕₜ,ᵢ, Δzₜ,ᵢ, dᵪʸₜ,ᵢ, d³ᴰₜ,ᵢ)，分别表示相对方位角、高度差、水平距离和三维距离；
  - 对象锚点通过 Grounded SAM 检测分割对象，得到其 2.5D 空间范围 gᵢ = (Rᵢ, zᵐⁱⁿ, zᵐᵃˣ)；
  - 存在远距离退化机制：当对象超过半数像素超出可靠深度（如 >100 m）时，对象锚点自动退化为方向锚点。

**② 持久对象空间记忆（Persistent Object Spatial Memory）**

- **层级结构**：以**空间对象知识库（SOKB）**为中心，采用“类型 → 实例”的层级存储：M = {Tₘ}，每类 Tₘ 包含对象实例 Oₘ；每个实例存储类型标签库、外观描述库、视觉嵌入库（DINOv2 特征）、2.5D 几何范围及置信度等。
- **对象关联（粗到细）**：
  - **类型级匹配**：基于 GTE-small 文本嵌入的语义相似度选出候选类型；
  - **几何门控**：排除水平分离超过 20 m 的不合理匹配；
  - **细粒度评分函数**：SM(i, j) = wG·SG + wS·SS + wV·SV（综合几何一致性、语义一致性和视觉相似性）；超过阈值 τM 即与现有实例融合，否则新建实例。
- **地标先验检索**：以当前子任务引用的地标为查询（语义相似度 + 距离过滤），检索候选实例集后，用 **MLLM 选择器**联合空间线索与指令隐含的关系进行消歧，选出最佳匹配实例，构成全局先验 Pₜ。

**③ 空间信息感知导航代理（Spatially-Informed Navigation Agent）**

- **闭环智能体框架**，包含三个子机制：
  - **子任务管理层**：在 episode 开始时把指令拆成有序序列 {(sₙ, Lₙ)}（子任务和其引用的地标）；
  - **技能级规划**：由 MLLM 在高层做技能选择，设计四种参数化技能：
    - **Pixel Navigation**（在图像中指定路径点和米制距离）；
    - **Altitude Adjustment**（指定带符号的垂直位移）；
    - **View Rotation**（利用 8 向全景观测进行精细转向推理，角度不受限于采样方向）；
    - **Path Backtracking**（基于当前子任务历史链的恢复机制，自动触发阈值 λstep = 3×子目标数，每子任务最多 2 次）；
  - **技能执行由底层 A* 运动规划器完成**（仅基于当前深度观测临时构建局部自由空间，不使用场景地图或模拟器导航图）；
  - **进度反思模块**：显式比较技能执行前后同一组锚点的空间线索（EAG 与重定位 EAG），使 MLLM 能明确判断“接近、越过、穿过、飞越”等空间语义关系，进而判断子任务是否完成。

## 6. 论文的主要结论与发现

- **范式层面**：空间锚点作为跨尺度统一原语是有效的——局部空间证据可以以轻量方式即时支持决策，并持续累积为全局地标先验，两者可在统一的智能体框架中被天然联合利用。
- **性能层面**：AirAnchor 大幅超越现有零样本空中 VLN 基线（相对提升 39%–52%），并在 Validation Unseen 上**超越全部学习型监督基线**，体现较强的零样本泛化能力。
- **组件贡献层面**：消融实验表明——
  - 空间反思（显式空间上下文对进度推理）缺失时 SR 下降 12.5%；无 EAG 时 SR 下降 18.8%，无不带地面参照时 SR 下降约 15.6%；
  - 移除地标先验造成 NE 增加 14.0 m（全局记忆主要贡献于长距离导航精度）；
  - 无 EAG 导致 SR 下降 18.8%，表明局部几何占主导作用；
  - SOKB 相较扁平知识库存储实例少 20.9%、重复率降低 74.0%、检索准确率提升 18.6%、候选集缩小 53.7%；
  - 所有四种技能均有贡献，其中 View Rotation（视野外转动）影响最大。
- **效率层面**：空锚的轻量级与技能级的抽象设计，使 AirAnchor 用不足 FineCog-Nav 十分之一的 MLLM 调用量就取得了更高性能。

## 7. 优点（续）

2. **方法设计优雅、浑然一体**：以“空间锚点”一种原语同时承担局部“探测点”与全局“地标”的双重角色，避免了异构空间表征之间的转换与对齐问题；EAG 图与 SOKB 之间不是“拼接”而是“累积”关系，架构简洁且逻辑自洽。
3. **零样本范式下极具竞争力**：在完全不训练导航策略的前提下，不仅全面碾压同骨干的零样本基线，还在 Unseen 场景上超越了需要任务专属轨迹监督的 LAG 等学习方法，有力证明了“强视觉感知 + 结构化空间推理”可以替代一部分数据驱动的导航学习。
4. **效率意识突出**：论文没有止步于指标提升，而是系统报告了 MLLM 调用次数与 Token 开销，并展示了相对最强基线一个数量级的工作量压缩，这对实际部署于算力受限的无人机平台具有重要意义。
5. **实验设计严谨、透明度高**：消融覆盖了从感知（锚点类型）、记忆（构造协议、层级结构）、决策（技能集、空间反思）的完整技术链路；同时公开提示模板、报告 episode 顺序扰动测试，体现了较强的可复现意识与学术诚信。
6. **失败分析客观深入**：定性分析不回避方法的短板，明确指出了稀疏定位瓶颈、持久记忆误差传播和空间进度判断模糊三类失败模式，为后续工作指明了改进方向。

## 8. 局限性

1. **空间锚点数量受限（K=3）**：锚点的稀疏性既是效率优势，也是性能天花板。当指令涉及多个分散地标、或在高度对称/自相似的城市布局中（如密集楼群），3 个锚点可能不足以刻画决策必需的几何参照。
2. **对视觉感知质量高度敏感**：锚点定位依赖深度图的可靠性与 Grounded SAM 的分割质量；在远距离、逆光、雨雾等退化条件下，对象锚点被迫降级为方向锚点，丧失语义−几何绑定能力，导航精度可能明显下滑。
3. **MLLM 的空间推理仍是瓶颈**：尽管 EAG 将数值化几何信息显式注入上下文，但 MLLM（Qwen3.6-Plus）对距离、方位和高度差的数值推理能力依然有限；论文也指出空间进度判定在多子任务链末端容易出现“假完成”或“越过目标”的模糊性。
4. **记忆的持久性与误差累积**：SOKB 在新实例写入后不再更新。若首次观测到的地标外观/位置存在误差，该误差将永久固化并影响后续 episode 的检索；虽然冷启动偏差测试表明无系统性顺序依赖，但长序列累积漂移问题未被充分研究。
5. **环境规模与真实性受限**：AerialVLN-S 仅含 17 个紧凑城市场景，且全部来自仿真器。论文未在真实无人机采集数据或开放世界（如大规模城市级）场景上验证，泛化到真实世界的可信度仍有待检验。
6. **缺乏安全性与动态障碍物考量**：底层 A* 规划仅利用当前深度观测构造静态自由空间，未考虑动态障碍物（车辆、行人、其他飞行器）、气象扰动和 UAV 动力学约束，离真实部署尚有距离。
7. **依赖在线商用 API**：使用 Qwen3.6-Plus 在线 API 意味着方法的结果受制于模型版本迭代和 API 服务稳定性，第三方复现时可能难以获得完全一致的性能。

## 9. 关联与可借鉴之处

**与我研究方向的关联（以具身智能、多模态大模型、空间推理与导航决策为交叉背景来看）：**

- **共享原语思想可迁移**：AirAnchor 以“锚点”统一局部与全局空间表征的做法，具有普适启发意义——在设计任何“感知−记忆−规划”分层具身智能体时，应优先寻找跨尺度共享的中间表征，而非分别为感知与记忆设计异构数据结构。
- **“稀疏而非稠密”的建模理念**：论文反复验证了“导航不需要穷尽环境建模”这一假设。这对后续工作是一个重要提醒：在 MLLM 上下文窗口与 token 预算有限的约束下，如何以最小充分信息量支持决策，比如何表征更多信息更值得深入研究。
- **显式空间数值注入优于隐式推理**：论文将锚点的四维空间线索（方位角、高度差、水平距离、三维距离）以结构化文本显式注入 MLLM 上下文，而非让模型“看图猜距”，这一设计显著提升了空间推理可靠度。可进一步探索如何将更丰富的空间关系（如遮挡关系、可见性、相对拓扑）以类似方式数值化表达。
- **进度反思机制可复用**：通过“执行前−执行后”锚点空间线索对比来判定子任务完成与否，是一种轻量、可解释的闭环反馈机制，可推广至其他长程具身任务（如室内 VLN、移动操作）中的里程碑判定。
- **潜在可扩展方向**：可将 SOKB 的粗到细关联机制改造为开放词汇增量学习系统；或将技能集从四种扩展为可学习的参数化动作原语库，与强化学习结合，在锚点表征上训练策略。

## 10. 总结评价

**总体判断**：AirAnchor 是一篇定位清晰、方法优雅、实验扎实的零样本空中视觉-语言导航工作。它的核心贡献不在于提出更强大的 MLLM 推理策略，而在于提供了一个更本质的答案：**空中导航的空间表征应是什么样的**。通过将空间信息刻意稀疏化为“决策相关锚点”，论文巧妙绕开了稠密建图的高成本与异质表征融合的复杂性，同时打破了局部感知与全局记忆之间的壁垒。其在 Unseen 场景超越监督基线、且 MLLM 计算量降低一个数量级的实验结果，有力地支撑了这一设计哲学的有效性。

**从学术价值看**：该工作为 MLLM 驱动的具身智能体提供了一种高效、可解释、可扩展的“感知−记忆−决策”架构范式，对 VLN 社区乃至更广泛的机器人导航领域均有借鉴意义。论文在效率分析、消融完整性、失败案例剖析和提示词公开等方面的做法也值得学习。

**从不足与展望看**：仿真环境验证的局限、动态场景与真实部署的缺失、MLLM 数值推理能力的限制，意味着从“论文效果”到“实飞可用”之间仍有相当距离。未来工作若能结合在线记忆修正机制、更稳健的锚点检测器、以及具备更强几何推理能力的视觉-语言模型，AirAnchor 的范式有望进一步释放潜力。

**综合评分（个人判断）**：
- 创新性：★★★★☆（原语统一视角有新意，但各组件均为成熟技术组合）
- 实验严谨性：★★★★☆（消融全面、对比公平，真实场景验证欠缺）
- 写作与可复现性：★★★★☆（结构清晰，模板公开，依赖在线 API 略影响复现）
- 影响力潜力：★★★★★（“稀疏锚点统一局部与全局”的范式很可能启发后续工作）

总体而言，这是一篇高质量、高完成度的零样本具身导航工作，值得精读并可作为后续研究的重要参照基线。
