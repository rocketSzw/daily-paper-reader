## 摘要
基于模型的强化学习（MBRL）是一类学习方法，它学习环境模型并利用该模型进行动作选择，由于其样本效率，非常适合机器人技术。将学习到的模型与在线规划相结合可以进一步改善动作选择，因为规划器可以利用模型找到比单独学习策略更好的动作。最近将学习策略与在线规划相结合的方法通常学习策略的价值，而不是更强的规划器引导行为。我们提出了CAST（具有交替状态值目标的评论家），它利用规划器引导行为来改进价值学习，同时用当前策略对价值估计进行正则化。CAST用状态值评论家取代了动作值评论家，其训练目标结合了真实规划器引导的转换和当前策略下的想象转换。由此产生的价值函数对应于规划器引导行为与当前策略之间的交替过程，使其能够从更强的规划器行为中受益，同时受到正在学习的策略的正则化。我们在DeepMind Control和HumanoidBench套件上评估了CAST与几种最先进方法的性能，并展示了在物理Unitree Go2四足机器人上执行动态倒立动作的成功迁移。

## Abstract
Model-based reinforcement learning (MBRL) is a family of RL methods that learn a model of the environment and use it for action selection, making it well suited to robotics due to its sample efficiency. Combining learned models with online planning can further improve action selection, as the planner can exploit the model to find better actions than the learned policy alone. Recent methods combining learned policies with online planning typically learn the value of the policy rather than the stronger planner-guided behavior. We present CAST (Critic with Alternating State-value Target), which uses planner-guided behavior to improve value learning while regularizing the value estimate with the current policy. CAST replaces the action-value critic with a state-value critic, trained using a target that combines a real planner-guided transition and an imagined transition under the current policy. The resulting value function corresponds to an alternating process between planner-guided behavior and the current policy, allowing it to benefit from the stronger planner behavior while being regularised by the policy being learned. We evaluate CAST on the DeepMind Control and HumanoidBench Suites against several state-of-the-art methods, and demonstrate successful transfer to a physical Unitree Go2 quadruped performing a dynamic handstand.

- **已有方法的局限**：

  - 这些方法本质上仍学习 πθ 的价值，只是试图让 πθ 逼近 β，并未让价值函数直接受益于 β 的更优表现。
- **本文出发点**：
  - 由于 β（规划器）在训练早期普遍优于 πθ，评论家应学习 β 的价值以辅助策略提升；但直接对 β 进行自举会导致策略更新过大、训练不稳定。
  - 因此提出一种正则化混合 TD 目标：一条真实 β 转移 + 一条 πθ 想象转移，使价值函数对应 β→π →β→π→… 的交替策略过程，兼顾 β 的优越性与 πθ 的稳定性。
  - 同时提出在策略优化侧使用状态值评论家（V），并基于学习到的模型展开 k 步策略梯度，以弥补 V 不能直接对动作求导的问题。

## 2. 论文提出的方法论

### 2.1 核心思想
- 将 TD-MPC2 的动作值评论家 Q(z,a) 替换为**集成状态值评论家 V(z)**，训练目标是"规划器 β 与当前策略 πθ 交替行为"的价值函数。
- 定义混合 Bellman 算子 TCAST = Tβ Tπ（先 β 转移一步，再 πθ 想象转移一步），其不动点 VCAST 介于 Vβ 和 Vπθ 之间，而非等于其中任意一个。

### 2.2 关键技术细节

**(1) 混合价值目标（Hybrid Value Target）**：
- 给定回放转移 (st, rt, st+1)，两阶段目标为：
  yt = rt + γ [ Rξ(zt+1, ãt+1) + γ V̄ψ(dξ(zt+1, ãt+1)) ]
  - 第一步：真实回放转移（由 β 产生）；
  - 第二步：在当前策略 πθ 下用学习模型生成的想象转移。
  - zt+1 = hξ(st+1), ãt+1 ~ πθ(·|zt+1)，目标网络 V̄ψ 用于自举。

**(2) 状态值替代动作值的理由**：
- 学习 Qβ(z,a) 需要在每个 TD 目标处重新运行规划器查询 β 的动作分布，代价极高；
- Vβ(z) 只依赖状态，回放缓冲区中已有 β 访问的状态，训练成本低；
- 用重构的 Q̂(z,a) = Rξ(z,a) + γ V̄ψ(dξ(z,a)) 在需要时恢复动作值信息。
- 规划器终端值也直接使用 V̄ψ(ẑt+H)，免去采样终端策略动作。

**(3) 理论刻画**：
- 在动力学确定、β 与 πθ 固定的假设下，证明 TCAST 是 γ²-压缩算子，具有唯一不动点 VCAST = Tβ Tπ VCAST；
- 不动点展开即为 β 与 πθ 交替采样奖励的折扣累加，使 VCAST 介于 Vβ 与 Vπθ 之间。

**(4) 扩展策略梯度（Expanded Policy Gradient）**：
- 用重构 Q̂(z,πθ(z)) 构建一步目标 J1；
- 将策略在可微模型上展开 Hπ 步，取 Jk(z0;θ) = Σ γi Rξ(z(i),a(i)) + γ^Hπ V̄ψ(z(Hπ)) 作为策略优化目标；
- 默认 Hπ=1，并在消融中研究 Hπ＞1 的影响。

**(5) 算法架构**：
- 沿用 TD-MPC2 的潜空间世界模型（编码器 hξ、动力学 dξ、奖励 Rξ），策略 πθ 为最大熵高斯策略；
- 保持 TD-MPC2 的模型训练损失（一致性、奖励、值分布 CE 损失）、目标网络 Polyak 平均、SimNorm、symlog 分箱等。
- 数据收集不变：策略为 MPPI 提供初始分布，MPPI 执行最终动作。

## 7. 优点

- **角度新颖**：不同于"让策略逼近规划器"或以 BC 替代策略优化，CAST 直接让价值函数学习"更强的行为策略 β"的价值，同时以 πθ 正则化，思路简洁且有理论支撑。
- **理论完备**：给出混合 Bellman 算子的压缩性证明与不动点刻画，明确了所学价值函数的语义（β 与 π 交替过程的折扣回报）。
- **工程简洁**：
  - 用状态值 V 取代动作值 Q，避免在 TD 目标中反复重新查询规划器，显著降计算开销；
  - 改动集中在 TD-MPC2 的评论家与策略优化模块，兼容性强；
  - 规划器终端值直接使用 V，简化了 MPPI 流程。
- **经验验证扎实**：覆盖 14 个任务、5 个基线、2 个任务套件，加真机部署；
- **消融清晰**：验证了"混合目标"、"β 比例"、"展开步数"三个设计维度的必要性，直接支撑关键设计决策。
- **可复现性好**：以 TD-MPC2 等公开代码库为基座，对比公开 benchmark，方便复现。

## 8. 不足与局限

- **实验层面**：
  - 未给出任何任务中 CAST 与 BOOM/BMPC 之间的显著性检验，部分优势可能落在置信区间重叠带；
  - 部分任务（如 H1hand-run）CAST 的 CI 极宽（570±379），说明跨种子方差大，鲁棒性存疑；
  - 消融实验只用了两个任务，对方法普适性的支撑有限；
  - AUC 分析基于归一化均值，未考虑任务级的统计差异。
- **对价值语义的依赖**：VCAST 介于 Vβ 与 Vπθ 之间，如果 β 与 πθ 差异过大，混合策略序列可能既不代表 β 也不代表 π，价值函数的语义在训练过程中不断漂移（因为 πθ 也在实时更新）；
- **对模型误差敏感**：第二段想象转移依赖学到的 dξ 与 Rξ，在模型误差较大时（真实物理环境或高动态任务），目标的偏差会通过自举累积；
- **规划器开销并未减少**：MPPI 规划仍然是每步的主计算开销，CAST 只简化了终端值采样，没有优化规划过程的整体时间成本；
- **Hπ > 1 的探索仅做了后验消融**：未从理论上解释为什么更长展开没有帮助；
- **未报告资源消耗**：没有对比 CAST 与基线间的训练时间、内存、参数量的实际差异；
- **真机实验局限**：只演示了单个技能（动态倒立），没有统计分析失败率或对扰动、地形变化的泛化能力，也未与 baseline 策略真机对照。
