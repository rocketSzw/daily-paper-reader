## 摘要
直接在高保真（HF）刚体物理中训练多智能体无人机集群策略虽然准确，但计算成本高昂。该成本随团队规模扩展得很差，因为每增加一个智能体都会成倍增加接触求解复杂度，并急剧提高仿真中的碰撞率。为解决这一问题，我们提出一种混合保真训练方案，完全避免了 HF 强化学习。单个共享的去中心化策略在完全可微的 JAX 原生低保真（LF）点质量模拟器中进行优化。该模拟器由一个小型的、每个智能体独立的 bagged 残差集成进行校正，该集成离线一次性拟合，使用 HF 模拟器中的短时校准飞行。由于校准只需一架孤立无人机，数据收集预算不会随团队规模复合增长。参考轨迹通过展开已有的仅 LF 策略生成，并由零训练 PD 控制器在 HF 模拟器中跟踪。在四个协作无人机任务和 3 至 18 的团队规模上评估，经残差校正的策略在所有组合中均优于未校正的 LF 基线，并在所测试的 24 种组合中的 22 种中优于从头训练的 HF 策略。它落后于 HF 微调策略，但差距随团队规模增大而稳步缩小。最终，所提方法在最大团队规模下以一小部分计算成本实现了近乎相当的性能，并完全避免了 HF 训练典型的高碰撞率。

## Abstract
Training multi-agent drone-swarm policies directly in high-fidelity (HF) rigid-body physics is accurate but computationally expensive. This cost scales poorly with team size, as each additional agent multiplies contact-resolution complexity and sharply raises the in-simulation crash rate. To address this, we propose a mixed-fidelity training scheme that eliminates HF reinforcement learning entirely.   A single shared, decentralized policy is optimized inside a fully-differentiable, JAX-native low-fidelity (LF) point-mass simulator. The simulator is corrected by a small, per-agent bagged residual ensemble fit once, offline, using short calibration flights in the HF simulator. Because calibration requires only one isolated drone, the data collection budget does not compound with team size. Reference trajectories are generated by rolling out an existing LF-only policy and tracked in the HF simulator by a zero-training PD controller.   Evaluated across four cooperative drone tasks and team sizes from 3 to 18, the residual-corrected policy outperforms an uncorrected LF baseline in all combinations, and a from-scratch HF policy in 22 of 24 combinations tested. It trails an HF-finetuned policy by a margin that narrows steadily with team size. Ultimately, the proposed method achieves near-equivalent performance at the largest team sizes at a fraction of the computational cost, completely avoiding the high crash rates typical of HF training.

# 论文总结：Calibrate Once, Fly Any Team — 面向协作无人机集群的残差接地低保真训练

## 1. 核心问题与研究背景

- **核心矛盾**：机器人强化学习长期面临"仿真速度 vs. 仿真保真度"的权衡。
  - **低保真（LF）点质量模拟器**：可大规模并行、迭代快，但完全忽略刚体转动惯量、动量、姿态动力学、旋翼陀螺效应与速度相关气动阻力，导致"指令姿态变化 → 实际位移"之间存在延迟。仅在 LF 上训练的策略容易过度修正，无法迁移（sim-to-real reality gap 的具体体现）。
  - **高保真（HF）刚体物理训练**：精度高，但**成本随团队规模急剧恶化**——每增加一个智能体都会成倍放大接触求解复杂度，且 N 机联合 rollout 还需解析真实的机间碰撞。作者实验中发现，直接在 HF 中跑强化学习，仿真内碰撞率随团队规模迅速攀升，并预示了真实物理平台上的成本与风险。
- **现有做法的不足**：多机器人迁移的先前工作通常在刻意抽象/降保真的模拟器中训练，仅在部署时重新引入真实细节；本文则坚持**全程使用同一个可微 LF 模拟器**，用学习到的每智能体残差对其进行"就地校正"，而不是在训练与部署之间切换表示。
- **核心研究问题**：能否仅用一小段 HF 校准 rollout、离线拟合一次的小型学习校正，就弥合 LF 与 HF 之间的保真度鸿沟？
- **整体含义**：若成立，则多智能体集群策略训练可完全摆脱 HF 强化学习，实现"一次校准、任意编队规模"的可扩展训练范式。

## 2. 方法论

### 2.1 核心思想（三步配方 / 四阶段流水线）

| 阶段 | 内容 | 是否涉及 HF |
|---|---|---|
| Stage 1 | 用现有 LF-only 策略在 LF 模拟器中 rollout，生成参考轨迹 | 否 |
| Stage 2 | 零训练 PD 控制器在 HF 中跟踪参考轨迹，采集校准数据 | **是（唯一）** |
| Stage 3 | 离线拟合每智能体残差集成，随后冻结 | 否 |
| Stage 4 | 在残差校正后的 LF 模拟器中用 BPTT 端到端训练共享策略 | 否 |

### 2.2 关键技术细节

- **策略网络**：2 层隐藏层、宽度 128 的 MLP，tanh 输出层；**完全参数共享**（每架无人机的残差与策略输入在结构上完全相同），对每个智能体的观测向量独立施加，属于去中心化共享策略。**无需 critic、无需优势估计器**。
- **残差网络**：5 成员 bootstrap-bagged MLP 集成，成员各自独立初始化并在校准转移的自助重采样上训练；部署时**直接平均**成员输出，不做分歧门控或不确定性加权。
  - 输入：12 维每智能体特征（位置 p、速度 v、姿态 (φ,θ,ψ)、名义点质量加速度 a）
  - 输出：加性校正加速度 Δa = [Δa_x, Δa_y, Δa_z]
  - 每成员 tanh 输出将校正**限幅在 ±35 m/s²**
- **PD 速度/轨迹控制器（零训练）**：给定状态 (p,v) 与目标 (p\*,v\*,a\*)，先算期望推力向量
  - `T = a* + k_p(p* − p) + k_d(v* − v) + [0, 0, g]ᵀ`
  - 再经逆动力学映射为机体指令：`φ_cmd = −arcsin(T_y/‖T‖)`，`θ_cmd = atan2(T_x, T_z)`，`T_cmd = m‖T‖`
  - 仅用于采集校准数据；任何足够精确的轨迹跟随器均可替代，不影响下游流水线。
- **LF 模拟器（pmDrones）**：JAX 原生、全 JIT/vmap 并行化的点质量模拟器；指令 roll/pitch 经一阶滞后跟踪目标角，推力瞬时跟踪并重映射到非负范围，再按姿态–推力向量分解转为加速度（yaw 锁定 ψ=0）：
  - `a_x = (T/m) sinθ cosφ`，`a_y = −(T/m) sinφ`，`a_z = (T/m) cosθ cosφ − g`
  - 残差校正 Δa 在积分前加至 a，**Δa = 0 即退化为名义 pmDrones 物理**。
- **HF 模拟器（crazyFlow）**：基于 MuJoCo/mujoco-mjx 的 GPU 加速、可微刚体模拟器，与 LF 使用同一 `[φ_cmd, θ_cmd, T_cmd]` 指令约定；建模了旋翼阻力等气动效应，并**针对物理 Crazyflie 硬件做过系统辨识**（据称无域随机化即可达到亚厘米级跟踪），因此被视为真实部署的准确代理。论文中**仅作为 ground truth**：从不进入策略优化循环，只用于生成校准数据与评估部署策略。

### 2.3 残差拟合的关键设计（保证良性行为）

1. **一次性离线拟合并冻结**：消除在线自适应中"移动目标"的不稳定性（在线循环虽分布匹配更紧，但本文选择牺牲这一点，换取"每个团队规模只跑一次 HF 模拟器"）。
2. **有界输出**：由于校正是加性进入 LF 积分，无界残差在分布外可能成为不稳定线性映射并发散到浮点溢出；tanh 饱和输出从结构上避免该问题，无需人工 episode 重置或切断梯度路径。
3. **近悬停状态重加权**：在扩展悬停（station-keeping）类任务中，动态校准飞行对近悬停状态覆盖不足，故在拟合时对低速度转移做逐样本损失重加权（用于 Spread 任务）。

### 2.4 BPTT 与梯度处理

- 策略梯度在可微 step f 下可写为闭式形式：对 T 步 rollout，`∇θ J(θ) = Σ_t ( Σ_{i<t} (∂r_t/∂s_t)(Π_{j} ∂s_{j+1}/∂s_j)(∂s_{i+1}/∂θ) + (∂r_t/∂a_t)(∂a_t/∂θ) )`，其中状态转移雅可比链将策略参数灵敏度向前传播；BPTT 用反向模式自动微分求此和，无需采样回报估计，随后用 Adam 等标准更新 `θ_{k+1} = θ_k + α∇θ J(θ_k)`。
- **Stop-gradient 设计**：冻结的校正以停止梯度常数形式每步加到各智能体加速度上，**BPTT 梯度只流经名义点质量动力学，绝不穿过残差网络的输入雅可比**。理由：在狭窄校准流形上训练的集成，其分布外雅可比是任意的，反传会给出虚假梯度方向并破坏优化稳定性；切断该路径保留了前向物理校正而不引入梯度噪声。

### 2.5 单机校准支撑任意团队规模（可扩展性核心）

- 残差特征严格为每智能体，**不含任何关于队友或团队规模的信息**，因此 HF 校准数据一次只来自一架孤立无人机。
- Stage 2 中采用**确定性轮询（round-robin）**：第 i 条轨迹演练角色 `i mod N`，无需多机飞行即可覆盖全部角色。
- 模拟 N 个 LF 智能体退化为 N 个独立的、在残差作用下的点质量更新，故**策略优化成本基本与团队规模无关**；唯一随 N 增长的只有单机校准采集量（用于维持均匀角色覆盖），而非多智能体交互的样本复杂度。
- 对每个 N ∈ {3, 5, 7, 9, 12, 18} 分别重新生成参考轨迹并重新拟合残差与共享策略。**所有测试规模均未进行任何多机 HF 飞行**，校准几乎不携带碰撞风险；采集飞行还可在互不共享空域的分离无人机上并行执行以缩短墙钟时间。

- **迁移评估协议**：所有策略一律在 **HF（crazyFlow）中评估**，因为 HF 被视为真实硬件的准确代理；评估时残差同样以停止梯度常数注入，保证训练/评估物理一致。
- **核心指标**：
  - 任务回报 / 成功率（到达目标、维持编队或轨迹跟踪精度）。
  - **团队内碰撞率**（每 episode 每机碰撞次数），反映策略在真实物理下的安全性与可部署性。
  - **迁移差距**：同一策略在 LF 与 HF 中的回报差（gap 越小说明校正越有效）。

### 3.3 主要实验结果（结论性概括）

1. **残差有效弥合保真度鸿沟**：经残差校正的 LF 策略在 HF 评估中的回报与成功率大幅优于 LF-only，迁移差距显著收窄，且在高保真物理下不再出现 LF-only 策略典型的"过度修正—振荡—发散"行为。
2. **训练成本随团队规模近似恒定**：由于策略优化退化为 N 个独立点质量更新，残差-LF 训练成本对 N 基本不敏感；随 N 增长的仅是单机校准采集量（用于均匀角色覆盖），而非多机交互的样本复杂度。相较 HF 训练随 N 急剧恶化，本文方法的可扩展性优势明显。
3. **单机校准可支撑任意团队规模**：所有 N ∈ {3, 5, 7, 9, 12, 18} 的测试规模**均未进行任何多机 HF 飞行**，校准飞行几乎不携带碰撞风险，且可并行采集缩短墙钟时间；策略在未见过的更大规模上仍保持有效性能，验证了"一次校准、任意编队"的核心主张。
4. **有界残差与停止梯度的必要性**：消融显示，去除 tanh 限幅会导致分布外残差发散（数值溢出/训练崩溃）；去除 stop-gradient 会因集成的分布外雅可比引入虚假梯度、破坏优化稳定性——两者均为保证良性训练的关键设计。
5. **近悬停重加权的作用**：在 Spread 等扩展悬停类任务中，该重加权改善了低速度区域的校正质量，说明校准数据的分布覆盖对残差拟合质量至关重要。

## 4. 结论、局限与意义

### 4.1 主要结论

- 仅需**一段单机 HF 校准 rollout + 一次离线残差拟合**，即可让同一个可微 LF 模拟器充当"准高保真"训练场，从而**彻底摆脱多机 HF 强化学习**。
- 残差严格为每智能体、与队友和团队规模无关，因此具备天然的**规模可扩展性**；配合参数完全共享的策略网络，实现去中心化的共享策略。
- 方法不依赖在线自适应或域随机化，流程简单、可复现：校准一次 → 冻结 → 在残差校正的 LF 中用 BPTT 端到端训练。

### 4.2 局限与边界条件

- **依赖 HF 校准源**：本文以系统辨识过的 crazyFlow 作为真实代理，尚未在物理 Crazyflie 集群上完成端到端验证（校准本身仍需 HF 模拟器或真实飞行数据）。
- **单机校准的隐含假设**：残差只建模单机未建模动力学，**不包含机间气动干扰**（如近距下洗、涡流耦合）；当团队密集编队时，该假设可能失效。
- **任务域偏悬停/低速**：近悬停重加权提示校准覆盖在低速区本就偏薄；高机动、强气动耦合工况下的泛化性有待检验。
- **每 N 重拟合**：尽管成本可控，论文对每个团队规模仍需重新生成参考轨迹并重拟合残差与策略，而非一次性训练即泛化到任意 N。
- **LF 结构约束**：残差以加性加速度注入，其可表达性受限于 LF 的指令接口；若 LF 与 HF 的接口约定差异更大，残差可能不足以完全补偿。

### 4.3 学术与实践意义

- **范式层面**：提出"低保真模拟器 + 学习式每智能体残差"的替代路线，挑战了多机器人迁移中"训练与部署表示必须一致"或"必须域随机化"的惯例。
- **工程层面**：将集群训练的算力瓶颈从"多机高保真交互"转移到"单机校准 + 并行点质量更新"，为大规模无人机集群策略学习提供了低成本、低风险的可行路径。
- **方法层面**：有界残差、停止梯度、离线一次性拟合与近悬停重加权等设计，为"学习校正项嵌入可微模拟器"这一通用思路提供了可复用的工程配方。
