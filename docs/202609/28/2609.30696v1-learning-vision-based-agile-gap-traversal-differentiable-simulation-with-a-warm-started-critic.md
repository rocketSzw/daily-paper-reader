## 摘要
穿越狭窄间隙对自主四旋翼无人机而言具有挑战性，尤其是当控制指令直接来自高维视觉观测时。现有的端到端方法通常依赖于行为克隆，或通过可微仿真进行完整轨迹展开的时间反向传播（BPTT），这可能限制策略性能或带来高昂的训练成本。我们提出一个两阶段强化学习框架，用于更高效地训练以自我为中心的视觉运动间隙穿越策略，该框架利用可微仿真中的准解析策略梯度（QPG）和评论家热启动。该框架利用 QPG 避免通过视觉渲染进行反向传播，从而降低计算和内存成本，同时提高样本效率。在第一阶段，使用包括间隙几何信息在内的特权观测来训练专家 actor 和评论家。与先前的间隙穿越方法不同，我们利用 QPG 的训练不需要沿优化后的参考轨迹重置智能体。在第二阶段，使用来自两个以自我为中心相机的二值间隙掩码和低维观测来训练视觉策略，同时其特权评论家从第一阶段热启动。与冷启动评论家或使用完整轨迹展开的 BPTT 相比，这显著提高了训练效率和穿越成功率。当系统参数变化时，我们的框架不需要重新训练专家 actor，从而比基于动作监督的最先进视觉间隙穿越方法更高效地泛化到不同无人机平台。学习到的视觉策略还能泛化到具有未见形状的间隙。大量真实世界实验进一步证明，使用在线渲染的二值掩码可以实现稳健的间隙穿越。除间隙穿越之外，所提出的框架具有通用性，可扩展到其他视觉运动机器人学习任务。

## Abstract
Traversing narrow gaps is challenging for autonomous quadrotors, especially when control commands come directly from high-dimensional visual observations. Existing end-to-end methods often rely on behavior cloning or full-rollout backpropagation through time (BPTT) via differentiable simulation, which can limit policy performance or incur high training costs. We propose a two-stage reinforcement learning framework for more efficient ego-centric visuomotor gap-traversal policy training, leveraging quasi-analytical policy gradients (QPG) via differentiable simulation and critic warm-starting. The framework utilizes QPG to avoid backpropagation through visual rendering, reducing computation and memory costs while improving sample efficiency. In the first stage, an expert actor and critic are trained using privileged observations, including gap geometry. Unlike prior gap-traversal approaches, our training utilizing QPG does not require resetting the agent along optimized reference trajectories. In the second stage, a visual policy is trained using binary gap masks from two ego-centric cameras and low-dimensional observations, while its privileged critic is warm-started from the first stage. This substantially improves training efficiency and traversal success compared with cold-starting the critic or using full-rollout BPTT. Our framework does not require retraining the expert actor when system parameters change, enabling more efficient generalization across drone platforms than state-of-the-art visual gap-traversal methods based on action supervision. The learned visual policy also generalizes to gaps with unseen shapes. Extensive real-world experiments further demonstrate robust gap traversal using binary masks rendered online. Beyond gap traversal, the proposed framework is generic and can be extended to other visuomotor robot learning tasks.

## 1. 核心问题与研究动机

- **任务背景**：自主四旋翼穿越狭窄间隙（gap traversal）是受限环境导航中最具挑战性的任务之一。当间隙宽度远小于飞行器横向尺寸时，智能体必须主动调整姿态（roll/pitch）才能通过，需要稳健的 SE(3) 规划与控制能力。
- **现有方法的痛点**：
  - **传统模块化流程**（规划 + 跟踪）会在系统各处累积并放大误差。
  - **模型无关强化学习**（如 PPO）依赖高方差策略梯度估计，训练不稳定、样本效率低。
  - **行为克隆 / 策略蒸馏**（如文献 [14][15]）把专家策略蒸馏为视觉策略，但监督信号只对训练时的动力学最优，**系统参数变化时无法适应**；且训练专家需要轨迹优化与沿参考轨迹重置智能体，带来额外计算开销。
  - **完整轨迹 BPTT**（可微仿真）虽提供低方差梯度，但长时域反传会导致梯度爆炸/消失、易陷局部极小，训练成本高。
  - **APG/SHAC 类方法**：SHAC 通过短时域截断 + 价值函数缓解上述问题，但其视觉版本仍依赖 critic；随机初始化的 critic 在训练早期无法提供有效引导。
- **核心挑战**：如何从高维视觉观测（且与敏捷运动强耦合）直接学习穿越策略，同时兼顾训练效率、样本效率、跨平台泛化与真实部署鲁棒性。
- **整体含义**：论文提出一种**两阶段强化学习框架**，结合可微仿真的准解析策略梯度（QPG）与**特权 critic 热启动**，以更低的训练成本实现从二值掩码视觉观测到敏捷间隙穿越策略的学习，且框架具有通用性。

## 2. 方法论

### 2.1 核心思想
- **两阶段训练**：
  - **第一阶段**：在**特权观测**（含间隙几何）下用 QPG 训练专家 actor 和 critic（对称 actor-critic）。
  - **第二阶段**：训练**视觉策略**，输入两个自视角相机的二值间隙掩码 + 低维观测，采用**非对称 actor-critic**结构，并**热启动**第一阶段的特权 critic（只复制 critic，不复制 actor）。
- **关键动机**：critic 看到的是特权状态（与视觉观测无关），因此可以为具有不同观测的 actor 提供可迁移的价值先验；热启动的 critic 从第一次策略更新起就提供"任务塑形"的终端伴随梯度。

### 2.2 问题形式化
- 四旋翼建模为刚体，状态 $x_{i+1} = f(x_i, u_i)$，状态维度 17（位置、速度、四元数、角速度及其导数、推力）。
- 每个控制步包含 $N$ 个物理子步；策略为高斯分布，通过重参数化技巧输出控制量：
  $u_k = \tanh(\mu_\theta(o_k) + \epsilon_k \sigma_\theta)$
- 部署策略输入：二值门掩码 $I_k$、roll $\phi_k$、pitch $\theta_k$、加速度计读数 $\tilde{a}_k^b$、机体坐标系目标位置 $p^b_{goal,k}$、上一动作 $u_{k-1}$；输出：集体推力与机体角速率（CTBR）指令。
- 穿越成功的定义：包围盒质心穿过开口，且包围盒与门框在任意时刻均不相交，之后在目标点稳定悬停。

### 2.3 可微仿真中的策略优化（QPG）
- 基于 SHAC 的 actor 损失：短时域 $h$ 内的折扣奖励之和，加上终端 critic 值 $V_\phi(c_{k_0+h})$。
- 完整动作导数包含"观测反馈项"；**QPG 将观测做 stop-gradient**（$o_k \leftarrow \text{sg}(o_k)$），移除反馈项，从而**避免通过视觉渲染反向传播**，同时保留一阶梯度。
- 终端伴随从 critic 出发（$\partial L_\theta/\partial x_{k_0+h} = -\gamma^h \partial V_\phi/\partial c \cdot \partial \Psi/\partial x$），再沿仿真器向后递推得到状态与动作伴随；**超过短时域的信用分配完全通过 critic 传递**。
- critic 在策略更新后用 TD-λ（$\lambda=0.95$）更新。

### 2.4 简化 Jacobian（降低梯度计算成本）
- 完整模型包含内环动力学（角速率二阶低通滤波、推力一阶延迟）与物理子步，梯度刚性强、计算昂贵。
- 采用**简化代理模型** $f^{sim}$ 做反传：假设角速率与推力瞬时跟踪，无物理子步，用半隐式欧拉在 $\Delta t_c$ 上积分。
- 通过**状态对齐**保证前向值一致：
  $x_{k+1} = x^{sim}_{k+1} + \text{sg}(x^{full}_{k+1} - x^{sim}_{k+1})$
- 反传只经过简化模型 Jacobian，兼顾有效性与稳定性。

### 2.5 视觉观测渲染器
- 使用**二值门掩码**而非深度/真实图像：保留间隙几何、规避纹理/光照/运动模糊的 sim-to-real 差距、可解析并随仿真器向量化编译。
- 通过针孔投影 + 光栅化构造开口边缘掩码，像素到边缘的平方距离判定是否属于掩码；对相机后方角点做平面截断修正，避免错误连线。
- 两个相机各自渲染后**拼接**作为策略视觉输入。

### 2.6 奖励函数
- 总奖励为加权和：进度奖励 $r_{prog}$（速度与目标方向内积）、对齐奖励 $r_{align}$（惩罚相对门的 roll/pitch 偏差）、间隙余量奖励 $r_{margin}$（鼓励各角点远离开口边缘）、悬停奖励 $r_{hover}$、动作正则 $r_{action}$。
- 权重：$w_{prog}=1.0,\ w_{align}=8.0,\ w_{margin}=12.0,\ w_{hover}=10.0,\ w_{action}=0.01$。

### 2.7 训练细节
- 基于 JAX 实现；控制频率 100 Hz，episode 长度 500 步，短时域 $h=64$。
- 策略/ critic 初始学习率分别为 $5\times10^{-4}$ 与 $2\times10^{-3}$，线性衰减；Adam 优化器，训练 25,000 迭代。
- 折扣因子 $\gamma=0.99$；1024 个并行环境。
- 第二阶段网络：CNN（32/64/64 卷积核，8/4/3，步长 4/2/1）+ GRU（256 单元）+ 两层 MLP；双相机中心前向 10 cm、上 2.9 cm、左右各 4.2 cm，光轴外张 ±45°，鱼眼用匹配 FOV 的针孔模型近似。

## 6. 主要结论与发现

- **QPG 优于 BPTT 与 PPO**：第一阶段中 QPG 约 12 分钟达 0.8 成功率并饱和至约 1.0；BPTT 虽最终接近但需 16,000 epoch；PPO 在 19,500 epoch 前成功率为 0；去掉 critic 梯度（w/o V-grad）曲线早期上升但饱和在 0.38，说明价值梯度对长时域信用分配不可或缺。
- **热启动 critic 显著提升视觉策略学习**：第二阶段本文方法峰值成功率 **0.893**；冷启动 critic 优于 BPTT 但仍不及两阶段方法；冻结 critic 长期低于 0.25（价值函数固定在专家状态分布，无法适应视觉策略）；双相机略优于单相机（视野更宽，穿越时门保持在视野内）。
- **简化模型加速训练**：使用简化 Jacobian 计算梯度可提升训练效率而不牺牲成功率。
- **泛化能力强**：同一策略无需重训即可穿越椭圆、梯形、三角形等**未见形状**的间隙。
- **跨平台优势**：系统参数变化时，仅需用旧 critic 重跑第二阶段，无需重训专家 actor；相比行为克隆（旧教师）在参数失配时性能显著下降，本文方法性能基本不退化。
- **真实部署可行**：在高度受限空间中，以最高约 3.5 m/s 速度完成 45°/60°/70°/80° 门 roll 角的真实穿越与悬停。

## 7. 优点

- **算法设计层面**：
  - 将 QPG（短时域 + critic 自举）用于视觉敏捷穿缝，**避免通过视觉渲染反传**，降低计算与内存开销，并保持样本效率。
  - **特权 critic 热启动**思路简洁有效：critic 与观测解耦，可跨观测模态复用，为视觉策略提供任务塑形梯度。
  - **无需轨迹优化与沿参考轨迹重置**，也无需策略蒸馏，流程比 RL-模仿两阶段管线更简洁。
  - **简化 Jacobian + 状态对齐**在保证前向精度的同时降低梯度计算成本，是工程上实用的技巧。
- **实验设计层面**：
  - 消融完整（critic 冷/热启动、冻结、相机数量、梯度模型），基线选择有代表性。
  - 同时验证了仿真泛化（未见形状）、跨平台迁移与真实飞行，论证链完整。
  - 使用二值掩码替代深度/RGB，降低 sim-to-real 视觉差距，便于向量化。
- **通用性**：框架不限于穿缝任务，可扩展至其他视觉运动机器人学习任务。

## 8. 不足与局限

- **感知层面**：真实实验中的二值门掩码由**动捕系统在线渲染**，并非机载相机实际感知结果，忽略了检测误差、延迟、遮挡、运动模糊等真实感知缺陷，sim-to-real 的视觉闭环尚未完整验证。
- **目标依赖**：策略仍接收目标的相对位置（机体坐标系），未实现完全从视觉推断目标；作者指出可借鉴文献 [32] 的相机配置来移除该依赖。
- **泛化验证范围有限**：未见形状泛化仅在仿真中测试；跨平台实验的统计细节（种子数、置信区间）较少。
- **真实实验覆盖有限**：仅在矩形门、特定受限空间、单一平台、4 个 roll 角下验证；速度上限 3.5 m/s 低于仿真中的 5.0 m/s。
- **报告完整性**：未明确给出 GPU 数量、总训练时长与能耗，复现成本评估受限。
- **简化模型的偏差风险**：简化 Jacobian 与前向精确模型之间存在不一致，虽用状态对齐缓解，但在动力学极端变化（如强延迟、低带宽）下可能影响梯度质量。
- **对比公平性**：BPTT 基线为"无价值自举的完整 episode BPTT"，PPO 基线在文中配置下长期零成功率，其超参是否对其最优未充分讨论。
