## 摘要
本文提出了一种面向微型飞行器的制导算法，使其仅依靠机载感知即可在未知、杂乱环境中运行。该方法基于最初源自空气动力学势流理论的面元公式，能从局部感知到的障碍物生成平滑、无碰撞的制导向量。通过利用机载激光雷达测量在线构建并更新障碍物表示，该方法被扩展至未知环境。由此得到的避障场与标称制导向量场相结合，以生成最终控制输入。该系统在两种场景下的室内飞行试验中进行了实验验证：航点导航和方向制导。在两种情况下，飞行器仅使用机载感知就实时避开所有障碍物并成功完成任务。结果表明，该方法计算轻量，适合机载实现，其中点云处理被认为是主要的实际限制。这些结果支持了在未知环境中进行轻量级机载制导的可行性。

## Abstract
This paper presents a guidance algorithm for micro aerial vehicles operating in unknown, cluttered environments using only onboard sensing. The method is based on a panel formulation originally derived from aerodynamic potential-flow theory and generates smooth, collision-free guidance vectors from locally perceived obstacles. The approach is extended to unknown environments by constructing and updating the obstacle representation online from onboard LiDAR measurements. The resulting obstacle-avoidance field is integrated with a nominal guiding vector field to produce the final control input. The system is experimentally validated in indoor flight tests under two scenarios: waypoint navigation and directional guidance. In both cases, the vehicle successfully completes its task while avoiding all obstacles in real time using only onboard perception. The results demonstrate that the method is computationally lightweight and suitable for onboard implementation, with pointcloud processing identified as the main practical limitation. These results support the feasibility of lightweight onboard guidance in unknown environments.

## 1. 核心问题与整体含义

- **研究动机**：微型飞行器（MAV）在搜救、灾害救援等场景中日益重要，但往往需要在无先验地图的未知杂乱环境中作业（如森林、灾区），预先测绘不可行，因此机载“感知—避障”能力是任务成功的关键。
- **用户背景**：MAV 常由缺乏飞行经验的现场人员部署，亟需能自动处理低级避障、让操作者专注于高层任务目标的制导系统。
- **现有方法的两难**：
  - **优化类方法**（FASTER、MADER、HDSM、DYNUS、SANDO 等硬约束；EGO-Planner、EGO-Swarm、SUPER 等软约束）通常依赖环境地图构建与在线优化求解，算力需求大，受限于小型 MAV 的机载硬件，重规划频率受限。
  - **反应式方法**（CBF 安全滤波、速度障碍/ORCA、势场法）算力低、延迟短、无需地图，但存在完备性、最优性、振荡及无连续时间安全保证等问题，势场法尤其易陷入局部极小值。
- **整体含义**：本文旨在验证一种**计算轻量、完全机载、无需先验地图**的 MAV 制导方案在未知环境中的可行性，并明确其实际限制。

## 2. 方法论

### 2.1 核心思想
- 采用**两个无局部极小值（各自假设下）且算力友好的向量场叠加**：
  - **标称运动**：源自 [13] 的收敛制导向量场（guiding vector field）。
  - **避障**：源自 [14,15] 的谐波势流/面板法（PGFlow）。
- 避障场由机载 LiDAR 在线构建的障碍面板生成，与标称向量场叠加得到最终速度指令。

### 2.2 标称运动（导引向量场）
- 将目标表达为点流形或线流形，计算法向与切向向量：
  - 点流形：∇Fp,1=[1,0,0]ᵀ、∇Fp,2=[0,1,0]ᵀ、∇Fp,3=[0,0,1]ᵀ，τp=0。
  - 线流形（平行于 xOy）：∇Fl,1=[0,0,1]ᵀ、∇Fl,2=[−sinα, cosα, 0]ᵀ，τl=[cosα, sinα, 0]ᵀ。
- 速度指令：
  - 点：V = −(vd·kc/3)·Σ Fp,i·∇Fp,i/‖∇Fp,i‖
  - 线：V = vd·τl/‖τl‖ − (kc/2)·Σ Fl,i·∇Fl,i/‖∇Fl,i‖，实际简化为沿切线方向 V = vd·τl/‖τl‖。
- 参数：vd 为期望速度，kc 为收敛增益。

### 2.3 避障：PGFlow（面板法）
- 借鉴流体力学，将障碍物建模为二维平面内的一组**一维面板**，每个面板等效为线源/涡，生成无旋速度场。
- 仅使用 x、y 分量（水平面避障更关键）；z 轴用更简单的斥力机制处理，以降低三维复杂度。
- 面板控制点取面板中点：pci := (poi2−poi1)/2 + poi1。
- 速度指令：
  - ẋ = Vx − Σ (λi/2π)∫ ∂/∂x ln Ri dli
  - ẏ = Vy − Σ (λi/2π)∫ ∂/∂y ln Ri dli
- 面板强度 λi 通过求解线性方程组确定，使每个控制点法向速度 Vi ≥ 0：
  - λi/2 + Σ_{i≠j} (λj/2π)·Iij = −Vi + V(xci, yci)·nᵢ
  - 其中 Iij 为面板交互矩阵，nᵢ 为面板外法向。
- **安全保证条件**：障碍物须按飞行器特征尺寸的至少一半进行膨胀（图 3 中红色区域）。

### 2.4 LiDAR 在线障碍提取
- 传感器：Livox MID-360 固态 LiDAR，约 10 Hz；C++ 驱动（基于 Livox-SDK2），经 ZeroMQ 发布。
- 状态由 OptiTrack 经 XBee 传输并与 IMU 融合，点云变换到统一 ENU 坐标系。
- 处理流程（图 5）：
  1. **体素降采样**：体素边长 s=0.2 m，体素索引 Ki = 1000003·⌊xi/s⌋ + 1001·⌊yi/s⌋ + ⌊zi/s⌋，同体素点取质心。
  2. **ROI 裁剪**：x,y ∈ [−3,3] m，z ∈ [0.5,3] m；剔除距传感器 <0.2 m 的点。
  3. **投影与聚类**：投影到水平面后聚类。
  4. **迭代 RANSAC 直线拟合**：从单个簇中提取多个平面面。
  5. **几何一致性过滤**：最小长度、点支撑、连续性、厚度等。
  6. **时序线段地图**：匹配观测更新已有线段，未匹配则新建；重复检测提升置信度，短暂遮挡在一定时长内保留。
- 输出：带障碍索引的线段集合（端点、切向、外法向、置信度），直接送入 PGFlow。
