## 摘要
许多物理和生物系统——泡沫、膜、弹性壳或组织片层——都可以在数学上描述为二维曲面。这些曲面可以承载复杂动力学，例如反应-扩散系统，并经历剧烈变形。在此，我们提出 triangulax，一个用于模拟和几何处理的开源 Python 库，它使用三角网格对曲面进行离散化，可在 https://github.com/nikolas-claussen/triangulax 获取。它结合了两个特性。第一，离散微分几何提供无坐标离散化，从而能够模拟强烈变形的曲面。第二，该库构建于机器学习框架 JAX 之上，因此基于网格的能量以及整个模拟都可以自动微分（包括具有随机力或拓扑修改的模拟）。这通过自动计算力简化了多物理场模拟，并允许将模型参数拟合到实验数据或设计目标。我们实现了一种在强烈变形曲面中保持网格质量的算法，并将其应用于与膜上浓度场耦合的膜力学模型。我们针对精确解和现有软件验证了我们的方法，并展示了 triangulax 在一系列问题中的应用，包括膜力学、顶点模型以及形状变形弹性体片材的逆向设计。

## Abstract
Many physical and biological systems -foams, membranes, elastic shells, or tissue sheets- can be mathematically described as 2D surfaces. These surfaces can host complex dynamics, like reaction-diffusion systems, and undergo drastic deformations. Here, we present triangulax, an open-source Python library for simulations and geometry processing that discretizes surfaces using triangular meshes available at https://github.com/nikolas-claussen/triangulax. It combines two features. First, discrete differential geometry provides coordinate-free discretization, which allows simulating strongly deforming surfaces. Second, the library is built on the machine-learning framework JAX, so mesh-based energies and entire simulations can be differentiated automatically (including simulations with stochastic forces or topological modifications). This simplifies multi-physics simulations by computing forces automatically and allows fitting model parameters to experimental data or design objectives. We implement an algorithm to preserve mesh quality in strongly deforming surfaces and apply it to a model of membrane mechanics coupled to an on-membrane concentration field. We validate our approach against exact solutions and existing software, and demonstrate triangulax across a range of problems, including membrane mechanics, vertex models, and inverse design of a shape-morphing elastomer sheet.
