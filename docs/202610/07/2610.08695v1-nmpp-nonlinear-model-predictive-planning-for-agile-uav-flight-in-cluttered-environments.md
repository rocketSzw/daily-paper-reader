## 摘要
让四旋翼在杂乱环境中飞行，不仅需要基于感知到的障碍物规划无碰撞参考轨迹，而且该参考轨迹还需动态可行并处于飞行器执行机构限制之内，以便控制器能够精确跟踪。现有方法要么在凸走廊内优化平滑多项式，这限制了敏捷性；要么将障碍物视为软代价，与跟踪性能进行权衡。我们提出一种非线性模型预测规划（NMPP），将感知到的障碍物作为硬几何约束，并将全状态参考交给一个不感知障碍物的 SE(3) 控制器。我们的规划器相比线性模型预测控制轨迹规划器，位置 RMSE 降低 58–67%；相比多项式轨迹规划器，RMSE 降低 41–70%。它还能以最高 9.5 m/s 的速度无碰撞完成所有森林飞行，并在更激进的速度剖面下达到 86% 的飞行成功率，而当前最先进的规划器仅有 26% 的成功率。真实世界部署表明，在未知杂乱环境中以最高 5.5 m/s 飞行时能够可靠执行。

## Abstract
Flying a quadrotor through a cluttered environment requires not only planning a collision-free reference trajectory based on perceived obstacles, but the reference also needs to be dynamically feasible and within the actuation limits of the vehicle, so that the controller can track it precisely. Existing methods either optimize a smooth polynomial inside a convex corridor, which limits agility, or treat obstacles as soft costs traded against tracking performance. We propose a Nonlinear Model Predictive Planning (NMPP) that imposes perceived obstacles as hard geometric constraints and hands a full-state reference to an obstacle-blind SE(3) controller. Our planner achieves a 58-67 % lower position RMSE than a linear Model Predictive Control trajectory planner and a 41-70 % lower RMSE than a polynomial trajectory planner. It also completes all forest flights with up to 9.5 m/s speed without collisions, and achieves 86 % flight success rate under a more aggressive speed profile where a state-of-the-art planner has only 26 % success rate. The real-world deployment showed reliable execution flying up to 5.5 m/s in an unknown cluttered environment.

# NMPP 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **应用背景**：多旋翼无人机越来越多地用于搜索救援、基础设施巡检等任务，需要在**杂乱且初始未知**的环境中飞行。飞行速度直接决定有限续航内能覆盖的范围，因此需要让平台逼近其动态极限运行。
- **核心矛盾**：高速穿越障碍要求参考轨迹同时满足三个条件：
  1. 基于感知障碍的无碰撞；
  2. 动态可行（符合非线性四旋翼动力学）；
  3. 在执行机构（推力、角加速度等）限制之内，以便控制器精确跟踪。
- **现有方法的两难**：
  - **走廊类多项式优化**（如 GCOPTER、SUPER、Bubble Planner）：把轨迹限制在自由空间的凸子集内，消除非凸性并支持在线计算，但平滑多项式表示**限制了飞行器逼近动态极限的能力**。
  - **把避障放入控制回路**（软代价、CBF 安全滤波器、GMPPI）：保留了对当前感知的反应能力，但障碍仅作为**软代价与跟踪性能权衡**，避障没有保证。
- **流程割裂问题**：常见做法是先在栅格/地图中找无碰撞路径，再转成控制器可跟踪的轨迹——结果"路径忽略动力学、轨迹忽略障碍"。
- **三个技术难点**：
  1. 障碍周围的自由空间是**非凸**的，硬约束易导致局部极小与不可行；
  2. 传感器返回的障碍数量**可变且无上界**，而问题规模必须固定以保证计算时间可预测；
  3. 在离散预测节点上可行的解，**可能在两个节点之间穿入障碍**。
- **整体含义**：本文主张把避障与动态可行性放进**单一机载优化**，用 NMPC 作为"规划器"（输出全状态参考）而非"控制器"（输出执行器指令），并用硬几何约束保证避障。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
- 提出 **NMPP（Nonlinear Model Predictive Planning）**：将 NMPC 用作**轨迹规划器**，为独立的、**不感知障碍的 SE(3) 几何控制器**提供**全状态参考**（位置、姿态、速度、角速度、推力），而不是输出执行器命令。
- 每次优化用**上一次生成的预测**（shift + resample）初始化，而非用含噪状态估计，从而允许施加精确的障碍约束。
- 感知到的 LiDAR 障碍以**硬几何约束**形式进入优化，同时辅以软障碍势函数与软化的加速度级 HOCBF 条件；完整障碍集用于节点间轨迹校验。

### 2.2 增广 NMPC 模型（关键创新）
- 传统形式以推力为控制量 u = f；本文**把推力增广进状态、以其变化率作为控制输入**：
  - 状态 `x = (p, q, v, ω, f)`，控制 `u = ḟ ∈ R⁴`。
- 好处：求解器在节点间保持控制量恒定。若以推力为控制量，推力在每个节点跳变，导致线/角加速度跳变，轨迹仅 p ∈ C¹、ω ∈ C⁰；改用推力变化率后，参考变为 **p ∈ C²、ω ∈ C¹**，更平滑、更易跟踪。
- 对动力学微分得到**加加速度（jerk）与角加加速度**均**线性依赖于 ḟ**（公式 6a、6b），因此可作为线性约束处理。

### 2.3 约束设计
- **硬约束（精确施加）**：
  - 单旋翼推力上下限 `fk ∈ [fmin, fmax]`；
  - 总推力 `Tk ∈ [Tmin, Tmax]`；
  - 角加速度 `J⁻¹Mfk ∈ [-ω̇max, ω̇max]`（为保持线性，忽略陀螺项 ω×Jω）。
- **软约束（带松弛变量）**：机体角速率、线速度、倾角 `[R(q)]₃₃ ≥ cosθmax` 及其八边形线性外近似（tilt polygon）。允许在切换更严格剖面时临时越界而不致不可行。
- **加速度限制的间接施加**：
  - 垂直加速度通过**收紧总推力界限**（式 9）；
  - 水平加速度通过**收紧倾角上限**（式 10）。
- 由于 `[R(q)]₃₃ = 1 − 2(qx² + qy²)`，倾角约束等价于 `qx² + qy² ≤ sin²θmax/2`，可用线性外近似（式 8d）在 QP 的线性一般约束块中限界，同时保留式 8c 的精确条件。

### 2.4 避障方法（感知—规划耦合）
- **点云处理**：去除机体与地面点 → 限制在航向对齐的局部 ROI → 累积 0.20 s 非重叠窗口（弥补 Livox MID-360 非重复扫描）→ **距离自适应体素降采样**（近处精细、远处粗糙）→ 欧氏聚类得到障碍簇 C。
- **障碍表示**：每个簇用**一个或多个有向椭球**近似（比球体更贴合树干、杆、墙等细长结构）。PCA 确定朝向，中心与半径覆盖全部点，并加**膨胀安全裕度**（考虑机体尺寸）。椭球定义为 `(ξ−cj)ᵀAj(ξ−cj) ≤ 1`，障碍函数 `hj(p) = (p−cj)ᵀAj(p−cj) − 1`，`hj ≥ 0` 为安全区。地面单独建模为高度 zg 的水平面，最小允许高度 `zmin = zg + dg`。
- **硬几何约束**：对每个选中椭球，在每个预测节点施加 `hj(pk) ≥ 0`。
- **软障碍势函数**：定义近似径向距离 dj,k 与有界势 `Jobs,j,k = ½[1 − tanh(αobs/2·(dj,k−εobs))]`，节点处代价 `Jobs,k = Σ J²obs,j,k`，促使优化器在硬约束激活前**提前开始规避**。
- **加速度级 HOCBF 条件**：由 hj 的一阶、二阶导数构造 `ḧj,k + kvel ḣj,k + kpos hj(pk) ≥ −sj,k`，用松弛变量 sj,k ≥ 0 软化并惩罚（应对新出现的障碍无法立即产生所需加速度的情况）。几何硬约束 hj(pk) ≥ 0 始终保持硬性。
- **障碍选择与轨迹校验**：
  - 求解器含**固定数量 Nobs = 15 个障碍槽位**，使问题规模与场景无关。
  - 若感知障碍数超过槽位数，按预测轨迹上的**最小归一化间距 Sj**（在节点间连续参数化 λ 上取最小）排序，取最小者进入活动集。
  - 任何与任一椭球相交或低于最低高度的轨迹被拒绝；若前一预测在更新后的障碍集下仍无碰撞则复用。

### 2.5 代价函数与实现
- 阶段/终端代价为**非线性最小二乘**形式，残差 yk 含位置、误差四元数向量部、速度、角速度、推力、控制量、角加速度与障碍势；权重块 `W = blkdiag(Q, Rf, R, Qω̇, Qobs)`。R 惩罚 ḟ 以避免 bang-bang 推力，Rf 把推力拉向悬停值。
- **非均匀时间步长**：近端短步保证积分精度，远端长步扩展时域覆盖。
- **实现**：集成到开源 MRS UAV 系统，运行 **100 Hz**；时域 **N = 28 个节点、2.0 s**（5×10 ms + 5×50 ms + 5×80 ms + 13×100 ms）；基于 **acados** 框架、实时迭代（RTI）方案。
- **优化与参考输出解耦**：求解器独立计时，控制器指令在每个控制步通过对已存预测插值产生；预测超过时域后被丢弃，跟踪器回退到当前状态指令。
