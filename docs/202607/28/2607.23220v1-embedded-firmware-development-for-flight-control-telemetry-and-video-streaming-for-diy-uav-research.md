## 摘要
本文介绍了基于双核ESP32-S3微控制器的低成本无人机四旋翼固件的设计与优化，目标是在严格的嵌入式资源约束下实现实时飞行控制、遥测与视频传输。该固件利用两个核心的专用任务分配：Core 1上运行400Hz控制循环，通过Madgwick滤波器实现传感器融合，并采用结合选择性导数缩放和前馈制动的混合定点PID控制器；Core 2则处理50Hz遥测编码以及基于UDP的25FPS VGA帧视频与数据流，确保控制与通信工作负载分离，防止延迟干扰。核间通信采用零拷贝缓冲区与互斥锁保护，以最小化开销并保证确定性执行。自定义事件驱动线程与类RTOS静态调度确保了ESP32-S3在有限内存与浮点性能下的实时响应及无抖动运行。实验评估证实，该固件架构提供了精确稳定的飞行稳定与可靠的遥测支持，使资源受限的ESP32-S3平台能够以最低投入和完全定制能力支持DIY项目与研究。

## Abstract
This paper presents the design and optimization of quadcopter firmware for a low-cost UAV based on the dual-core ESP32-S3 microcontroller, targeting real-time flight control, telemetry, and video transmission within stringent embedded resource constraints. The firmware leverages dedicated task allocation across the two cores: 400Hz control loop on Core 1 implements sensor fusion with a Madgwick filter, a hybrid fixed-point PID controller enhanced by selective derivative scaling and feedforward braking. Core 2 handles 50 Hz telemetry encoding and UDP-based video and data streaming at 25FPS VGA frames, ensuring separation of control and communication workloads to prevent latency interference. Inter-core communication employs zero-copy buffers with mutex protection for minimal overhead and deterministic execution. Custom event-driven threading and RTOS-inspired static scheduling guarantee real-time responsiveness and jitter-free operation despite ESP32-S3's limited memory and floating-point performance. Experimental evaluation confirms that this firmware architecture provides precise, stable flight stabilization and robust telemetry support, enabling resource-constrained ESP32-S3 platforms to handle DIY projects and research with minimal investment and full customization capability.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 利用ESP32-S3双核架构，将飞行控制（400Hz）与遥测/视频流（50Hz/25FPS）严格分离到不同核心，避免任务干扰；采用混合PID控制器（前馈制动+选择性导数缩放）提升抗扰动能力；通过零拷贝缓冲区与互斥锁实现低开销核间通信。

### 关键技术细节
- **飞行控制（Core 1）**：
  - **传感器融合**：Madgwick滤波器（固定点实现）。
  - **控制律**：混合级联PID，对滚转、俯仰、偏航分别独立控制。
  - **前馈制动**：当误差导数`de/dt < 0`且误差正向趋近零点时，施加一次制动脉冲`u_b = -k_b * de/dt`，抑制惯性，允许增大比例增益但不引起振荡。
  - **选择性导数缩放**：针对滚转和俯仰轴，使用非线性缩放函数`S_axis(e)`抑制大误差时的导数作用，仅在误差接近零时启用微分项，避免传感器噪声引起的导数冲击。公式：
    - `S_x(e) = min(1.0, max(0.0, 10/(|e-3|·|e+3|·σ_x) + 1 · 5))`，σ_x=0.2
    - `S_y(e) = min(1.0, max(0.0, 10/(|e-5|·|e+5|·σ_y) + 1 · 5))`，σ_y=0.067
    - 最终微分项：`D(t) = K_d · S_axis(e) · de/dt`
  - **混合控制输出**：`u_i = K_p·e_i + K_i∫e_i dt + K_d·S_i(e_i)·de_i/dt + u_{b,i}`，i∈{roll, pitch, yaw}
  - **自适应让出CPU**：在循环中插入`vTaskDelay()`等，避免看门狗超时。
- **遥测与视频流（Core 2）**：
  - **遥测**：紧凑打包为单字节UDP包，每个包包含完整快照，容忍丢包。
  - **视频流**：OV5640摄像头（5MP，JPEG压缩）通过DCMI接口采集VGA帧（8-25KB），存入PSRAM FIFO，分割为1000字节UDP包，附带帧ID和分片ID。接收端采用轻量级模糊填充处理丢包。
- **核间通信**：零拷贝缓冲区+互斥锁，尽量减少复制开销，保证确定性执行。

### 算法流程（文字说明）
1. Core 1以400Hz循环：读取IMU数据 → Madgwick滤波 → 计算误差 → 前馈制动判断 → 选择性导数缩放 → 计算PID控制量 → 输出PWM到电机 → 自适应让出CPU。
2. Core 2以50Hz循环：读取传感器/状态信息 → 打包遥测UDP包；同时独立线程以25FPS读取摄像头JPEG帧 → 分片为1000字节UDP包 → 发送。
3. 两核通过共享内存（互斥锁保护）交换关键状态（如姿态、指令）。
